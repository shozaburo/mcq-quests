# 【C8】月次レポート統合 — Lv.3 書司・117分（クリアで「書司」称号）

## 1. はじめに：複数ファイル横断統合 — Skill化で永久自動化

複数のExcelファイル（部門別・支店別）を毎月集約する月次定型業務。手作業なら半日、Claudeなら3分。さらにSkillに保存すれば、毎月「いつもの月次やって」の一言で全自動実行――これがLv.3クリアのゴールです。

## 2. 学習目標（クリア後にできること）

- 複数Excelを横断してデータを転記・結合
- 全社サマリー＋部門別の月次レポートを1ファイルに統合
- Skillに保存して翌月以降ボタン一つで完結
- 月次定型業務の属人化を解消

## 3. 扱う具体例：複数Excel横断統合

### シート構成
- シート1：全社サマリー（KPIダッシュボード）
- シート2以降：部門別シート（営業部・経理部・製造部…）

### 整合性チェック
部門別合計と全社合計が一致するかを自動検証。不一致は警告。

### 過去月との比較
前月レポートと自動比較し、変化点を強調表示。

**プロンプト例**：
> 「全Excelを横断して、月次サマリーを1ファイルにまとめて。シート1=全社サマリー、シート2以降=部門別」

**発展**：Skillに保存して毎月「いつもの月次やって」で完結。

## 4. 使うClaude機能：xlsxスキル + Code Execution + Skills

複数Excelの読み込み、Pythonでの集計・転記、結果Excelの生成。SKILL.mdに手順・ファイル命名規則・想定シート構造を保存して再利用。

**最大のメリット**：月次定型業務を完全自動化。属人化解消、月初の経理工数削減、引き継ぎ不要に。

## 5. つまずきポイントと対策

### つまずき①：部門ごとに列名・書式が微妙に異なる
「列名のマッピング表を最初に作成し、統一フォーマットに正規化してから集計」と二段階処理を指示。C2「Excel統一フォーマット化」のスキルと組み合わせる。

### つまずき②：Skillに保存しても引き継ぎ時に動作しない
SKILL.mdに「対象ファイルの命名規則」「想定するシート構造」「最終出力先」を明記。例外ケース対応も記載。

### つまずき③：シート名・セル位置が部門ごとに異なる
「シート名は部門名と一致」「データ開始行は3行目から」など、共通ルールをSkillに含める。

## 6. 実践ステップ

1. **各部門Excelを共通フォルダに集約**（命名規則：部門名_YYYYMM.xlsx）
2. **Claudeで統合プロンプト実行**
3. **生成された月次レポートを確認**
4. **Skillとして保存**（プロンプトと手順をSKILL.mdに）
5. **翌月以降は「いつもの月次やって」で自動実行**

## 7. Skill化のテンプレ例

```markdown
# 月次レポート統合スキル

## 目的
3部門のExcelを統合し、全社サマリー+部門別レポートを生成

## 入力
- 営業部_YYYYMM.xlsx
- 経理部_YYYYMM.xlsx
- 製造部_YYYYMM.xlsx

## 処理
1. 列名マッピング（売上=Revenue=収益）
2. 全社合計算出
3. 整合性チェック
4. シート構成で出力
```
