# 【F8】ツール権限を設定 — Lv.6 棟梁・146分（クリアで「棟梁」称号）

## 1. はじめに：AIの行動を細かく管理
AIに何でも自由にさせるのではなく、「ファイル削除はDeny」「特定フォルダのみAllow」と細かく権限制御。安全な業務運用に必須。

## 2. 学習目標
- Claude Settings JSONの編集
- ツールアクセス権限のAllow/Deny設定
- 業務リスクに応じた権限設計
- 安全で確実なAI運用基盤の構築

## 3. 扱う具体例
**手順**：
> 設定 → Tools → Permissionsで「ファイル削除はDeny」「特定フォルダのみAllow」など個別設定。

### 設定ファイル例（`.claude/settings.json`）
```json
{
  "permissions": {
    "allow": [
      "Bash(ls:*)",
      "Bash(grep:*)",
      "Edit(./reports/*)"
    ],
    "deny": [
      "Bash(rm:*)",
      "Bash(sudo:*)",
      "Edit(./.env)",
      "Write(./password*)"
    ]
  }
}
```

## 4. 使うClaude機能
- **Permissions（settings.json）**：ツール権限の細粒度制御
- **環境別設定**：開発/本番で異なる権限
- **最大のメリット**：誤操作・情報漏洩のリスクをゼロに

## 5. つまずきポイントと対策
- **つまずき①**：必要な権限まで拒否してしまう → 段階的に緩める
- **つまずき②**：許可しすぎてリスク → 「最小権限の原則」
- **つまずき③**：設定が複雑 → 「Allow/Denyのチェックリスト」を作成

## 6. ポイント
業務で使うときは必ず確認、特に削除系は慎重に。

## 7. 実践ステップ
1. 業務リスクを洗い出し
2. 「絶対許可」「絶対拒否」を明示
3. settings.jsonに記述
4. テスト環境で動作確認
5. 本番反映
