# 【E6】ノート・DBへ自動記録（OneNote/Notion/Spreadsheet対応） — Lv.5 橋渡・128分

## 1. はじめに：会議の決定事項が「自動で台帳化」される世界
OneNote、Notion、Google Spreadsheetへ会議結果や日報を自動記録。手作業の入力をゼロに。

## 2. 学習目標
- ノート・DBへの自動書き込み
- タスクや決定事項を構造化して蓄積
- タグ管理で後から検索可能に
- LMS/CRMの代替としてSpreadsheet活用

## 3. 扱う具体例
**プロンプト例**：
> 連携後 → 「今日の会議の決定事項とタスクを、『プロジェクト管理』シート/ページに新規行/ページとして追加。タグは『MTG』『〇〇案件』で」

**ポイント**：塾長スタイルではGoogleスプレッドシートをLMS/CRMの代替として使うのも◎。

## 4. 使うClaude機能
- **MCP Connectors**：OneNote/Notion/Google Sheets
- **構造化書き込み**：列・タグ・親子関係を保持
- **最大のメリット**：「会議→記録」を完全自動化

## 5. つまずきポイントと対策
- **つまずき①**：書き込み先の構造が複雑 → 事前にテンプレート整備
- **つまずき②**：重複記録 → 既存行と照合してから書き込み
- **つまずき③**：タグの一貫性 → タグ辞書をルール化

## 6. 実践ステップ
1. ノート/DBのテンプレ準備
2. MCP接続
3. 書き込みプロンプト
4. タグ・カテゴリ自動設定
