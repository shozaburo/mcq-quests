# 【G4】Hooksでトリガー実行 — Lv.7 影守・120分

## 1. はじめに：イベント駆動の自動化
ファイル更新や作業完了を「トリガー」として、次のスクリプトを自動実行。Hooksで業務フロー全体を連鎖させる。

## 2. 学習目標
- Hooks機能の理解と設定
- イベント駆動の自動化
- ファイル更新→集計→通知の連鎖
- 業務フローの完全自動化

## 3. 扱う具体例
**設定例**：
> 「.claude/settings.json にhookを設定。『〇〇.csvが更新されたら、自動で集計スキルを実行』」

### settings.json hooks例
```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write",
        "hooks": [{ "type": "command", "command": "echo Updated" }]
      }
    ]
  }
}
```

## 4. 使うClaude機能
- **Hooks（settings.json）**：イベントベースのスクリプト実行
- **連鎖実行**：複数Hookの組み合わせ
- **最大のメリット**：「人間が起動」をなくす

## 5. つまずきポイントと対策
- **つまずき①**：無限ループ → Hook内で同じファイルを更新しない
- **つまずき②**：エラー時の挙動 → エラーハンドリング明記
- **つまずき③**：複雑化しすぎる → シンプルに保つ

## 6. 実践ステップ
1. トリガーイベント決定（ファイル更新等）
2. 実行スクリプト作成
3. settings.json編集
4. テスト実行
5. 本番運用
