# 【C3】Excelレポート自動生成 — Lv.3 書司・86分

## 1. はじめに：分析結果を「見せる資料」へ自動変換する時代

データ分析が終わっても、「どう見せるか」が課題になります。グラフを作り、ピボットテーブルで集計し、シートを分けて整える――これらの定型作業に経理担当者は毎月数時間を取られていました。Code Execution機能を備えたClaudeを使えば、分析結果から「そのまま会議で使えるExcelレポート」を自動生成できます。

## 2. 学習目標（クリア後にできること）

- 分析結果をもとに、見やすいグラフやピボットテーブルを含むExcelレポートをゼロから自動生成できる
- 4シート構成（表紙・サマリー・月別グラフ・詳細データ）の標準レポートを5分以内で出力
- 手作業のグラフ作成・シート分割の手間をゼロにし、即座に提出可能な.xlsxファイルを得られる

## 3. 扱う具体例：4シート構成のExcelレポート

### シート1：表紙
レポートタイトル、作成日、対象期間、作成者を記載。会議資料として配布する際の「顔」になる部分。

### シート2：サマリー
全体の売上や重要KPI、分析から得られた傾向の要約をテキストと簡潔な表で。経営者は「ここだけ読めば概要を把握できる」を目指す。

### シート3：月別グラフ
分析結果の推移を視覚的に表現。棒グラフ、折れ線グラフ、円グラフを使い分け、軸ラベル・凡例・色合いを整える。

### シート4：詳細データ
グラフやサマリーの元になっているローデータの一覧。第三者が検証できる粒度で。

**プロンプト例**：
> 「先ほどの分析結果を元に、表紙＋サマリー＋月別グラフ＋詳細データの4シートからなるExcelレポートを作って」

## 4. 使うClaude機能：xlsxスキル + Code Execution

ClaudeがバックグラウンドでPythonを記述し、安全な仮想環境（サンドボックス）で実行してExcelファイルを生成する機能。openpyxlやpandasなどのライブラリを駆使し、複数シート構成・グラフ・ピボットを含む.xlsxファイルを直接作成する。

**最大のメリット**：分析→可視化→ファイル化の一気通貫。手作業のExcel整形がゼロに。

## 5. つまずきポイントと対策

### つまずき①：グラフが思い通りの形にならない・文字化け
プロンプトに「グラフ種類（棒グラフ）、軸ラベル、色合い」を具体的に指定。文字化け対策として「matplotlib font設定を含めて」と念押し。

### つまずき②：シート間のデータ連携・書式の不整合
「『詳細データ』シートの数値を元にして、『月別グラフ』シートのグラフを作成して」のように、シート間の関係性を明示。

## 6. 実践ステップ

1. **データ準備**：分析対象のCSV/Excelをドライブに用意
2. **指示出し**：プロンプトに4シート構成と具体例を明記
3. **生成確認**：Code Executionの実行ログでエラーがないか確認
4. **微調整**：「グラフの色を青系に変更」「タイトルを変更」など追加指示で調整

## 7. 確認問題

1. Code Executionを使ってExcelを生成するメリットは何か？（一気通貫・正確性）
2. シート間連携が崩れる失敗例のプロンプトに、どんな指示を加えれば正しく生成されるか？
3. 経営会議向けのExcelレポートを作成するための最初のプロンプトをどう書くか？

## 8. おわりに

「分析→Excel化」を自動化できると、経理担当者の発想は「数字を整える」から「数字から何を読むか」に変わります。Claudeに資料化を任せ、人間は意思決定の質を上げる――これがLv.3「書司」の核心です。
