【D1】GPTs（自分専用チャットボット）の概念と作成準備 - クイズ（サイト実装分）

Q1. GPTs（自分専用AI）を作るいちばんの目的はどれ？
1. AIの応答速度を上げるため
2. 毎回同じ前提を説明する手間をなくすため ← 正解
3. 月額料金を安くするため
4. 会話履歴を自動で保存するため
解説：一度教えれば、次からは説明なしで「あなた流」の答えが返ってくる。

Q2. 最初の1体を企画するとき、1行で言えるようにしておくことはどれ？
1. いくらまで課金できるか
2. どのAIモデルを使うか
3. 何色のアイコンにするか
4. 誰の・どんな定型業務を・どう楽にするか ← 正解
解説：目的がはっきりしているほど、いいGPTsに育つ。

Q3. GPTs化する業務を洗い出すプロンプトとして、このマスに沿うのはどれ？
1. 「GPTs化すると効果が大きい定型業務を洗い出して。頻度×説明の手間で優先順位をつけて」 ← 正解
2. 「いま一番人気のGPTsを教えて」
3. 「私の業務をすべて自動化して」
4. 「GPTsの作り方の歴史を説明して」
解説：「頻度×説明の手間」で優先順位をつけるのがポイント。

Q4. 最初のGPTs作りでよくある失敗と、その対策はどれ？
1. 狭く作りすぎて失敗 → 何でもできる万能型にする
2. 名前を凝りすぎて失敗 → 名前は後で決める
3. 万能GPTsを作ろうとして失敗 → 「議事録整形専用」くらい狭く、1体1業務で作る ← 正解
4. テストしすぎて失敗 → テストは省略する
解説：欲張って万能型を目指すと、どれも中途半端になる。1体1業務が成功の型。

Q5. D1がステージDの最初に置かれている理由はどれ？
1. いちばん難しいマスだから
2. 「何を作るか」の企画を固めてから作り始めるほうが、うまくいくから ← 正解
3. 他のマスとは関係のない独立した作業だから
4. 有料プランの契約が必要なマスだから
解説：企画が決まれば、D2からの作業がすいすい進む。遠回りに見えて近道。
