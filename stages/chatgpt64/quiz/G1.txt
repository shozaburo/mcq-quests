【G1】MCPの基礎知識と概念 - クイズ（サイト実装分）

Q1. MCP（Model Context Protocol）とは、ひとことで言うと何？
1. 画像を高速で生成するための新しいAIモデル
2. パソコンの動作を速くするためのメモリ管理技術
3. AIと外部ツールをつなぐための共通規格 ← 正解
4. SNSの投稿を予約するためのカレンダー機能
解説：MCPはAIと外部ツールをつなぐ共通規格。いろんな道具に手を伸ばせるようになる土台の決まりごと。

Q2. MCPのイメージとして、このマスで使われている例えはどれ？
1. 「AI用のUSBポート」——対応ツールなら何でも挿して使える ← 正解
2. 「AI用の金庫」——大事なデータを鍵をかけてしまっておける
3. 「AI用の翻訳機」——外国語のサイトを日本語にしてくれる
4. 「AI用のカメラ」——画面の中身を写真に撮ってくれる
解説：「AI用のUSBポート」。対応している道具なら何でも挿して使える差し込み口。

Q3. MCPという横文字に圧倒されてしまったとき、どう理解して前に進めばいい？
1. 全部の技術仕様を暗記してから次に進む
2. プログラミングを先に習得してから戻ってくる
3. 理解できないので、このステージは飛ばしてしまう
4. 「AIがGmailやSlackを直接触れるようになる差し込み口」とだけ理解する ← 正解
解説：むずかしく考えなくてOK。この一文だけ分かれば前に進める。細かいことは使いながら覚える。

Q4. MCPの概念を学ぶプロンプトとして、このマスの例に沿っているのはどれ？
1. 「MCPの技術仕様書を英語の原文のまま全部見せて」
2. 「MCPとは何か、家電とコンセントの例えで説明して。私が使っているツールはMCP対応している？」 ← 正解
3. 「MCPを使わずに済む方法だけを教えて」
4. 「MCPのプログラムコードを今すぐ書いて」
解説：身近な例えでお願いするのがコツ。ついでに自分のツールが対応しているかも聞けば一石二鳥。

Q5. G1がステージGの最初に置かれている理由はどれ？
1. MCPの仕組みを知ると、以降の連携の全体像が一気に見通せるから ← 正解
2. G1が終わればもう他のマスをやる必要がないから
3. 一番むずかしい内容を最初に済ませるべきだから
4. MCPは概念だけ知れば実際に使うことはないから
解説：最初に地図を広げると旅が楽になる。MCPが分かれば、この先の連携の全体像が見通せる。
