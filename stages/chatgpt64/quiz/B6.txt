【B6】スケジュール機能（Pulse）を利用した「毎朝のニュース・競合リサーチ」の自動化 - クイズ（サイト実装分）

Q1. Pulseとはどんな機能？
1. 音声でChatGPTと会話する機能
2. 画像を高速で生成する機能
3. 決めたスケジュールでAIが定期実行してくれる機能 ← 正解
4. ファイルを自動でバックアップする機能
解説：毎朝8時、みたいに時刻を決めておけば、指示しなくてもAIが定時に働く。

Q2. このマスが「初めての自動化体験」と呼ばれる理由はどれ？
1. PCの電源が自動で入るから
2. メールが自動で送信されるから
3. AIの応答速度が上がるから
4. 自分が指示しなくても、AIが定時に働いてくれるから ← 正解
解説：「頼む」から「仕組みにする」への第一歩。

Q3. 毎朝のリサーチを設定するプロンプトとして、このマスの例に沿うのはどれ？
1. 「今すぐ業界ニュースを教えて」
2. 「毎朝8時に、{業界}の主要ニュースと{競合3社}の新着情報を調べて、3分で読めるダイジェストにまとめて届けて」 ← 正解
3. 「競合3社のホームページを作って」
4. 「業界ニュースを全文コピーして保存して」
解説：いつ・何を・どんな形でまで決めて仕込むのが型。

Q4. 届く情報が浅い、または多すぎるときの絞り方はどれ？
1. 「私に関係する順に3件だけ」「なぜ重要かを1行添えて」と指定する ← 正解
2. 配信を止めて手動リサーチに戻す
3. 配信時刻を深夜に変更する
4. 競合の数を10社に増やす
解説：量より「自分に関係あるか」で絞るのがコツ。

Q5. このマスの実践課題の進め方として正しいのはどれ？
1. 設定だけして受け取りは確認しない
2. 毎日ちがうテーマで新しい配信を追加し続ける
3. 初日に完璧な指示文を作ってから設定する
4. 定期リサーチを1本設定し、3日間受け取って精度を調整する ← 正解
解説：最初から完璧を狙わず、届いたものを見ながら指示文を直していく。自動化は育てるもの。
