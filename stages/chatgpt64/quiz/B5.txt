【B5】ChatGPT Workを使った複数Excel/CSVデータの統合・集計・分析 - クイズ（サイト実装分）

Q1. このマスでWorkモードに任せる仕事の範囲はどれ？
1. ファイルの保存場所を変えるだけ
2. 複数のExcel/CSVの統合・集計・グラフ化・示唆出しまでを一括で ← 正解
3. 1つのファイルの誤字チェックだけ
4. データの印刷とファイリング
解説：ファイルを渡したら、統合から集計、グラフ、気づきの指摘まで一気に組み上げる。

Q2. このマスが目指す、あなたの時間の使い方の変化はどれ？
1. 「ファイルを開いて関数を書く」時間が「結果を確認して判断する」時間に変わる ← 正解
2. Excelの関数をより速く書けるようになる
3. データを見る時間そのものがゼロになる
4. 集計を部下に頼む時間が増える
解説：手を動かす側から、結果を見て判断する側へ。

Q3. 売上データを分析させるプロンプトとして、このマスの例に沿うのはどれ？
1. 「この3つのCSVをきれいに印刷して」
2. 「この3つのCSVのファイル名を変えて」
3. 「この3つの売上CSVを統合して、月別・商品別に集計して。前年比が悪化している商品を指摘して、考えられる原因も挙げて」 ← 正解
4. 「この3つのCSVを1つのフォルダにまとめて」
解説：統合→集計→悪化商品の指摘→原因の仮説、と欲しい結果まで一息に注文する。

Q4. ファイルごとに列名の表記がバラバラで統合に失敗するとき、添えるひと言はどれ？
1. 「エラーは無視して進めて」
2. 「列名は全部削除して」
3. 「統合できた分だけでいいよ」
4. 「列名が違う場合は内容から対応づけて。対応表も見せて」 ← 正解
解説：表記ゆれは、内容から対応づけさせれば乗り越えられる。

Q5. このマスで使う機能の組み合わせはどれ？
1. Chatモード／トーン指定／ロールプレイ
2. ChatGPT Work／複数ファイル処理／データ分析・グラフ生成 ← 正解
3. Pulse／Web検索／通知
4. 画像生成／表デザイン／印刷設定
解説：複数ファイルをまとめて預かって、分析とグラフまで仕上げるのがWorkの本領。
