【F1】Appshotsで画面を瞬間共有してUI修正 - クイズ（サイト実装分）

Q1. 「Appshots」はどんな機能？
1. 画面を自動で録画して動画を作る機能
2. 見ている画面をワンアクションでCodexに共有できる機能 ← 正解
3. スクリーンショットをフォルダに整理する機能
4. 画面の文字を読み上げてくれる機能
解説：Appshotsは、いま見ている画面をワンアクションでCodexにぱっと共有できる機能。見せれば伝わる。

Q2. 画面の崩れを直してほしいとき、F1で学ぶ頼み方はどれ？
1. 崩れの状況を文章で細かく箇条書きにして送る
2. 崩れた画面を自分で直してから報告する
3. Appshotsで画面を共有して「崩れている箇所を特定して、直して」と頼む ← 正解
4. エラーが出るまで待ってからエラー文を送る
解説：画面を見せて「崩れている箇所を特定して、直して」でOK。画面1枚見せるほうが早くて正確。

Q3. 「文章だけで状況を説明したけど伝わらない」ときの合言葉はどれ？
1. 説明3行より画面1枚 ← 正解
2. 百聞は一見にしかずだから動画を撮る
3. 説明は長ければ長いほど伝わる
4. 伝わるまで同じ文章を送り続ける
解説：「説明3行より画面1枚」がF1の合言葉。迷ったら見せる。

Q4. Appshotsを使うと、AIとの協働スタイルはどう変わる？
1. AIに話しかける回数を減らして節約できる
2. AIが人間の代わりに画面を操作してくれる
3. 文章を書く力が鍛えられて説明上手になる
4. 「見せれば伝わる」スタイルになり、状況説明の手間が消える ← 正解
解説：「見せれば伝わる」に変わるのが一番の値打ち。本題の「どう直すか」にすぐ入れる。

Q5. F1の実践課題として設計されているのはどれ？
1. 画面の説明文を10パターン書いてみる
2. 気になる画面をAppshotsで共有し、修正または解説をしてもらう ← 正解
3. Appshotsの設定画面をすべて確認する
4. 他人のPC画面を共有してもらって比較する
解説：気になる画面を1つ共有してみる。直してもらうでも解説してもらうでもOK。
