【C8】ChatGPT Sites機能を利用した、Webサイト・LPの即時作成と公開術 - クイズ（サイト実装分）

Q1. ChatGPT Sites機能の特長として正しいのはどれ？
1. 印刷用のチラシデータを作る機能
2. サイトのアクセス解析だけを行う機能
3. サーバー契約もHTML知識も不要で、作ったページをその場でWebに公開できる ← 正解
4. 既存サイトのデザインをコピーする機能
解説：サーバーも専門知識もいらない。作ったLPがその場で公開され、URLが発行される。

Q2. C8で体験する「スピード感」を表しているのはどれ？
1. 1年かけてじっくりサイトを育てる
2. 思いついた企画のページが今日中に世に出る ← 正解
3. 制作会社の納期が半分になる
4. ページの表示速度が2倍になる
解説：朝ひらめいた企画のページが夕方には世に出ている、そのスピード感を体験する。

Q3. Sitesで公開するLPの頼み方として、設計書の例に沿っているのはどれ？
1. 「話題になりそうなページを適当に作って」
2. 「C6のLP構成とコピーを使って1ページのLPを作って。スマホ表示を最優先。C3のテンプレ画像も組み込んで」 ← 正解
3. 「パソコン表示だけ整えてくれれば十分」
4. 「文章はダミーのままで公開して」
解説：これまでの成果物を材料に指定し、スマホ表示を最優先に。

Q4. 「公開＝完成」と思ってしまう人への、設計書のアドバイスはどれ？
1. 公開したら1年間は触らないほうがよい
2. 完成度が100%になるまで公開しないほうがよい
3. 公開後の修正は有料なので慎重にすべき
4. URLを人に送って感想をもらい、直してすぐ再公開する——育てるのが前提 ← 正解
解説：公開はゴールじゃなくスタート。ページは手を入れて育てるもの。

Q5. C8の実践課題はどれ？
1. 1ページのサイトを公開してURLを知人1人に送り、感想を1つ反映する ← 正解
2. 10ページの大型サイトを一気に作る
3. サイトの企画書だけを書いて終える
4. 独自ドメインを取得して設定する
解説：公開して感想をもらい1つ反映する。この一巡が「育てるサイト運営」の第一歩。
