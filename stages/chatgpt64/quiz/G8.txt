【G8】ブラウザ操作自動化で競合調査 - クイズ（サイト実装分）

Q1. G8でCodexにやらせることはどれ？
1. 競合他社のサイトを改ざんすること
2. 自社サイトのデザインを自動で変更すること
3. 競合のSNSアカウントに自動でコメントすること
4. Webブラウザを操作させ、競合サイトの巡回・価格チェック・情報収集を自動化すること ← 正解
解説：ブラウザをAIに操作させ、競合サイトの巡回や価格チェックを自動化する。手作業の調査が勝手に回る。

Q2. データ取得先のルールについて、正しい心がけはどれ？
1. 会員制サイトの規約・robots・アクセス頻度を確認し、「人が見てよい頻度」を超えない ← 正解
2. 自動化なのでルールは気にせず高速で巡回してよい
3. 取得がバレなければ規約は守らなくてよい
4. アクセス頻度は多ければ多いほどよい
解説：規約・robots・アクセス頻度を確認し「人が見てよい頻度」を超えない。マナーを守ってこそ続けられる。

Q3. このマスのプロンプト例として正しいのはどれ？
1. 「競合サイトのデータを全ページ丸ごとコピーして保存して」
2. 「競合3社の料金ページを巡回して、価格・プラン内容を表に整理して。前回チェック時から変わった箇所があれば強調して」 ← 正解
3. 「競合サイトに毎秒アクセスして最新情報を取り続けて」
4. 「競合サイトの会員ページにログインして中の情報を取ってきて」
解説：料金ページを巡回して表に整理、変わった箇所は強調。丸ごとコピーや毎秒アクセスはマナー違反。

Q4. G8で取得データとセットで仕組み化するものはどれ？
1. データの完全削除機能
2. データの印刷と郵送
3. 取得データの整理と、変化の検知（差分検知） ← 正解
4. データの暗号化と隠蔽
解説：取ってくるだけでなく、整理して前回からの変化を検知するところまでセット。見る時間はほんの少しで済む。

Q5. G8の実践課題として正しいのはどれ？
1. 競合サイトを1日100回チェックする仕組みを作る
2. 競合の情報を自社サイトにそのまま転載する
3. 調査は自動化せず毎日手作業で続ける
4. 競合ウォッチの自動巡回を1本作り、週次で差分レポートを受け取る ← 正解
解説：自動巡回を1本作り、週に1回差分レポートを受け取る。週次くらいのゆったりした頻度がちょうどいい。
