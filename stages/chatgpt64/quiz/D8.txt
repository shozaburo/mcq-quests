【D8】専門特化型AI（右腕AI）の完成 - クイズ（サイト実装分）

Q1. D8の位置づけとして正しいのはどれ？
1. ステージDの中で最も簡単な準備運動のマス
2. ナレッジ＋インストラクション＋Skillを統合する、ステージDの集大成 ← 正解
3. 他のマスと関係なく単独で完結するおまけのマス
4. ステージEの内容を先取りするだけのマス
解説：D2ナレッジ・D3インストラクション・D5〜D7のSkillを、ぜんぶひとつに束ねる集大成。「右腕AI」まであと一歩。

Q2. プロンプト例で、設計の最初にやるべきとされているのはどれ？
1. AIの名前とアイコンを決める
2. 完成発表会の日程を決める
3. 有料プランをアップグレードする
4. 現状の弱点（答えられないこと）を洗い出すテスト計画を立てる ← 正解
解説：最初は「今なにが答えられないか」の洗い出し。弱点が分かれば足すべきナレッジやルールがはっきりする。

Q3. 「作って満足して使わなくなる」ことへの対策はどれ？
1. 毎日の業務動線（ブックマーク・ショートカット）に置く ← 正解
2. 使わなくなったら新しいAIを作り直す
3. 使うたびに記録を紙に書く
4. 月に1回だけ使う日を決める
解説：せっかくの右腕も遠くにいたら呼ばれなくなる。ブックマークやショートカットで毎日の動線に置く。

Q4. D8を終えると手に入るものとして、このマスに沿うのはどれ？
1. AIに関する資格・認定証
2. 無制限の利用権
3. 自分の専門業務に特化した「自分の型を持つAI」 ← 正解
4. 最新モデルへの優先アクセス
解説：手に入るのは「自分の型を持つAI」。あなたのやり方・文体・手順を覚えた、世界にひとつの右腕。

Q5. D8の実践課題はどれ？
1. 専門特化AIの構想をノートにまとめるだけでよい
2. 専門特化AIを完成させ、1週間毎日1回は実務で使う ← 正解
3. 完成したら1か月間は触らずに寝かせる
4. 完成後すぐに一般公開する
解説：完成させたら1週間毎日1回は実務で使う。毎日使ってこそ、右腕はあなたの手に馴染んでいく。
