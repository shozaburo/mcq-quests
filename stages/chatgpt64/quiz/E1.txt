【E1】Codexの概要とGPT-5.6モデルの使い分け - クイズ（サイト実装分）

Q1. AIエージェント「Codex」の説明として正しいのはどれ？
1. ブラウザの中だけで会話するチャット専用のAI
2. スマホでしか使えないメモアプリ
3. 自分のPCの上でファイル操作やコード実行まで行うAIエージェント ← 正解
4. 画像を生成することに特化したAI
解説：Codexはブラウザの中の会話ではなく、あなたのPCの上で実際に手を動かすAIエージェント。安全な任せ方はこの先で学ぶ。

Q2. GPT-5.6の3モデルのうち、Sol（ソル）の持ち味はどれ？
1. 高速で、軽い作業向き ← 正解
2. 深い思考で、難問向き
3. バランス型で、日常業務向き
4. 画像生成の専門モデル
解説：Solは高速、単純作業をぱっと片づけるタイプ。適材適所。

Q3. Luna（ルナ）を使うのがふさわしい場面はどれ？
1. ファイル名を一括で変えるだけの単純作業
2. 毎日の定型的なメール下書き
3. とにかく速く終わらせたい軽作業
4. じっくり考えてほしい設計や難問 ← 正解
解説：Lunaは深い思考の担当。設計や難問など腰を据えて考える仕事に出す。

Q4. 「常に最強モデルを使っていたら、遅いし高い」への対処はどれ？
1. モデルは選ばず、毎回おまかせにする
2. 日常はTerra、単純作業はSol、設計や難問だけLunaと使い分ける ← 正解
3. 全部Lunaに固定して品質を最優先する
4. 全部Solに固定して速さを最優先する
解説：使い分けが答え。日常はTerra、単純作業はSol、難問だけLuna。火加減を変えられる人が上手。

Q5. このマスの実践として、設計書に沿った頼み方はどれ？
1. 「私の業務リストを見て、Chat/Work/Codexのどれ向きかと、使うべきモデル（Sol/Terra/Luna）を仕分けして」 ← 正解
2. 「私の業務を全部Codexで自動化して」
3. 「一番高性能なモデルだけ教えて」
4. 「業務リストを削除して整理して」
解説：まずは仕分けから。自分の業務がどの道具・どのモデル向きかをAIと棚卸しする。
