【F7】方針・ゴールを渡して任せる依頼術 - クイズ（サイト実装分）

Q1. F7で学ぶ「上級の依頼術」とはどんなもの？
1. 手順をこれまでの2倍細かく指示する
2. ゴール・制約・判断基準を渡して、進め方はAIに任せる ← 正解
3. 指示を出さずにAIの提案をひたすら待つ
4. 依頼文をすべて英語で書く
解説：手順を細かく書くのをやめ、ゴール・制約・判断基準を渡す。マイクロマネジメントから権限委譲へ。

Q2. F7のプロンプト例の構成として正しいのはどれ？
1. 「手順1から手順20まで、この通りに実行して」
2. 「とにかく頑張って。詳細はすべてお任せ」
3. 「ゴール、制約、迷ったら優先する基準を示し、進め方は任せる。大きな分岐だけ相談して」 ← 正解
4. 「結果だけ教えて。途中経過は一切報告しないで」
解説：ゴール・制約・判断基準の3点セット＋「大きな分岐だけ相談して」がF7の型。丸投げでも細かい指図でもない。

Q3. 「任せると言いつつ途中で細かく口を出してしまう」ときの対処はどれ？
1. 口を出したくなった内容を、次回の「制約・基準」に書き足す ← 正解
2. 口を出さないように作業画面を見ないことにする
3. 任せるのをやめて全部自分でやる
4. 口を出した回数を数えて反省する
解説：口を出したくなったら、その中身を次回の制約・基準に書き足す。依頼文が育ち、任せられる範囲が広がる。

Q4. ゴール指向の依頼で「制約」に書くべき内容の例はどれ？
1. AIへの励ましの言葉
2. 自分の好きな食べ物
3. 過去に成功した自慢話
4. 予算・期限・してはいけないこと ← 正解
解説：制約に書くのは予算・期限・してはいけないこと。ダメな線を先に引くのが上手な任せ方。

Q5. F7の実践課題はどれ？
1. 手順書を今までより詳しく書く練習をする
2. 手順を書かず、ゴールと制約だけで1タスクを任せて完走させる ← 正解
3. AIに自分の仕事をすべて丸投げして1日過ごす
4. ゴールを決めずに作業を始めてみる
解説：手順ナシ、ゴールと制約だけで1タスク完走。任せて完走できたときの手応えは格別。
