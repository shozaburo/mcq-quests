【C3】シード値やプロンプトテンプレートを活用した一貫性のあるSNS・ブログ用画像素材の量産法 - クイズ（サイト実装分）

Q1. C3で作る「画像量産の体制」の柱となる2つの道具はどれ？
1. 高性能パソコンと液晶タブレット
2. シード値の固定とプロンプトテンプレート（型文） ← 正解
3. 有料の写真素材サイトと編集ソフト
4. 外注デザイナーと発注書
解説：この2つが量産の羽。同じキャラ・同じ世界観の画像を何枚でも生み出せる。

Q2. アイキャッチ量産の考え方として、C3が目指す形はどれ？
1. 毎回ゼロから新しいデザインを考える
2. 1枚の画像をすべての記事に使い回す
3. 型に流し込んで作る——差し替え箇所だけ変えて同テイストで量産する ← 正解
4. 画像はやめて文字だけの投稿にする
解説：{季節}{商品}{ひとこと}の3箇所だけ差し替えれば同テイストで量産できる。

Q3. テンプレート化を頼むプロンプトとして設計書の例に沿っているのはどれ？
1. 「このプロンプトをテンプレート化して。3箇所だけ差し替えれば同じテイストで量産できる形にして」 ← 正解
2. 「毎回ちがう雰囲気になるようにランダムに作って」
3. 「テンプレートは使わず自由に描いて」
4. 「一番人気のデザインを予想して」
解説：どこを固定してどこを変えるかを設計するのがあなたの仕事。

Q4. 量産していると微妙に絵柄がブレてくるとき、正しい対処はどれ？
1. ブレも味だと思ってそのまま使う
2. 生成のたびに新しいテンプレートを作り直す
3. 量産をやめて1枚ずつ丁寧に作る
4. 基準画像を毎回添付して「この絵柄に合わせて」と参照させる ← 正解
解説：お手本の1枚を毎回添える。言葉だけより見本を見せるほうが確実。

Q5. C3の実践課題はどれ？
1. テンプレートを10本作り比べる
2. 自分のSNS用テンプレートを1本作り、差し替えで3枚量産する ← 正解
3. 他人のテンプレートをそのまま真似る
4. 画像を1枚だけ時間をかけて仕上げる
解説：テンプレ1本＋差し替えで3枚。同じ世界観で並んで量産体制の完成を実感。
