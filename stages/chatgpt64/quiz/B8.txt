【B8】WorkモードでWord・Excel・PDF等の「最終成果物ファイル」を直接生成・保存させる技術 - クイズ（サイト実装分）

Q1. このマスで学ぶ、ChatGPT Workの強みはどれ？
1. 回答の文字数が無制限になること
2. 画像の画質が上がること
3. 回答スピードが速くなること
4. Word報告書・Excel集計表・PDFなどの最終成果物をファイルとして直接生成・ダウンロードできること ← 正解
解説：回答文で終わらせず、提出できるファイルそのものを納品してもらう。

Q2. この技術によって消える「工程」はどれ？
1. AIの回答をコピペして、WordやExcelに清書し直す工程 ← 正解
2. 上司に報告書を提出する工程
3. データを集める工程
4. 成果物の内容を確認する工程
解説：コピペ清書の時間がまるごと消える。ただし内容の確認だけは消しちゃだめ。

Q3. 集計結果をファイル化するプロンプトとして、このマスの例に沿うのはどれ？
1. 「集計結果をもう一度画面に表示して」
2. 「B5で集計した結果を、①上司提出用のWord報告書（A4・1枚） ②数字の根拠が入ったExcelファイル、の2つのファイルにして出力して」 ← 正解
3. 「集計結果を暗記しておいて」
4. 「集計結果を全部削除して」
解説：誰に出すか・どんな形か・何と何かまで指定するのが任せ方のコツ。

Q4. 生成されたファイルのレイアウトが期待と違うとき、有効な手はどれ？
1. レイアウトはあきらめて手直しする
2. 同じ指示を何度も送り直す
3. 「見出し・表・強調」の希望を先に伝えるか、社内フォーマットを見本として渡す ← 正解
4. ファイル形式をPDFに変えれば必ず解決する
解説：見た目の希望は後出しせず、先に伝えるのがコツ。

Q5. Workモードで生成できるファイルの種類として挙がっているのはどれ？
1. Word・Excel・PDF・PowerPoint ← 正解
2. 動画ファイルのみ
3. 音声ファイルのみ
4. 圧縮ファイル（ZIP）のみ
解説：報告書のWord、集計のExcel、配布用のPDF、それにPowerPointまで。
