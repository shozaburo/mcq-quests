【E5】Codex Petsの設定と活用 - クイズ（サイト実装分）

Q1. Codex Petsは、何をしてくれる機能？
1. 本物のペットの世話を代行してくれる
2. ペットの写真を生成してくれる
3. 作業中のエージェントをペットとして可視化し、進行状況をひと目で分かるようにする ← 正解
4. AIの声をペット風に変える
解説：作業中のエージェントが、ペットの姿で見えるようになる機能。今どのタスクが動いているか一目で分かる。

Q2. Petsを設定する実用的な利点はどれ？
1. 今どのタスクが動いているか、視覚的に把握できる ← 正解
2. AIの処理速度が2倍になる
3. 料金が割引になる
4. ファイルが自動で暗号化される
解説：見た目がかわいいだけでなく、進行状況を視覚的に把握できる、れっきとした進行管理の道具。

Q3. Petsによって、AIとの協働の感覚はどう変わるとされている？
1. 「協働」から「競争」の感覚に変わる
2. 「監視」から「飼育・相棒」の感覚に変わる ← 正解
3. 「仕事」から「ゲーム」に完全に変わる
4. 特に何も変わらない
解説：じっと画面を監視する感じから、飼育・相棒の感覚に変わる。続ける気持ちを支えるモチベーション装置でもある。

Q4. 「しょせんおまけ機能でしょ」と侮ったときに起きがちなことはどれ？
1. 特に問題は起きない
2. ペットが反抗して作業を止める
3. 料金が上がる
4. 進行管理が雑になり、後の並列作業の段階で状況把握に困る ← 正解
解説：侮ると進行管理が雑になる。複数タスクを同時に走らせる段階で視覚的な状況把握が効いてくる。

Q5. Pets設定後の使い方として、設計書に沿った頼み方はどれ？
1. 「今動いているタスクの状況を教えて。終わったら知らせて」 ← 正解
2. 「ペットにエサをあげて」
3. 「ペットの種類を毎日変えて」
4. 「タスクの通知を全部オフにして」
解説：状況を聞いて、完了を知らせてもらう。この習慣で待ち時間に別の仕事ができる。
