【D2】GPTsへのナレッジ（過去の資料やSNS投稿など）の付与 - クイズ（サイト実装分）

Q1. GPTsのナレッジとして持たせるものの例として、このマスに挙がっているのはどれ？
1. 他社の有名なベストセラー書籍
2. インターネット上のニュース記事
3. 自分の過去資料・SNS投稿・マニュアル ← 正解
4. AIが自動生成したダミーデータ
解説：入れるのは「自分の」過去資料・投稿・マニュアル。積み上げてきたものこそ最高の教材。

Q2. ナレッジを持たせたGPTsが汎用AIと別物になる理由はどれ？
1. 「私の文体」「わが社のルール」を踏まえて答えてくれるから ← 正解
2. 応答速度が2倍になるから
3. 画像がきれいに生成できるようになるから
4. 無料で使えるようになるから
解説：自分の文体やルールを知っているAIは、長年一緒に働いてきた相棒のような使い心地になる。

Q3. ナレッジ添付後のプロンプト例として、このマスに沿うのはどれ？
1. 「この資料をすべて削除して」
2. 「この資料を英語に翻訳して」
3. 「この資料の誤字脱字を直して」
4. 「添付の過去投稿30本の文体・構成の特徴を分析して。今後この文体で書くための要点をまとめて」 ← 正解
解説：過去投稿を分析させて「この文体で書くための要点」をまとめさせるのが活用の型。

Q4. 「何でもナレッジに入れたら答えがブレる」とき、正しい対処はどれ？
1. ナレッジ機能を使うのをやめる
2. その業務で「参照してほしい資料」だけに絞る。資料の鮮度も大事にする ← 正解
3. もっと大量に資料を追加する
4. 答えがブレるのは仕様なので気にしない
解説：資料は量より質。古い資料が混ざると古い答えが出るので鮮度も大事。

Q5. D2の実践課題はどれ？
1. ナレッジ機能の説明文を読む
2. 資料を1つだけ試しに登録する
3. D1のGPTsに資料を3つ以上ナレッジ登録する ← 正解
4. 他人のGPTsのナレッジを調べる
解説：3つ入ると答え方がぐっと「あなた寄り」になるのが分かる。
