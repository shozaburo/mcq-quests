【D3】インストラクション（行動ルール）の調整とテスト - クイズ（サイト実装分）

Q1. インストラクションに書く4つの要素の組み合わせはどれ？
1. 役割・手順・出力形式・禁止事項 ← 正解
2. 名前・アイコン・色・キャッチコピー
3. 料金・期間・回数・上限
4. 感想・評価・レビュー・星の数
解説：役割・手順・出力形式・禁止事項の4点セット。人に業務マニュアルを渡すのと同じ考え方。

Q2. プロンプト例で、情報が足りないときのふるまいとして指定しているのはどれ？
1. とりあえずそれらしく答えさせる
2. エラーを出して止まらせる
3. 推測せず質問させる ← 正解
4. 前回と同じ答えを繰り返させる
解説：「情報が足りないときは推測せず質問する」の1行が大事。聞き返してくれるほうが安心して任せられる。

Q3. インストラクションの育て方として、このマスに沿うのはどれ？
1. 最初に完璧なものを書き上げて、二度と直さない
2. うまくいかなかったら最初から全部書き直す
3. 他人のインストラクションをそのままコピーして使い続ける
4. 実際に使う→ズレた点を1行追記する、の反復で育てる ← 正解
解説：一発で完璧を目指さなくていい。使ってみてズレたら1行追記。小さな反復でどんどん育つ。

Q4. インストラクションのGPTsにおける位置づけはどれ？
1. 見た目を整える飾りの部分
2. GPTsの心臓部で、AIへの「業務マニュアル」にあたる部分 ← 正解
3. 料金プランを決める部分
4. 会話履歴を保存する部分
解説：インストラクションはGPTsの心臓部。書き方ひとつで働きぶりががらっと変わる。

Q5. D3の実践課題として正しいのはどれ？
1. GPTsを完成させ、実務入力3パターンでテストして2回以上改良する ← 正解
2. インストラクションを書いたら、テストせずに公開する
3. テストは1回だけ行い、改良はしない
4. テストは他人に任せて自分では使わない
解説：実務入力を3パターン試して2回以上改良。この往復がAIへのマニュアル力を鍛える。
