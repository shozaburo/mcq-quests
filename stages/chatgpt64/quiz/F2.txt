【F2】組み込みブラウザでUI確認と自動修正 - クイズ（サイト実装分）

Q1. F2で学ぶ「開発エージェントの基本形」のループはどれ？
1. 作る→自分で見る→直す、をAIの中で回す ← 正解
2. 作る→人間が見る→AIに報告する、を繰り返す
3. 見る→直す→削除する、を繰り返す
4. 直す→作る→公開する、を一度だけ行う
解説：「作る→自分で見る→直す」をAI自身の中で回すのが基本形。組み込みブラウザでAIが自分の作品を確認できる。

Q2. 作ったWebページの確認を頼むプロンプトとして、F2の例に沿うものはどれ？
1. 「このHTMLを私のメールに送って」
2. 「このHTMLを印刷用に変換して」
3. 「このHTMLをブラウザで表示して、スマホ幅で崩れがないか自分で確認して。崩れていたら直して、直った状態を見せて」 ← 正解
4. 「このHTMLの文字数を数えて報告して」
解説：表示→確認→修正→直った状態を見せる、まで一息で頼むのがコツ。スマホ幅チェックまで任せられる。

Q3. 「人間が毎回目視確認して疲れる」つまずきへの対処はどれ？
1. 確認は週に1回だけと決める
2. 「自分で表示して確認してから報告して」と検証まで任せる ← 正解
3. 確認作業を家族に手伝ってもらう
4. 確認せずにそのまま公開する
解説：検証までAIに任せる。人間は最後の仕上がりだけ見ればいい。

Q4. 組み込みブラウザを使う一番のうまみはどれ？
1. インターネットの閲覧履歴が残らないこと
2. ページの表示速度が上がること
3. ブラウザを別途インストールしなくて済むこと
4. AI自身が作ったページを表示・確認しながら直せること ← 正解
解説：AIが自分の作品を自分の目で見て直せるのが一番のうまみ。確認と修正がAIの中で回る。

Q5. F2の実践課題はどれ？
1. 組み込みブラウザの機能一覧を書き出す
2. Webページを3つ新しく作る
3. C8または自作のページをCodexに自己確認→修正させる ← 正解
4. 他社のWebサイトの崩れを探して報告する
解説：手持ちのページをCodexに「自分で確認して直して」とやらせてみる。ループが回る瞬間は感動もの。
