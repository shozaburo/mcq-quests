【C4】画像入力（Vision）からのテキスト生成とUIモックアップの書き起こし - クイズ（サイト実装分）

Q1. C4で学ぶ「画像入力（Vision）」は、C1〜C3までとどう違う？
1. より高画質な画像を生成する機能
2. 画像に音声を付ける機能
3. 画像を「作る」のではなく「読ませて」テキストやデータに変換する活用 ← 正解
4. 画像を自動でSNSに投稿する機能
解説：ここまでは描く側、C4は読ませる側。目で見た情報をテキストやデータに変える。

Q2. ホワイトボードの写真を活用する頼み方として、設計書の例に沿っているのはどれ？
1. 「この写真を読み取って、決定事項とTODOに分けて清書して」と頼む ← 正解
2. 「この写真をもっときれいに撮り直して」と頼む
3. 「この写真の感想を聞かせて」と頼む
4. 写真は使わず記憶を頼りに議事録を書かせる
解説：どんな器に盛り付けてほしいか（決定事項とTODO）まで指定するのがコツ。

Q3. WebサイトのスクリーンショットをVisionに読ませてできることはどれ？
1. そのサイトの管理画面へのログイン
2. ページ構成や使われている要素の書き起こし ← 正解
3. サイトの表示速度の改善
4. サイト運営者への自動連絡
解説：参考にしたいサイトの骨組みが言葉になる。LPづくりの下絵にもなる。

Q4. 手書き文字の読み取りで気をつけるべき習慣はどれ？
1. AIの読み取り結果は常に正しいので確認不要
2. 手書きは読ませずすべて自分で入力する
3. 誤読を防ぐため写真は白黒に加工してから送る
4. 読み取り結果を必ず目視確認し、「読めなかった箇所は？」と聞く ← 正解
解説：手書きは誤読があるもの。「読めなかった箇所は？」と正直に白状させるのも作法。

Q5. C4の実践課題はどれ？
1. Vision機能の仕組みを図解する
2. 会議のホワイトボード（またはメモ）を撮影して、議事メモに変換させる ← 正解
3. 手書き文字の練習をする
4. スクショを100枚撮って保存する
解説：写真1枚がきちんとした記録になる瞬間を、実際の会議で試してみる。
