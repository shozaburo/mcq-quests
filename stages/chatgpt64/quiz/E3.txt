【E3】基本設定と権限管理（サンドボックス・承認） - クイズ（サイト実装分）

Q1. サンドボックスとは、どんな仕組みのこと？
1. AIの作業を隔離された環境に閉じ込め、外へ影響させないための仕組み ← 正解
2. AIの応答速度を上げるための高速化機能
3. 子ども向けのゲームモード
4. ファイルを自動で砂時計のように整列させる機能
解説：サンドボックスは隔離環境。AIの作業を囲いの中に閉じ込め、外の大事な場所に影響させない。初めての家ではまず一部屋から。

Q2. Codexの承認モードの3つの違いとして正しいのはどれ？
1. 無料・有料・法人の3プラン
2. 朝・昼・夜の時間帯別モード
3. 1回ずつ確認する／読み取りは自動／全自動、の3段階 ← 正解
4. 日本語・英語・自動翻訳の3種類
解説：承認モードは3段階。1回ずつ確認、読み取りは自動、そして全自動。どこまで手綱を渡すかの段階分け。

Q3. 初心者がまず選ぶべき、安全寄りの設定はどれ？
1. 最初から全自動にして手間を省く
2. 都度承認（1回ずつ確認）から始める ← 正解
3. 承認モードは気にせず初期設定のまま使う
4. 権限を全部オフにして何もさせない
解説：最初は都度承認。AIが何をしようとするか、1回ずつ自分の目で見て許可する。過保護なくらいでちょうどいい。

Q4. 「毎回の承認が面倒だから、最初から全自動にしたい」への正しい向き合い方はどれ？
1. 面倒なものは仕方ないので即・全自動にする
2. 全自動が不安なら使うのをやめる
3. 承認は他人に代行してもらう
4. 都度承認で「AIが何をしようとするか」を1週間観察してから、徐々に緩める ← 正解
解説：急がない。都度承認のまま1週間観察し、信用できると分かってから緩める。信頼は積み重ねで作るもの。

Q5. 権限設定に迷ったとき、設計書に沿った頼み方はどれ？
1. 「権限設定を全部オンにして」
2. 「設定画面を二度と表示しないで」
3. 「今の権限設定を説明して。私が初心者だとして、安全寄りのおすすめ設定にするには何を変えればいい？」 ← 正解
4. 「他の人と同じ設定にして」
解説：分からないなら本人に聞くのが一番早い。今の設定の説明と、初心者向けの安全寄り設定を提案させる。
