【G4】n8n×Codexでワークフロー構築 - クイズ（サイト実装分）

Q1. n8nなどで組むワークフローの基本の並びはどれ？
1. 出力先→AI処理→トリガー
2. AI処理→AI処理→AI処理
3. トリガー→出力先→AI処理
4. きっかけ（トリガー）→AI処理→出力先 ← 正解
解説：「きっかけ→AI処理→出力先」の順。何かが起きたらAIが考えてどこかに届ける。この3つの並びが基本。

Q2. 最初から複雑なフローを組んでつまずいたら、どうすればいい？
1. n8nをあきらめて別のツールを探す
2. ノード3つ（受け取る→AI→送る）の最小構成から始める ← 正解
3. ノードを増やしてさらに複雑にする
4. 全部手作業に戻す
解説：欲張らず、ノード3つの最小構成から。受け取る→AI→送る、これだけでちゃんと動く。

Q3. G4で設計する「役割分担」とはどういうこと？
1. チームメンバーの担当業務を決めること
2. n8nとパソコンの置き場所を決めること
3. AIに考えさせる部分と、機械的に流す部分を分けること ← 正解
4. 有料プランと無料プランを使い分けること
解説：考える仕事はAIに、決まりきった流れは機械に。適材適所の役割分担を設計する。

Q4. このマスのプロンプト例で組もうとしているワークフローはどれ？
1. フォームに問い合わせが入ったら、AIが返信案を作って、Slackの承認チャンネルに投げる ← 正解
2. 毎朝天気予報を調べてメモ帳に保存する
3. SNSの投稿を自動でリツイートし続ける
4. パソコンの電源を毎晩自動で切る
解説：問い合わせ→AIが返信案→Slack承認チャンネルへ。構成図と設定手順までAIに出してもらえば迷わない。

Q5. G4の実践課題として正しいのはどれ？
1. n8nの全機能を暗記する
2. ワークフローを10本同時に組む
3. n8nの解説動画を全部見終える
4. トリガー→AI→通知の最小ワークフローを1本動かす ← 正解
解説：まずは最小のワークフローを1本、実際に動かす。「わぁ、流れた！」の感覚が何より大事。
