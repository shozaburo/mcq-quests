【F8】CodexとClaude Codeの併用・分業 - クイズ（サイト実装分）

Q1. F8で学ぶ分業の考え方として正しいのはどれ？
1. AIエージェントは必ず1社に絞って使うべき
2. 性能テストで勝ったほうだけを使うべき
3. 設計・レビュー・文章はClaude、自律作業・ファイル処理・量産はCodex、と適材適所で分業する ← 正解
4. 日替わりでランダムに使い分けるべき
解説：1社に絞らなくていい。設計・レビュー・文章はClaude、自律作業・ファイル処理・量産はCodex——適材適所の分業。

Q2. F8のプロンプト例が示す作業の流れはどれ？
1. Claudeに設計書レビュー→Codexに実装→Claudeに検品 ← 正解
2. Codexに設計→Codexに実装→Codexに検品
3. Claudeに実装→Codexにレビュー→人間が実装し直す
4. 両方に同じ実装をさせて速いほうを採用する
解説：レビューはClaude、実装はCodex、検品はまたClaude。作る人と見る人を分けるのは品質を守る基本。

Q3. 両方のAIを使う人だけが得られる価値として挙げられているのはどれ？
1. 利用料金が自動的に半額になる
2. 片方の成果物をもう片方に見せる「セカンドオピニオン」 ← 正解
3. 処理速度が2倍になる
4. どちらかが故障しても仕事メールが自動転送される
解説：セカンドオピニオン。片方が作ったものをもう片方に見せると、思い込みや見落としが見つかる。

Q4. 「CodexとClaude、どちらが優秀か」で迷って止まったときの対処はどれ？
1. 決着がつくまで比較記事を読み込む
2. 優秀と言われるまでどちらも使わない
3. 毎回コイントスで決める
4. 優劣ではなく持ち味と考え、まず「作るのはCodex・見るのはClaude」から試す ← 正解
解説：優劣論争はいったん置いて、「作るのはCodex・見るのはClaude」から試す。使えば持ち味は体で分かる。

Q5. F8の実践課題はどれ？
1. 両方のAIの機能比較表を完成させる
2. どちらか一方を解約して使うほうを決める
3. 1つの成果物を「片方に作らせ、もう片方にレビューさせる」で仕上げる ← 正解
4. 2つのAIに同時に同じ質問をして答え合わせをする
解説：1つの成果物を片方に作らせもう片方にレビューさせて仕上げる。分業のうまみを味わえば現場が二馬力になる。
