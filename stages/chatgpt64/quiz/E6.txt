【E6】スラッシュコマンドの基本とショートカット - クイズ（サイト実装分）

Q1. スラッシュコマンドとは、どんな操作のこと？
1. 画面を斜めにスワイプする操作
2. 「/」から始まる短い命令で、よく使う操作を一発で呼び出す操作 ← 正解
3. キーボードを2台つないで入力する操作
4. 音声でAIを呼び出す操作
解説：「/」で始まる短い命令のこと。よく使う操作を一発で呼び出せる。長い文章を毎回打つ手間を消す道具。

Q2. スラッシュコマンドで呼び出せる操作の例として、設計書に挙がっているのはどれ？
1. PCの電源オフ・再起動・初期化
2. 印刷・スキャン・FAX送信
3. 音楽再生・動画編集・写真加工
4. 設定変更・状態確認・定型実行 ← 正解
解説：設定変更、状態確認、定型実行。日々くり返す操作ほど、コマンド一発の恩恵が大きい。

Q3. 「コマンドを覚えようとして挫折…」への正しい対処はどれ？
1. 一覧表を印刷して壁に貼り、全部暗記する
2. 覚えられないので使うのをやめる
3. 全部は覚えない。自分の頻出3つだけ体に入れる ← 正解
4. 毎朝テストして自分を追い込む
解説：全部覚えなくていい、頻出3つだけ。それで日常の9割は回る。手の抜きどころも実力のうち。

Q4. どんなコマンドがあるか知りたいとき、設計書に沿った頼み方はどれ？
1. 「使えるスラッシュコマンドの一覧と、それぞれいつ使うのかを初心者向けに教えて」 ← 正解
2. 「コマンドを自分で作って勝手に増やして」
3. 「コマンドを全部無効にして」
4. 「上級者向けの隠しコマンドだけ教えて」
解説：一覧と「いつ使うか」をセットで聞くのがコツ。名前だけでは使いどころが分からない。

Q5. スラッシュコマンドを使いこなす利点はどれ？
1. AIの回答の精度そのものが上がる
2. 月額料金が安くなる
3. PCの動作が軽くなる
4. 長い指示文を打たずに済み、よく使う操作が一瞬で終わる ← 正解
解説：利点はシンプル、速いこと。長い指示文を打つ時間が消えて、よく使う操作が一瞬で終わる。
