【G3】外部データの自動集計・レポート化 - クイズ（サイト実装分）

Q1. G3で目指す仕事の流れはどれ？
1. 「取ってくる→まとめる→報告書にする」を人手ゼロでつなげる ← 正解
2. データを手作業でコピペしてから、AIに清書だけ頼む
3. 報告書だけAIに書かせて、データ集めは自分でやる
4. データを印刷して紙のファイルに綴じる
解説：「取ってくる→まとめる→報告書にする」を人手ゼロでつなげる。バラバラだった作業がひとつの流れになる。

Q2. このマスのプロンプト例として正しいのはどれ？
1. 「売上データを画面に表示するだけして」
2. 「Driveのファイルを全部別のフォルダにコピーして」
3. 「Driveの売上フォルダから今月の全ファイルを取得して、月次サマリーを作って、Word報告書として保存して」 ← 正解
4. 「売上フォルダの中身を全部削除して」
解説：取得→サマリー作成→Word保存、3つを1文で頼む。一連の流れをまとめて渡すとAIが最後までやり切る。

Q3. 元データの置き場が散らかっていて集計に失敗するとき、効いてくるのはどれ？
1. もっと高性能なパソコンに買い替えること
2. A6/E7で学んだ「フォルダの型」を整えておくこと ← 正解
3. データを全部1つのファイルにまとめてしまうこと
4. 集計をあきらめて手作業に戻ること
解説：置き場が整っていればAIも迷わずデータを取ってこられる。片付けが自動化を助ける。

Q4. G3で使う機能の組み合わせとして正しいのはどれ？
1. 画像生成＋音声入力＋翻訳
2. ブラウザ操作＋動画編集
3. スケジュール機能だけ
4. MCP＋データ集計＋ファイル生成の連結 ← 正解
解説：MCPで取ってきて、集計して、ファイルにする。3つを連結させると力が何倍にもなる。

Q5. G3の実践課題として設計書に挙がっているのはどれ？
1. レポートのテンプレートを100種類集める
2. 毎日手作業でレポートを書き写す
3. 外部ツールのデータから月次レポートを1本自動生成する ← 正解
4. 他社のレポートをそのままコピーして使う
解説：外部データから月次レポートを1本自動で作る。1本できれば、あとは横に増やすだけ。
