【B7】複雑なタスクを複数ステップに分割し、Workモードで最後までやり切らせる設計 - クイズ（サイト実装分）

Q1. 複数工程の仕事をWorkに任せるときの設計のポイントはどれ？
1. 「調査→整理→資料化」のような工程を明示して渡す ← 正解
2. 工程は伝えず「いい感じにやって」と任せる
3. 工程ごとに別のAIサービスを使い分ける
4. 最初の工程だけ伝えて、あとは様子を見る
解説：仕事の手順書を先に渡すイメージ。工程が見えていれば最後までコツコツ走れる。

Q2. このマスのプロンプト例の構成として正しいのはどれ？
1. ④の共有文章だけを最初に作らせる
2. 「①価格をWebで調査 ②比較表に整理 ③わかったことを3点に要約 ④社内共有用の文章を作成」と番号つきで手順を示す ← 正解
3. 手順は示さず結論だけ要求する
4. ①と④だけ伝えて途中は省略する
解説：番号つきの手順がそのまま指示になる。仕事の流れをそのまま言葉にして渡すだけ。

Q3. 丸投げの粒度が正しいと、Workはどうなる？
1. 作業速度が2倍になる
2. 料金が安くなる
3. 追加の質問を一切しなくなる
4. 途中で止まらず、最後まで走り切ってくれる ← 正解
解説：任せ方が曖昧だと途中で迷子になるが、粒度が合っていれば完走してくれる。

Q4. 作業の途中で方向がズレていくときの対処はどれ？
1. 最初からやり直しを命じる
2. ズレたまま最後まで待つ
3. 「各ステップの成果を見せながら進めて」と指示に入れておく ← 正解
4. 工程の数を1つに減らす
解説：ステップごとに成果を見せてもらえば、ズレた瞬間に軌道修正できる。

Q5. B7で学ぶ設計力は、どんな力につながる？
1. AIを使わずに自分で速く作業する力
2. 複数工程の実務を、途中で止まらない形でAIに任せ切る力 ← 正解
3. プログラミング言語を書く力
4. 会議の司会をする力
解説：単発の作業を頼むのがB1〜B4、まとまった仕事を任せ切るのがB7。
