【D4】チームでのGPTs共有とアクセス管理 - クイズ（サイト実装分）

Q1. GPTsをチームに共有する目的として、このマスに沿うのはどれ？
1. 自分のGPTsを自慢するため
2. 共有するとAIの性能が上がるため
3. 「自分が楽になる」を「チーム全員が楽になる」に広げるため ← 正解
4. 共有しないとGPTsが削除されてしまうため
解説：便利なGPTsを自分だけで使うのはもったいない。共有すれば「自分が楽」が「みんなが楽」に広がる。

Q2. GPTsの公開範囲の設定として、このマスに挙がっている組み合わせはどれ？
1. 公開・限定公開・下書き
2. 自分のみ／リンクを知っている人／組織内 ← 正解
3. 無料・有料・サブスク
4. 国内のみ・海外のみ・全世界
解説：自分のみ・リンク共有・組織内の3段階。誰にどこまで見せるか、共有の前に決めておく。

Q3. 共有前のプロンプト例として、このマスに沿うのはどれ？
1. 「このGPTsをもっと面白くして」
2. 「このGPTsの宣伝文を作って」
3. 「このGPTsの利用回数を集計して」
4. 「共有する前に、社外秘情報が含まれていないか、共有範囲の設定はどうすべきかチェックリストを作って」 ← 正解
解説：共有前に「社外秘が入っていないか」をチェックリストで確認。ナレッジごと相手に渡る可能性があるので慎重に。

Q4. 「共有したのに使われない」ときの対策はどれ？
1. 「どんな時に・何を入れると・何が出るか」の1枚案内を添える ← 正解
2. 毎日使うように業務命令を出す
3. 使われるまで何度もリンクを送り続ける
4. 共有をやめて自分だけで使う
解説：使ってもらうには案内が肝心。「どんな時に・何を入れると・何が出るか」の1枚で、ぐっと使われるようになる。

Q5. D4の実践課題はどれ？
1. GPTsの共有機能の説明を読むだけでよい
2. 共有リンクを作るだけで、渡さなくてよい
3. GPTsを1体チーム（または家族・知人）に共有して使ってもらう ← 正解
4. 他人が作ったGPTsを10体集める
解説：実際に1体、チームや家族・知人に共有して使ってもらう。思わぬ改善点も見つかる。
