【F3】LP・プロトタイプをCodexに構築させる - クイズ（サイト実装分）

Q1. F3がC6〜C8の「ページを作る」から一歩進んでいる点はどれ？
1. ページのデザインがきれいになる
2. フォームや計算機能など「動く仕組み」を持つものを作る ← 正解
3. ページの枚数を増やして大規模サイトにする
4. 英語のページも作れるようになる
解説：見た目だけでなく「動く仕組み」を作るのがF3。ページが「読む物」から「使う道具」に変わる。

Q2. 料金シミュレーター付きLPを頼むとき、F3の例に沿うプロンプトはどれ？
1. 「かっこいいLPをとにかくたくさん作って」
2. 「料金シミュレーターの作り方を論文形式で解説して」
3. 「他社のLPをコピーして作って」
4. 「料金シミュレーター付きLPを作って。入力は3項目、結果表示はその場で。デザインはスマホ最優先」 ← 正解
解説：具体的な条件を短く渡すのがいい注文。要件がはっきりしていると仕上がりが早い。

Q3. 「要望を一度に全部盛ってしまう」つまずきへの対処はどれ？
1. まず動く最小版を作り、触ってみてから追加する ← 正解
2. 要望を全部盛った完璧な仕様書を先に完成させる
3. 機能はAIに全部おまかせで決めてもらう
4. 要望は口頭で伝えて記録に残さない
解説：まず動く最小版、触ってから追加が結局いちばん速い。小さく作って育てるのが職人流。

Q4. F3で学ぶことの核心はどれ？
1. プログラミング言語を1つマスターすること
2. デザインソフトの操作を覚えること
3. コードを書けなくても、日本語の要望だけでCodexに試作品を構築させられること ← 正解
4. エンジニアを雇うときの面接方法
解説：コードが書けなくても日本語の要望だけでCodexが作ってくれる。仕事は「何がほしいか」をはっきりさせること。

Q5. F3の実践課題はどれ？
1. HTMLの教科書を1冊読み終える
2. 動く仕掛け（フォーム・計算・診断など）付きのページを1つ作る ← 正解
3. LPのデザイン案を10個スケッチする
4. プログラミングスクールの資料請求をする
解説：「動く仕掛け」入りのページを1つ作ってみる。自分の商売に使えるものにすると実戦投入できる。
