【G6】定期実行タスクで毎日の業務を自動化 - クイズ（サイト実装分）

Q1. G6の定期実行は、B6のPulseからどう進化したもの？
1. 通知の回数が増えただけのもの
2. 受け取る情報の種類が変わっただけのもの
3. 「受け取る自動化」から「作業そのものを毎日自動でやらせる」へ進化したもの ← 正解
4. スマホでも通知が見られるようになっただけのもの
解説：B6は情報を「受け取る」自動化、G6は「作業そのもの」を毎日やらせる。ひとつ上の自動化。

Q2. このマスのプロンプト例で毎朝7時に自動実行させる内容はどれ？
1. ①ニュースを読み上げ ②天気を通知 ③音楽を再生
2. ①SNSに投稿 ②メールを全削除 ③PCを再起動
3. ①ファイルを全部圧縮 ②ゴミ箱を空に ③画面をロック
4. ①受注メールを集計 ②Excelの管理表を更新 ③今日の要対応リストを通知 ← 正解
解説：集計・更新・通知の朝ルーティンを3つまとめてお任せ。朝いちの1時間が浮く。

Q3. 定期実行タスクを設定するとき、必ずセットで設定すべきものはどれ？
1. 「失敗したら必ず通知」の設定 ← 正解
2. 実行結果を毎回印刷する設定
3. 深夜にもう一度実行する設定
4. 実行のたびにパスワードを変える設定
解説：「失敗したら必ず通知」を必ずセットに。いちばん怖いのは失敗に気づかない「無音の失敗」。

Q4. G6で自動化の対象にしていく仕事はどれ？
1. 一生に一度しかやらない特別な仕事
2. 毎朝のデータ集計・ファイル整理・バックアップなど「私がやらなくても回る仕事」 ← 正解
3. その場の判断が毎回必要な交渉ごと
4. お客様と直接顔を合わせる接客
解説：狙い目は毎日くり返す「私がやらなくても回る仕事」。1つずつ手放していく。

Q5. G6の実践課題として正しいのはどれ？
1. タスクを設定だけして実行はしない
2. 10本のタスクを一気に設定する
3. 毎日の定期実行タスクを1本設定し、3日連続で成功させる ← 正解
4. 手動実行を3日続けてから考える
解説：定期実行タスクを1本、3日連続で成功させる。3日続けば、それはもう立派な仕組み。
