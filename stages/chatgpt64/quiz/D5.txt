【D5】Skill（手順書）の概念と作り方 - クイズ（サイト実装分）

Q1. GPTsとSkillの関係を表す、このマスの説明はどれ？
1. GPTsが「手順書」で、Skillが「人格」
2. GPTsが「人格」なら、Skillは「手順書」 ← 正解
3. GPTsとSkillはまったく同じもの
4. SkillはGPTsの古い名前
解説：GPTsが「人格」、Skillが「手順書」。キャラクターと台本みたいな関係。手順書どおりなら迷わず動ける。

Q2. Skillに書き込む内容の組み合わせとして、このマスに沿うのはどれ？
1. 感想・評価・改善要望
2. 料金・納期・担当者
3. 目標・夢・座右の銘
4. 手順・判断基準・注意点 ← 正解
解説：書くのは手順・判断基準・注意点の3つ。作業のやり方をまるごとAIエージェントに覚えさせるのがSkill。

Q3. Skillを書き起こすプロンプト例として、このマスに沿うのはどれ？
1. 「私が毎週やっている定型業務の手順を聞き取って、AIエージェントが実行できるSkill（手順書）の形式に書き起こして」 ← 正解
2. 「世界で人気のSkillを一覧にして」
3. 「Skillという言葉の語源を調べて」
4. 「私の業務をすべて廃止する計画を立てて」
解説：自分で書こうとせず、AIに手順を聞き取らせてSkillの形式に書き起こさせる。インタビューされているうちに手順書ができる。

Q4. Skill作りでよくある失敗と、その対策はどれ？
1. 丁寧に書きすぎて失敗 → できるだけ短く省略して書く
2. 英語で書いて失敗 → 必ず専門用語で書く
3. 手順を省略して書いて失敗 → 「新人に教えるつもり」で判断基準まで書く ← 正解
4. 紙に書いて失敗 → 高価な専用ソフトを買う
解説：「これくらい分かるでしょ」の省略が失敗のもと。新人に教えるつもりで、判断基準まで書く。

Q5. 最初のSkillの題材として、このマスが勧めているのはどれ？
1. 年に1回あるかないかの特別な仕事
2. 毎週やっている定型業務 ← 正解
3. まだやったことのない新しい仕事
4. 他人の担当業務
解説：選ぶのは毎週やってる定型業務。手順をよく知っていて回数が多い仕事ほど、Skill化の効果が大きい。
