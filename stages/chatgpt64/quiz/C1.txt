【C1】画像生成（GPT-Image 2.0）の基礎と、文字入り画像・ロゴの作成 - クイズ（サイト実装分）

Q1. GPT-Image 2.0による画像生成が実務でとくに価値を発揮するのはどんな場面？
1. 日本語の文字入りバナーやロゴなど、文字が崩れない画像づくり ← 正解
2. 動画の撮影と編集
3. パソコンの動作を速くすること
4. 文章の誤字チェック
解説：SNSの告知もチラシもロゴも、文字が読めてこそ仕事になる。

Q2. 告知バナーを頼むプロンプトとして、設計書の型に沿っているのはどれ？
1. 「いい感じのバナーを作って」とだけ伝える
2. 文字は入れずに後から自分で貼り付ける前提で頼む
3. 「『春の感謝祭 3/20-31』の文字を入れた告知バナーを、明るい雰囲気・横長（16:9）で」と頼む ← 正解
4. 英語に翻訳してから頼む
解説：入れたい文字・雰囲気・アスペクト比まで言葉にするのが頼み方の型。

Q3. 生成した画像の文字が微妙に化けてしまったとき、正しい対処はどれ？
1. あきらめて文字なしの画像で妥協する
2. 入れたい文字列を「」で明示し、生成後に文字だけ修正指示する ← 正解
3. 何度も同じプロンプトを送り続ける
4. 画像編集ソフトを別途購入する
解説：文字は「」で示し、化けたら文字だけ直す。全部やり直す必要はない。

Q4. 用途に合わせた頼み方として、C1で身につけるのはどんな考え方？
1. どんな用途でも同じプロンプトを使い回す
2. 用途は伝えず、サイズだけ指定する
3. 画像はすべて正方形で統一する
4. SNS・チラシ・ロゴなど用途別に頼み方を変える ← 正解
解説：用途を伝えれば、AIはその舞台に合う衣装を選んでくれる。

Q5. C1の実践課題はどれ？
1. 他社のロゴを集めて研究する
2. 画像生成の歴史をレポートにまとめる
3. 自分の事業の告知バナーを1枚、文字入りで完成させる ← 正解
4. 画像を100枚生成して比べる
解説：明日そのまま使える1枚を作る。実務に直結してこそ学びは輝く。
