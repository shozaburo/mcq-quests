【D7】複数Skillを組み合わせた連続タスクの実行 - クイズ（サイト実装分）

Q1. D7で学ぶ発想として、このマスに沿うのはどれ？
1. Skillを1つずつ手動で切り替えながら使う
2. Skillの数をできるだけ減らす
3. Skillを数珠つなぎにして、一連の業務フローを1指示で流す ← 正解
4. Skillを毎回ゼロから書き直す
解説：Skillを数珠つなぎにして1指示で最後まで流す。部品を組み合わせて仕事のラインを作る発想。

Q2. 3つのSkillをつなぐプロンプト例で指定されているのはどれ？
1. 「前のSkillの成果物を次のSkillの入力にして」 ← 正解
2. 「3つのSkillを同時にバラバラに実行して」
3. 「いちばん速いSkillだけ実行して」
4. 「Skillの実行順はAIが好きに決めて」
解説：「前の成果物を次の入力に」がバトンリレーの合言葉。結果が次へ次へと流れていく。

Q3. Skill間で受け渡しがうまくいかないときの対策はどれ？
1. Skillの数を1つに減らす
2. 受け渡しは毎回手作業でコピペする
3. つなぐのをあきらめて別々に実行する
4. 各Skillの「出力形式」と「入力形式」を揃えて定義しておく ← 正解
解説：バトンの形が揃っていないとリレーは落とす。出力形式と入力形式を揃えておくのが連携のコツ。

Q4. このマスで例に挙がっている連続タスクの流れはどれ？
1. 撮影→編集→公開
2. 調査→分析→資料化 ← 正解
3. 受注→請求→入金
4. 採用→研修→配属
解説：「競合調査」→「比較分析」→「報告書作成」の3連コンボ。花から花へ蜜をつなぐイメージ。

Q5. D7の実践課題はどれ？
1. Skillの連携図を眺めるだけでよい
2. Skillを10本以上新しく書く
3. 2つ以上のSkillをつないだ連続タスクを1本完走させる ← 正解
4. 連続タスクの計画書だけ作って実行はしない
解説：2つ以上のSkillをつないで1本最後まで完走。小さなリレーでいいから、まず1本走り切ろう。
