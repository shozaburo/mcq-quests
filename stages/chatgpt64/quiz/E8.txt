【E8】初めての自律作業（ファイル整理・要約） - クイズ（サイト実装分）

Q1. E8で体験する自律作業の流れとして正しいのはどれ？
1. 実行→提案→報告→承認
2. 承認→報告→提案→実行
3. 報告→実行→承認→提案
4. 分類の提案→承認→実行→結果報告 ← 正解
解説：流れは、提案→承認→実行→報告。AIが案を出し、あなたが許可し、AIが動き、最後に報告する。

Q2. 「いきなり大事なフォルダでやる」のが危ない理由と、正しい始め方はどれ？
1. 危なくないので、大事なフォルダから始めてよい
2. 失敗したら取り返しがつかないので、まずコピーした練習用フォルダで試す ← 正解
3. 大事なフォルダは全部クラウドに逃がしてから全自動で実行する
4. フォルダではなくPC全体を対象にする方が安全
解説：まずコピーした練習用フォルダで。しくじっても元が残っていれば笑い話で済む。信頼はそれからで遅くない。

Q3. このマスのプロンプト例として、設計書に沿うのはどれ？
1. 「このフォルダのファイルを内容ごとに分類する案を出して。私がOKしたら実行して、最後に何をどう動かしたか報告書を書いて」 ← 正解
2. 「このフォルダを黙って全部整理しておいて」
3. 「このフォルダのファイルを全部削除して空にして」
4. 「フォルダの整理方法を長文で解説だけして」
解説：案を出させて、OKしたら実行、最後に報告書。ひとつの指示に安全弁が3つ入っている。

Q4. 最後に「報告書」を書かせる意味はどれ？
1. 報告書を書かせると料金が安くなるから
2. 報告書がないとファイルが開けなくなるから
3. 何をどう動かしたかを後から確認でき、任せた作業を人間が把握できるから ← 正解
4. 報告書は飾りで、特に意味はない
解説：任せっぱなしにしない、が肝。何をどこへ動かしたか報告させれば、あとから自分の目で確かめられる。

Q5. E8の位置づけとして正しいのはどれ？
1. ステージEの中で飛ばしてもよいおまけのマス
2. ステージEの卒業試験。自分のPCの上でAIが実際に手を動かす瞬間を見るマス ← 正解
3. ステージFの予習用の座学マス
4. 設定だけして何も実行しないマス
解説：ここはステージEの卒業試験。自分のPCの上で、AIが実際に手を動かす瞬間を自分の目で見る。
