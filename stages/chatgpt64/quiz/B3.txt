【B3】ファイル読み込み（PDF/Word等）と内容に基づく精度の高いQ&A - クイズ（サイト実装分）

Q1. このマスでできるようになることはどれ？
1. 契約書やマニュアルをアップロードし、「この資料の中から」対話で答えを探せる ← 正解
2. 契約書を自動で締結できる
3. 資料を読まずに内容を予知できる
4. 紙の書類が自動でスキャンされる
解説：探すのが面倒な書類こそ、読み込ませて聞くのがいちばん早い。

Q2. 契約書から必要な箇所を探すプロンプトとして、このマスの例に沿うのはどれ？
1. 「この契約書を短くまとめて」
2. 「この契約書の問題点を推測して」
3. 「この契約書の中で、解約に関する条項をすべて抜き出して。該当ページ・条番号も添えて」 ← 正解
4. 「この契約書を英語に翻訳して」
解説：「すべて抜き出して」で漏れを防ぎ、「ページ・条番号も添えて」で原本と照合できるようにする。

Q3. 資料にない内容まで推測で答えてしまうときの対処はどれ？
1. 推測かどうかを毎回自分で見抜く
2. 資料を2回アップロードする
3. 質問を短くする
4. 「資料に書かれていないことは『記載なし』と答えて」と縛る ← 正解
解説：先にルールを渡しておけば、AIは資料の外へ勝手に出なくなる。

Q4. このマスで読み込ませる書類として想定されているのはどれ？
1. 白紙のテンプレート
2. 契約書・マニュアル・規程集など「探すのが面倒な書類」 ← 正解
3. 他社の社外秘資料
4. 手書きの日記
解説：分厚くて探すのに苦労する書類が狙い目。読み込ませておけば必要なときに聞くだけ。

Q5. このマスで使う機能はどれ？
1. スケジュール実行（Pulse）
2. 画像生成
3. ファイルアップロード（PDF/Word/テキスト）と文書内Q&A ← 正解
4. ファイル生成（Word・Excel）
解説：PDFやWordをアップロードして、その中身について質問する組み合わせが基本形。
