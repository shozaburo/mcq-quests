【D6】Skillで定型タスク（Excel集計・資料作成）を自動化 - クイズ（サイト実装分）

Q1. D6の狙いとして、このマスに沿うのはどれ？
1. 毎週のExcel集計などの定型タスクを「Skill実行1回」で終わらせる ← 正解
2. Excelの関数を手作業で覚える
3. 集計作業を外部の業者に発注する
4. 定型タスクの回数を増やす
解説：D5で書いた手順書をいよいよ実戦投入。毎週のExcel集計が「Skill実行1回」で終わる体験ができる。

Q2. プロンプト例「Skill『週次売上集計』を、今週のファイルで実行して」に添えられている工夫はどれ？
1. 「できるだけ急いで出して」と急かす
2. 「結果は誰にも見せないで」と指示する
3. 「先週と形式が揃っているか自分で検算してから出して」と頼む ← 正解
4. 「好きな形式に自由にアレンジして」と任せる
解説：「自分で検算してから出して」の一言がプロの頼み方。AI自身に確かめさせると仕上がりが安定する。

Q3. たまに例外データでSkillの結果が崩れるとき、正しい対処はどれ？
1. Skillの利用をあきらめて手作業に戻る
2. 例外時の対応（「不明な行は別シートに退避」等）をSkillに追記して育てる ← 正解
3. 例外データを見なかったことにする
4. 毎回すべて手作業でチェックし直す
解説：例外でつまずいたら、その対応をSkillに1行追記。Skillは追記のたびに賢くなる。

Q4. Skillの効果を実感するために、このマスが勧めている方法はどれ？
1. AIに「すごい」と言わせる
2. 利用回数をカウントする
3. 同僚の作業時間と比べる
4. 手作業でやった場合と時間を比較する ← 正解
解説：手作業なら30分、Skillなら1分——この差を自分の目で確かめる。数字で見ると実感できる。

1. Skill実行／ChatGPT Work／ファイル生成 ← 正解
2. 画像生成／音声入力／翻訳

4. 動画編集／配信／字幕
