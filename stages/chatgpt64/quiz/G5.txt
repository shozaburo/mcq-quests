【G5】SNS完全自動運用システムの構築 - クイズ（サイト実装分）

Q1. G5で作るSNS自動運用ラインの流れとして正しいのはどれ？
1. 投稿→リサーチ→画像生成→本文生成の順で回す
2. ネタのリサーチ→本文生成→画像生成→予約投稿までを自動ラインにする ← 正解
3. 画像だけを毎日自動生成して保存する
4. 他人の投稿を自動でコピーして再投稿する
解説：リサーチ→本文→画像→予約投稿まで、ぜんぶひとつのライン。制作と自動化の合体技。

Q2. SNS自動運用ラインに必ず設けるべきものはどれ？
1. 投稿前に人間が承認する「関所」 ← 正解
2. 投稿数を最大化する高速連続投稿の仕組み
3. 誰にも見られないようにする鍵アカウント設定
4. AIが勝手に返信までする全自動返信機能
解説：投稿前に人間が承認する「関所」を必ず。世に出る前にあなたの目でひと目確認する。

Q3. 「人間の承認」を挟むことについて、正しい考え方はどれ？
1. 自動化の意味がなくなるので入れないほうがいい
2. AIの性能が低いときだけ入れる応急処置である
3. 手抜きではなく設計であり、炎上リスクをここで消す ← 正解
4. 承認は月に1回まとめてやれば十分である
解説：承認は手抜きではなく設計。全自動投稿で事故ってからでは遅い。炎上リスクはこの関所で消す。

Q4. G5はどのステージとどのステージの合体技？
1. ステージA（基本操作）×ステージB（日常業務）
2. ステージD（データ分析）×ステージE（開発）
3. ステージF（チーム連携）×ステージH（自律化）
4. ステージC（コンテンツ制作）×ステージG（自動化） ← 正解
解説：ステージCの制作と、ステージGの自動化の合体技。作る力と流す力、両方そろって自動運用に。

Q5. このマスのプロンプト例にある自動化の設計として正しい順序はどれ？
1. ①トレンドリサーチ ②本文と画像生成 ③下書きを私に承認依頼 ④承認後に予約投稿 ← 正解
2. ①予約投稿 ②承認依頼 ③本文生成 ④リサーチ
3. ①本文生成 ②即時投稿 ③リサーチ ④画像生成
4. ①画像生成 ②リサーチ ③投稿 ④本文生成
解説：リサーチ→生成→承認依頼→承認後に予約投稿。「承認してから投稿」の順番が崩れないことが大事。
