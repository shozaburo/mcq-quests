【C2】プロンプトを使った画像デザインの微調整・テイストの統一 - クイズ（サイト実装分）

Q1. C2で学ぶ画像づくりの姿勢を表す言葉として正しいのはどれ？
1. ガチャではなく「ディレクション」で画像を作る ← 正解
2. 運まかせで良い1枚が出るまで引き続ける
3. 最初の1枚で必ず完成させる
4. 画像はプロのデザイナーにしか作れない
解説：あなたが監督になって指示を重ねるディレクション。「ここだけ変えて」を重ねる。

Q2. 画像の一部だけ変えたいとき、設計書のプロンプト例に沿った頼み方はどれ？
1. 「もっと良くして」と全体の改善を頼む
2. 「全部作り直して」と最初からやり直す
3. 「この画像の雰囲気はそのままで、背景だけ夕方に変えて」と頼む ← 正解
4. 画像を送らずに口頭の記憶だけで説明する
解説：変えたい場所を一点だけ指すのがコツ。部分修正はピンポイントで。

Q3. 今後の画像のテイストを統一したいとき、有効な頼み方はどれ？
1. 毎回ゼロから感覚で頼む
2. 「この画像のテイストを再現できるプロンプト（スタイル指示文）を書き出して」と頼む ← 正解
3. 色の名前だけを毎回伝える
4. 統一はあきらめて多様性を楽しむ
解説：画風をAI自身に言語化させる。そのスタイル指示文が専用の絵の具箱になる。

Q4. 修正を頼むたびに別物の画像になってしまうとき、正しい対処はどれ？
1. 修正回数を1回までに制限する
2. 毎回ちがう言い回しで頼み直す
3. 画像生成をやめて写真素材を買う
4. 変えたい要素だけを指示し「他は維持して」と必ず添える ← 正解
解説：「他は維持して」が命綱。別物になる悲劇を防げる。

Q5. C2の実践課題はどれ？
1. 1枚の画像を3回の修正指示で狙い通りに仕上げる ← 正解
2. 10種類のちがう画風で10枚作る
3. 他人の作った画像を批評する
4. 修正なしの一発勝負で完成させる
解説：回数を決めて一手一手を考えて指示する。ディレクションの練習になる。
