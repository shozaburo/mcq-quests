【B4】バラバラの情報を表やマークダウン形式に整理・抽出する方法 - クイズ（サイト実装分）

Q1. このマスで学ぶ「AIが最も得意とする仕事のひとつ」はどれ？
1. 表の色やデザインを整えること
2. 情報を暗記して覚えておくこと
3. 文章を長く書き足すこと
4. 非構造データ（バラバラの情報）を構造データ（表）に変換すること ← 正解
解説：メールやメモから必要な項目だけ拾って表に組み直す、時間を食う地味な作業こそ得意分野。

Q2. メールのやり取りから案件情報を整理するプロンプトの例はどれ？
1. 「以下のメールを削除して」
2. 「以下のメールのやり取りから、案件名・相手・金額・期日・次のアクションを表にまとめて」 ← 正解
3. 「以下のメールに返信して」
4. 「以下のメールを転送して」
解説：拾ってほしい項目を並べて「表にまとめて」と頼むだけで全体像が見える。

Q3. 欲しい列が表に出てこないとき、確実な手はどれ？
1. 先に列名（ヘッダー）を自分で指定する ← 正解
2. 何度も同じ指示を繰り返す
3. 表ではなく文章でまとめてもらう
4. 情報量を減らして渡す
解説：先に列の設計図を渡せば、中身はこっちが詰める。

Q4. このマスで表に変換する「素材」として挙がっているのはどれ？
1. すでに完成しているExcelの表
2. 画像や動画のファイル
3. メールの文面・メモ・議事録などのバラバラな情報 ← 正解
4. Webサイトのデザインデータ
解説：形になっていない文章のかたまりが素材。「文章→表」の変換を覚える。

Q5. 情報を表形式に整理することの実務上の利点はどれ？
1. 必要な項目が一覧になり、抜け漏れの確認や共有がしやすくなる ← 正解
2. 元のメールが自動で削除されて容量が空く
3. 表にすると情報が自動で最新に更新される
4. 文章より必ずファイルサイズが小さくなる
解説：バラバラのままだと見落とすものも、表に並べば一目でわかる。
