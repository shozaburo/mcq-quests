【E2】デスクトップアプリ導入とワークスペース作成 - クイズ（サイト実装分）

Q1. ワークスペース（作業用フォルダ）とは何のこと？
1. PCの空き容量を増やすための圧縮フォルダ
2. AIに触らせる範囲を区切った、AI専用の作業机になるフォルダ ← 正解
3. クラウド上の共有ドライブのこと
4. アプリのインストール先フォルダのこと
解説：ワークスペースは「AI専用の作業机」。ここだけ触っていい、と範囲を決めた場所。机を決めるのが安全に任せる第一歩。

Q2. 「PC全体をAIの対象にしたら、なんだか不安…」への対処はどれ？
1. 不安なのでCodexの利用自体をやめる
2. PC全体を対象にしたまま、祈りながら使う
3. 大事なファイルを全部削除してから使う
4. 専用フォルダを1つ作り、そこだけを作業場に指定する ← 正解
解説：専用フォルダを1つ作ってそこだけを作業場に。家全体を開放せず、客間を一部屋用意すれば十分。

Q3. ワークスペースを作った直後、最初に投げるプロンプトはどれ？
1. 「このワークスペースの中を見て、どんなファイルがあるか一覧にして。まだ何も変更しないで」 ← 正解
2. 「このワークスペースのファイルを全部リネームして」
3. 「不要そうなファイルを判断して削除して」
4. 「フォルダごと圧縮してバックアップして」
解説：最初は「見るだけ」。一覧にさせて、まだ何も変更させない。まず顔合わせから。

Q4. 「まだ何も変更しないで」と一言添える狙いはどれ？
1. AIの返事を速くするため
2. 料金を安くするため
3. 読み取りだけに留めて、AIの動きを安全に確かめるため ← 正解
4. ファイルを自動でバックアップするため
解説：読み取りのみが最初の作法。AIが何をどう見るのか、安全な状態で確かめられる。

Q5. E2がステージEの序盤に置かれている理由はどれ？
1. 一番難しい内容を先に済ませるため
2. 安全に任せるための「作業机」を先に用意してから、次の学びに進むため ← 正解
3. 他のマスとは無関係の独立した作業だから
4. アプリの宣伝が目的だから
解説：机がなければ仕事は始まらない。先にワークスペースを整えるから、この先も安心して試せる。
