【G7】チームでのプラグイン・MCP共有と管理 - クイズ（サイト実装分）

Q1. G7で防ごうとしている「属人化」とはどんな状態？
1. 作った人しか直せない状態 ← 正解
2. チーム全員が同じ作業をしている状態
3. 誰も自動化を使っていない状態
4. AIが人の代わりに雇われている状態
解説：「作った人しか直せない」状態が属人化。作った人が休むと止まる仕組みは危うい。みんなで支えられる形に。

Q2. 自分の環境依存で他の人が動かせないとき、最短の対処はどれ？
1. 他の人のPCを自分と同じ機種に買い替えてもらう
2. 自分が全員のPCで代わりに設定して回る
3. 手順書はAIに書かせて、別の1人に試してもらう ← 正解
4. 共有をあきらめて自分だけで使い続ける
解説：手順書はAIに書かせて別の1人に試してもらう。自分では気づけない環境固有の前提を見つけてくれる。

Q3. このマスのプロンプト例として正しいのはどれ？
1. 「この自動化設定を誰にも真似できないように暗号化して」
2. 「チームメンバーの評価レポートを作って」
3. 「自動化の説明は口頭で済ませたいので要点だけ暗記させて」
4. 「この自動化設定をチームメンバーが再現するためのセットアップ手順書を作って。つまずきそうな箇所に注意書きを入れて」 ← 正解
解説：再現用の手順書を、つまずきポイントの注意書き入りで。読む人の目線で先回りすると質問の嵐にならない。

Q4. G7で学ぶ内容の組み合わせとして正しいのはどれ？
1. 画像生成のコツとSNSのバズらせ方
2. MCPサーバー・設定の共有方法と、権限・アカウントの管理 ← 正解
3. パソコンの分解と修理の方法
4. 経理ソフトの仕訳入力の方法
解説：共有方法と、権限・アカウント管理の2本立て。便利さと安全、両方をちゃんと持つ。

Q5. G7の実践課題として正しいのはどれ？
1. チーム全員分の自動化を自分ひとりで作る
2. 自動化の存在をチームに秘密にしておく
3. 自分の自動化1本を、他の人が再現できる手順書つきで共有する ← 正解
4. 手順書だけ作って共有はしない
解説：自分の自動化を1本、手順書つきで共有。あなたの便利が、みんなの便利になる。
