【E4】インテリジェンス（思考の深さ）の調整 - クイズ（サイト実装分）

Q1. 「インテリジェンス（思考の深さ）」の設定とは、どういうもの？
1. AIの知識量を増やす課金オプション
2. 画面の明るさを調整する設定
3. AIの返事の口調を変える設定
4. タスクに応じて、AIにどれくらい深く考えさせるかを調整する設定 ← 正解
解説：考えさせ方の深さを選ぶ設定。単純作業は浅く速く、設計や分析は深くじっくり。

Q2. 浅め（速い）設定が向いている作業はどれ？
1. 事業計画の分析と設計
2. ファイル整理やリネームのような単純作業 ← 正解
3. 複雑な判断が絡む業務フローの見直し
4. 重要な契約書の内容比較
解説：ファイル整理やリネームは浅めでいい。考え込む要素がない作業に深い思考は無駄遣い。

Q3. 逆に、深め設定にすべきなのはどんなとき？
1. とにかく急いでいるとき
2. ファイルをコピーするだけのとき
3. 設計や分析など、判断が絡む仕事のとき ← 正解
4. AIに雑談を頼むとき
解説：判断が絡むものは深めが目安。設計・分析はじっくり考えさせた方がいい答えが返る。

Q4. 「深い設定のまま単純作業をさせて、延々待たされた…」への対処はどれ？
1. 作業の性質に合わせて、単純作業は浅め・判断が絡むものは深めに切り替える ← 正解
2. 待つのも仕事だと割り切る
3. 深い設定を二度と使わない
4. PCを買い替えて速くする
解説：切り替えればいいだけ。整理やリネームは浅め、判断が絡むものは深め。設定見直しの10秒を惜しまない。

Q5. このマスの実践課題として、設計書に沿うのはどれ？
1. 深い設定だけを1週間使い続ける
2. 同じ依頼を浅い/深い設定の両方で実行し、結果と時間の違いを見比べる ← 正解
3. 設定画面のスクリーンショットを集める
4. 一番速いモデルを探すために全モデルを購入する
解説：同じ依頼を浅い/深い両方でやらせて、結果と時間を見比べる。体感した方が早く身につく。
