【B4】Gemini Canvasを用いた文書の構成案作成とリライト技術 - クイズ（サイト実装分）

Q1. 普段のチャット欄ではなくCanvasモードを使うと、文書作成で何が変わるか？
1. 回答が必ず箇条書きだけになる
2. 文書が編集画面に表示され、指示するとその場が書き換わる ← 正解
3. 文字は扱えず図形やグラフしか作れなくなる
4. 作った文書が自動でネット上に公開される
解説：Canvasは文書を編集画面で開き、指示すればその場で書き換わるモードだ。ただのチャットとの違いも知らずに使う者はいねがー！？

Q2. Canvasで作った提案書のうち、導入部分だけを柔らかい印象に直したい。効果的な指示はどれ？
1. 「全部を最初から書き直して」とゼロからやり直させる
2. 何も言わずAIが自分で気づくのを待つ
3. 文書をいったん消してから自分で書き直す
4. 「冒頭の段落を、親しみやすい柔らかい表現にして」と場所と方向を指定する ← 正解
解説：直したい場所と方向を伝えれば、そこだけ的確に直るのだ。ひと部分のために全部を書き直させる無駄遣いはいねがー！？

Q3. Canvasで作った文書に、比較表を入れたい。適切な頼み方はどれ？
1. 「表を追加して」のように指示すれば文書内に挿入できる ← 正解
2. Canvasは文字専用なので表や画像は入れられない
3. 表は一度Wordに移さないと作れない
4. 表や画像は最上位の有料プランでしか使えない
解説：『表を追加』と頼めばその場で入るのだ。できぬと思い込んで手作業に逆戻りするよい子はいねがー！？

Q4. 1万字の報告書を、Canvasを活かして効率よく仕上げる進め方として最も適切なのはどれ？
1. 完成品が一発で出るまで同じ指示を送り続ける
2. まず見出し構成案を作らせ、章ごとにCanvas上でリライトを重ねて仕上げる ← 正解
3. 構成は考えず思いつくまま最後まで一気に書き散らす
4. 全文を紙で下書きしてから清書だけ頼む
解説：構成案づくり→章ごとのリライト、この積み重ねこそCanvasの正道だ。一発完成を夢見て同じガチャを回す者はいねがー！？

Q5. Canvasでリライトを重ねる際、意図せず前の良い表現が消えてしまうのを防ぐ実務的な工夫はどれ？
1. 編集は一切せず最初の文だけを使う
2. 毎回ノートアプリに全文をコピーしてから直す
3. 大きく直す前に現状を別途コピーで残し、直したい範囲を具体的に指定する ← 正解
4. うまくいくまで同じ指示を何度も送り直す
解説：大きく手を入れる前に一度控えを取り、直す範囲を絞って指示するのが賢いやり方だ。上書きで名文を失って泣く者はいねがー！？ガハハ！
