Q1. XLOOKUP関数の引数の並びとして正しいのはどれ？
1. =XLOOKUP(戻り値範囲, 検索キー, 検索範囲)
2. =XLOOKUP(検索キー, 検索範囲, 戻り値範囲) ← 正解
3. =XLOOKUP(検索範囲, 戻り値範囲, 検索キー)
4. =XLOOKUP(列番号, シート名, 検索キー)
解説：「誰を・どこで探し・何を返すか」の順、すなわち検索キー・検索範囲・戻り値範囲だ、クルックー。この呪文を諳んじたまえ。

Q2. 会員台帳では会員番号が右端の列にあり、その左の氏名列を引きたい。VLOOKUPとXLOOKUPの違いとして正しいのは？
1. どちらの関数でも、検索列の左右は関係なく値を返せる
2. VLOOKUPは検索列の右しか返せないが、XLOOKUPは左の列も返せるので対応できる ← 正解
3. 左の列を返すには元データを並べ替えるしかない
4. 数値のキーでは左の列は返せない
解説：VLOOKUPは検索列より右しか見渡せぬ古兵だが、XLOOKUPは左右自在の新王だ、クルックー。列の位置に縛られぬ柔らかさこそ強みなのだよ。

Q3. フォーム回答（会員番号あり）に、会員台帳の住所を付け足したい。XLOOKUPが果たす役割は？
1. 会員番号をキーに台帳を検索し、該当者の住所を引き当てて回答行に付ける ← 正解
2. 回答データを自動で削除して匿名化する
3. 台帳のセルの色を、回答に合わせて塗り替える
4. フォームの設問文を、台帳の言葉に置き換える
解説：会員番号という鍵を頼りに、台帳から正しき相手の住所を引き寄せる、それが名寄せだ、クルックー。散らばった帳面がひとつに結ばれるのだよ。

Q4. XLOOKUPで一致するキーが無いと「#N/A」と表示され、報告書が見苦しい。適切な対処は？
1. エラーは放置して、そのままにする
2. 検索範囲を消してエラーごと消す
3. キー列を削除してしまう
4. IFERRORで包むか、XLOOKUPの「見つからない場合」引数に『該当なし』等を指定する ← 正解
解説：#N/A の泣き言は握りつぶさず、IFERRORか「見つからない場合」引数で受け止めるのだ、クルックー。見苦しさは作法で整えるものなのだよ。

Q5. XLOOKUPの書き方に迷ったとき、講座で勧められている現実的な手はどれ？
1. 関数をあきらめ、全件を手作業で照合する
2. 適当な式を入れ、エラーが消えるまで総当たりで試す
3. 紙の関数辞典を最初から最後まで読み通す
4. Geminiに列の配置とやりたい照合を伝え、XLOOKUPの式を作ってもらって少数の行で検証する ← 正解
解説：Geminiに材料と目的を伝えて式を頼むのだ、クルックー。AI関数が返す文と、実際に計算する数式は別物。台帳のキーと結果が一致するか確かめたまえ。
