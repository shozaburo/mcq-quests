【F7】URLリンクによる双方向化：資料からフォームやサイトへスムーズに誘導する設計 - クイズ（サイト実装分）

出典：stages/google64/data/quests/F.js の F7
サイト版：quest.html?id=F7

Q1. 配布するセミナー資料の「詳しくはこちら」という文字から、申込ページへ飛ばしたい。詳細に沿った設定はどれ？
1. 申込ページのURLを、スライドの隅に小さな文字で書いておく
2. その文字を選択し、挿入→「リンク」でURLを設定する ← 正解
3. URLを画像化してスライドに貼り付ける
4. スピーカーノートにURLを控え、口頭で読み上げる
解説：文字を選んで挿入→リンク、たった三手よ。URLを裸で書いても画像にしても、押しても飛ばないでしょう。ちゃんとリンク化してこそ「動く名刺」になるの。

Q2. 資料の「双方向化」で誘導する先の例として、詳細で挙げられているのはどれ？
1. 発表者のデスクトップにあるローカルファイル
2. 社内の紙の資料棚
3. アンケートフォーム・申込ページ・関連資料 ← 正解
4. 発表者のメール受信箱
解説：アンケートフォーム、申込ページ、関連資料……見た人をワンクリックで次の場所へ案内するの。銀座のドアマンみたいなものね。

Q3. リンクを設定した資料をPDFにして配ったとき、正しいのはどれ？
1. PDFにするとリンクは必ず消えてしまう
2. 紙に印刷しても、リンクはタップで機能する
3. リンクがあるとPDF化そのものができなくなる
4. 受け取った人がタップやクリックで、そのままリンク先へ飛べる ← 正解
解説：PDFにしてもリンクは生きてるの。配ったあとも、相手を次の場所へ案内し続けてくれる……健気だと思わない？紙に刷ったらさすがに飛ばないけどね。

Q4. 商談後にじっくり検討してもらう提案資料。双方向化で置くと最も効果的なリンクはどれ？
1. 見積もり依頼フォームや詳細資料など「次の一歩」に直結するリンク ← 正解
2. 自社のトップページだけへのリンク
3. 発表者個人のSNSアカウントへのリンク
4. リンクは付けず、口頭で「各自で調べて」と伝える
解説：置くなら「次の一歩」に直結するリンクよ。トップページに放り込んでも相手は迷子。検討の熱があるうちに、見積もりや詳細へすっと導くの。導線は具体的でなきゃ意味がないわ。

Q5. セミナー資料でアンケートの回収率を上げたい。詳細の考え方を活かした一手はどれ？
1. アンケートは終了後、口頭でお願いするだけにする
2. 最後のスライドにアンケートフォームへのリンクを置き、その場で誘導する ← 正解
3. アンケート用紙を後日、郵送する
4. 回答は主催者が代わりにまとめて書いておく
解説：熱が冷めないその場で誘導するのが肝よ。最後の一枚にフォームのリンクをぽんと置くの。導線があるかどうかで、集まる数はまるで変わるものよ。
