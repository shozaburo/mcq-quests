Q1. 半年分・数十件の出張予定を一気にカレンダーへ入れたい。最も効率的な流れは？
1. Geminiにカレンダー用のCSVを作らせ、カレンダーの「インポート」で取り込む ← 正解
2. Geminiに予定を1件ずつ読み上げさせ、聞きながら手入力する
3. GeminiにGoogleのパスワードを渡し、直接カレンダーへ書き込ませる
4. 予定表をスクリーンショットし、カレンダーに画像として貼り付ける
解説：ZUNDA…（訳：CSVにして「インポート」で一気に取り込むのが正道。豆を一粒ずつ運ぶ者と、袋ごと担ぐ者の差なのだ。パスワードを渡すのは蔵の鍵を見知らぬ者に預けるようなもの、してはならぬ）

Q2. Geminiに予定リストを渡すとき、そのまま取り込めるCSVを得る頼み方は？
1. 「予定を覚えておいて、あとで使うから」とだけ伝える
2. 「次の出張予定を、Googleカレンダー用のCSV形式で」と用途と形式を明示する ← 正解
3. 「CSV」とだけ入力し、あとは察してもらう
4. Excelファイルのまま渡し、AIがカレンダーへ自動反映するのを待つ
解説：ZUNDA…（訳：「Googleカレンダー用のCSVに」と用途と形式まで告げるのが肝。何を植えたいか言わねば、望む豆は畑から出てこないのだ）

Q3. 数十件を手入力する場合と比べ、CSVインポートに置き換える最大の意義は？
1. 予定ごとに色分けとリマインドが自動で決まり、設定の手間がなくなる
2. 1件あたりに書ける情報量が手入力より増え、説明文を充実させられる
3. まとめて登録する手間を減らせるが、CSVの列名・日時と登録先は事前に確認する ← 正解
4. 取り込んだ予定は後からまとめて一括削除できるようになる
解説：ZUNDA…（訳：一括登録にも確認は要る。列名はGoogle指定の英語表記にそろえ、少数の予定で試そう。CSVの取り込みだけではゲストや会議情報は移らず、後の変更も同期されない）

Q4. AIが出したCSVを実際にカレンダーへ取り込む操作は？
1. CSVをGmailに添付し、自分宛てに送っておく
2. CSVをGoogleドライブに置いておけば自動で予定になる
3. CSVの中身を、既存の予定のメモ欄に貼り付ける
4. カレンダーの設定から「インポート」を選び、CSVを読み込ませる ← 正解
解説：ZUNDA…（訳：取り込みは設定の「インポート」から。ドライブに置くだけでは予定にならぬ。収穫した豆は、正しい戸口から蔵へ納めるのだ）

Q5. 取り込んだ結果、日付や時刻がずれて登録された。最も先に疑うべき原因は？
1. Geminiが有料版でないと、日時は必ずずれる仕様である
2. CSVの日付・時刻の列の書式が、カレンダーの想定と食い違っている ← 正解
3. カレンダーは一度に50件までしか受け付けない仕様である
4. インポートは既存の予定をすべて消してから入れ直す仕様である
解説：ZUNDA…（訳：ずれの多くは日付・時刻の列の書式違い。取り込む前に一列だけ検（あらた）めれば、畑一面の作り直しは避けられるのだ）
