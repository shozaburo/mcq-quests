【G3】引用（シテーション）機能を活用した一次情報の即時検証 - クイズ（サイト実装分）

出典：stages/google64/data/quests/G.js の G3
サイト版：quest.html?id=G3

Q1. NotebookLMの回答文中に現れる[1][2]といった番号は、何を表しているか？
1. 回答の重要度ランキング
2. 回答生成にかかった秒数
3. 根拠となった元ソースの箇所を示す引用（シテーション）番号 ← 正解
4. ソースをアップロードした順番
解説：[1][2]は根拠たる一次情報を指す引用番号なり。矢文の出所を検めるが如く、必ず辿れ。

Q2. 回答内の引用番号をクリックすると起きることは？
1. 元ソースの該当箇所がハイライト表示され、すぐ原文を確認できる ← 正解
2. 回答が別の言い回しで再生成される
3. そのソースがノートブックから削除される
4. 外部の解説サイトが新しいタブで開く
解説：番号を押せば元ソースの該当箇所が浮かび上がり、即座に原文を検められる。疾きこと風の如き検証よ。

Q3. 引用機能が最も威力を発揮する業務はどれか。最適なものを選べ。
1. SNS投稿のネタ出しなど、正確性より速さ優先の作業
2. 社内イベントの余興アイデア出し
3. キャッチコピーの語感チェック
4. 法務・契約・医療など、絶対に間違えられない情報を扱う業務 ← 正解
解説：一つの誤りが命取りとなる戦場でこそ、引用による検証が要となる。慎重なること林の如くあれ。

Q4. 引用番号が付いた回答でも「引用があるから内容もすべて正確」とは限らない。引用機能の限界の説明として、最も正しいのはどれ？
1. 引用は元の該当箇所を指し示すだけで、その周りのAIの要約が原文とずれたり、引用範囲を超えた推測が混じることがある ← 正解
2. 引用番号が付いた文は、原文を一字一句そのまま貼り付けたものなので、要約のずれは決して起きない
3. 引用の限界は、回答をより長く生成させれば必ず解消され、推測も混じらなくなる
4. 引用番号が多い回答ほど、原文に忠実で余計な推測が混じることはない
解説：引用は道標にすぎず、その周りの要約や引用範囲を超えた推測まで正しいとは限らぬ。番号の先の原文と、答えの言い回しのずれに目を配れ。それも兵法よ。

Q5. AIが「御社の返品規定は購入後14日以内です」と引用番号[3]付きで答えた。担当者が取るべき最善の行動は？
1. 番号が付いているので、そのまま顧客に14日と回答する
2. [3]をクリックして原文を開き、本当に『14日』か、条件や例外がないかを確かめてから使う ← 正解
3. 念のため別のAIにも同じ質問をして多数決で決める
4. 14日という数字をWebで検索し直して裏を取る
解説：引用[3]を開き、原文で数字と例外まで検めてから用いよ。引用は確かめる入口ぞ、押さずに信ずるは危うし。
