Q1. スプレッドシートでピボットテーブルを作成する、正しい手順は？
1. ファイル → インポート → ピボット
2. 挿入 → ピボットテーブル を選択する ← 正解
3. データ → データの入力規則 → ピボット
4. 拡張機能 → Apps Script → ピボット
解説：「挿入」メニューから「ピボットテーブル」だ、クルックー。集計の玉座はそこから据えるものなのだよ。

Q2. ピボットテーブルで集計表の形を組み立てるときの、基本操作はどれ？
1. セルにSUM関数を1つずつ手入力していく
2. 集計したい数字を電卓で計算し、貼り付ける
3. 編集パネルの「行」「列」「値」の「追加」から集計したい項目を選ぶ ← 正解
4. データを五十音順に並べ替えるだけでよい
解説：まず各欄の「追加」で項目を選ぶのだ、クルックー。追加した項目はドラッグで移すこともできる。行は何で分け、値は何を数えるか決めたまえ。

Q3. 「部署別」で組んだアンケート集計を、今度は「年代別」で見たい。ピボットテーブルなら？
1. 行エリアの項目を入れ替えるだけで、即座に別の切り口の集計に変わる ← 正解
2. 元データを年代順に、手作業で並べ直す必要がある
3. 最初からシートを作り直すしかない
4. 年代別の集計は、関数でしか作れない
解説：項目を差し替えるだけで切り口が変わる、これぞ多角的分析だ、クルックー。作り直し無用で、何通りにも景色を眺められるのだよ。

Q4. ピボットの「値」が『合計』で集計されているが、本当は「回答件数」を数えたい。正しい対処は？
1. 元データを消して、最初から数え直す
2. 値エリアの集計方法を『COUNTA（個数）』などに変更する ← 正解
3. ピボットテーブルは合計しか計算できないので諦める
4. 別の列に、手作業でCOUNT関数を書き足す
解説：値の集計方法は玉座から選び替えられるのだ、クルックー。合計から個数へ、ひと押しで数え方を変えたまえ。作り直しは無用なのだよ。

Q5. 現在のGoogleスプレッドシートで、AIを使って分析やグラフ作成を助けてもらう方法はどれ？
1. シートを印刷するためのプレビュー機能である
2. 他のユーザーの閲覧履歴を探る機能である
3. 使うと元データが自動で削除される危険な機能である
4. 利用可能な契約では、Geminiに表の分析やグラフ作成を頼み、結果を確認して挿入できる ← 正解
解説：旧「データ探索」は終了しておる。今はGeminiのサイドパネルや、挿入メニューのグラフ等を使うのだ。AIの提案も、範囲と集計方法を確かめたまえ。
