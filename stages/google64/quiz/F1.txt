【F1】NotebookLM スライド生成機能：ボタン一発で膨大な資料をスライド形式へ自動変換 - クイズ（サイト実装分）

サイト版：quest.html?id=F1

Q1. 50ページの社内マニュアルをNotebookLMでスライド化したい。ソースを投入したあと、スライドを生成する操作はどれ？
1. ノートブックのチャット欄に「スライドにして」と入力する
2. ノートブックガイドの「音声概要」から変換する
3. スタジオ（Studio）パネルで「スライド（スライドデッキ）」を選んで生成する ← 正解
4. Googleスライドを開いて「NotebookLM連携」ボタンを押す
解説：あら、スライドはスタジオパネルの「スライド」から生むのよ。チャットに頼んでも音声概要をいじっても出てこないの。入口を間違えないことね。

Q2. NotebookLMで生成したスライドの扱いとして、事実に合っているのはどれ？
1. 生成と同時にGoogleスライドのファイルが自動で作られ、ドライブに保存される
2. NotebookLM上でそのまま提示でき、PDFやPowerPoint（.pptx）形式で書き出せる ← 正解
3. 生成物は画像1枚に統合されて出力される
4. スライドは音声概要の再生画面の中でしか見られない
解説：……いいこと教えてあげる。NotebookLMのスライドはその場で見せられて、PDFやPowerPointで書き出せるの。Googleスライドが勝手に出来上がる、なんて話じゃないのよ。勘違いしてる人、案外多いんだから。

Q3. 生成したスライドを、Googleスライドで開いて手直ししたい。正しい進め方はどれ？
1. PowerPoint（.pptx）形式で書き出し、そのファイルをGoogleスライドで開く ← 正解
2. NotebookLMの共有ボタンからGoogleスライドへ直接送信する
3. スライドを1枚ずつスクリーンショットしてGoogleスライドに貼る
4. Googleスライドでは開けないので、内容を手入力で作り直す
解説：PowerPointで書き出してGoogleスライドで開けるわ。書き出された文字や図がどこまで編集できるかは実物で確認してね。画像になっている部分は、元のスライドを修正して作り直す方法もあるのよ。

Q4. 生成する前に、スライドの切り口や焦点を自分の狙いに寄せたい。事実に沿うと、できることはどれ？
1. 生成は一発勝負で、事前の調整は一切できない
2. 出力される秒数を指定して長さだけ決める
3. ソースをすべて削除してからでないと調整できない
4. 生成前にカスタマイズ（鉛筆アイコン等）で焦点や指示を与えてから作らせる ← 正解
解説：あら、作る前に鉛筆アイコンから注文をつけられるのよ。焦点を伝えてから生ませる……仕立て屋に採寸させてから縫わせるのと同じ。黙って任せるより、ずっと似合う一着になるの。

Q5. 自分が話しながら見せる、口頭発表用のスライドをNotebookLMで作りたい。適切なのはどれ？
1. 文字を詰め込んだ詳細型より、要点を絞った発表者向け（プレゼン補助）のスタイルにする ← 正解
2. 全部の文章を載せた詳細スライドにして、それを棒読みする
3. スライドは作らず、音声概要だけで済ませる
4. 1枚のスライドに全情報を詰め込んでおく
解説：話しながら見せるなら、要点だけの発表者向けが上品よ。文字だらけのスライドを棒読みなんて、聞くほうも退屈でしょう。詳細型は配布用、発表用は身軽に……使い分けが粋ってものよ。
