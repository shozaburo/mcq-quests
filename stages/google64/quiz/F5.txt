Q1. 詳細に出てくる「Nano Banana」とは何のこと？
1. Googleスライドの黄色いデザインテンプレート
2. スプレッドシートの新しい関数の名前
3. Geminiの画像生成モデル ← 正解
4. フリー素材サイトのサービス名
解説：Nano BananaはGeminiの画像生成モデルの名前よ。ふふ、可愛い名前に油断してると、その仕事ぶりに驚かされるわよ。

Q2. Nano Bananaでイメージ通りの画像を出したい。詳細に沿った、最も良い指示の仕方はどれ？
1. 「おしゃれでいい感じの画像を、きれいに作って」と雰囲気を丁寧に伝える
2. 「ビジネス向けの〇〇のイメージ、ミニマル、青系で」と用途・テイスト・色まで指定する ← 正解
3. 「〇〇の画像を、とにかく高画質で」と品質だけ指定する
4. 「青系で作って」と色だけ指定する
解説：「いい感じ」じゃAIも困るのよ。用途・テイスト・色まで注文するの。オーダーメイドは細かく伝えてこそ、思い通りに仕立ちあがるってわけ。

Q3. フリー素材と比べたときの、AI生成画像の利点として詳細で挙げられているのはどれ？
1. 画質が必ずフリー素材より高くなる
2. 加工や調整が一切不要になる
3. ファイルサイズが必ず小さくなる
4. 用途に合わせて独自の見た目を作りやすいが、他人の権利を侵害しないか確認は必要 ← 正解
解説：雰囲気を自分の資料に合わせられるのは魅力よ。でもAIが作っただけで権利の心配が消えるわけではないの。公開前に、他人の作品や人物の扱いも確かめてね。

Q4. 生成された画像が、思い描いたイメージとだいぶ違っていた。まず取るべき手はどれ？
1. 用途・テイスト・色などをより具体的に伝えて再生成する ← 正解
2. 諦めてフリー素材に切り替える
3. 画像編集ソフトで一から描き直す
4. AIには無理なので手描きに戻す
解説：一発で理想通りは稀なのよ。違ったら、用途や色をもっと具体的に伝えて出し直すの。注文を細かくするほど、狙いに寄っていくものよ。

Q5. 生成したオリジナル画像を、プレゼン資料でどう活かすのが最も適切か。
1. 画像は表紙スライドだけに使うのがルール
2. 生成画像はSNS専用で、スライドには使えない
3. 資料の世界観に合う一枚として挿入し、訴求力を高める ← 正解
4. 重くなるので画像は一切入れないほうがよい
解説：資料の世界観に合う一枚を挿し込んで、訴求力を上げるの。あら、プレゼンだって装いが物を言う……大事なことよ。
