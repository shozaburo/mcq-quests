【F3】Geminiとテーマ・レイアウトを使って、伝わるスライドに整える - クイズ（サイト実装分）

出典：stages/google64/data/quests/F.js の F3
サイト版：quest.html?id=F3

Q1. スライドの見た目を整えたい。現在の機能に沿った方法はどれ？
1. 終了した「データ探索」ボタンを探し続ける
2. テーマやレイアウトを選び、必要に応じてGeminiにも案を頼む ← 正解
3. 画面の明るさだけを変える
4. スライドを画像にして一切読めなくする
解説：旧「データ探索」は終了しているの。テーマとレイアウト、利用できるGeminiの機能を組み合わせて整えましょ。

Q2. Geminiにスライド案を頼むとき、最初に伝えるとよいことは？
1. 使うPCの色だけ
2. 文字をとにかく小さくすること
3. 聞き手・目的・伝える要点・希望する雰囲気 ← 正解
4. 理由なく図を十個入れること
解説：誰に何を届けたいのかを先に伝えるのよ。見た目は、その話が伝わるために整えるものなの。

Q3. Geminiが作ったスライド案を採用する前に行うことは？
1. 事実・読みやすさ・配置を確認し、必要な修正をする ← 正解
2. AI生成なので確認を省く
3. 資料の出典をすべて消す
4. 文字数が多いほど良いと判断する
解説：AIの案も下書きよ。数字と出典、文字の大きさ、図との重なりを確かめてから舞台に出しましょ。

Q4. GoogleスライドにGeminiの機能が表示されない場合、適切な対応は？
1. 資料を公開すれば必ず使える
2. 他人のアカウントを借りる
3. ファイルを削除する
4. 契約や管理者設定を確認し、テーマ・レイアウト等で整える ← 正解
解説：使える機能には契約や設定の条件があるの。テーマやレイアウトでも整えられるわ。必要な条件を確かめてね。

Q5. レイアウトを整える一番の目的は？
1. 同じ文字を何度も繰り返すこと
2. 装飾の数を最大にすること
3. 相手が要点と話の順番をつかみやすくすること ← 正解
4. 文字をすべて画像に変えること
解説：主役は伝えたい内容よ。見出しと余白を整え、客席が迷わず読める舞台にするの。
