【D6】文書フォーマットの最適化：Web向け「ページ分けなし設定」と、ワンクリック翻訳機能 - クイズ（サイト実装分）

出典：stages/google64/data/quests/D.js の D6
サイト版：quest.html?id=D6

Q1. GoogleドキュメントをWeb記事のようなフラットなレイアウトにしたい。正しい操作はどれか？
1. 余白をすべて0cmに設定する
2. 用紙サイズをA3横に変更する
3. ファイル → ページ設定 → 「ページなし」を選ぶ ← 正解
4. 表示 → 印刷レイアウトを2ページ表示にする
解説：「ファイル → ページ設定 → ページなし」でWeb記事的フラットレイアウトに！紙の枠を捨てる勇気を持て！

Q2. 「ページなし」設定が特に向いている文書はどれか？
1. 紙に印刷して製本する契約書の最終版
2. 画面で読むことが前提の社内Wiki的な文書やWeb掲載用の原稿 ← 正解
3. ページ番号が重要な官公庁への提出書類
4. はがきサイズで印刷する案内状
解説：画面で読む社内Wikiや掲載原稿にこそ「ページなし」が活きる！読み手の環境に姿を合わせよ！

Q3. ドキュメント全体を別言語に翻訳した版を作りたい。講座で紹介された方法はどれか？
1. ツール → ドキュメントを翻訳で、翻訳された別ファイルを即生成する ← 正解
2. キーボードの言語設定を切り替えると本文が自動翻訳される
3. 一文ずつコピーして外部の翻訳サイトに貼り付ける
4. 翻訳会社に発注する以外に方法はない
解説：「ツール → ドキュメントを翻訳」で別言語版が即生まれる！一文ずつ写す苦行は捨て、執念は別に使え！

Q4. ワンクリック翻訳で外国語版を作ると、固有名詞をめぐって起こりやすい問題はどれか？
1. 固有名詞は翻訳されず必ず原文のまま完璧に残るので、問題は起きない
2. 社名・製品名・人名が一般名詞として意訳されたり、不自然に音訳されることがある ← 正解
3. 固有名詞だけ自動で太字になり、本文が読めなくなる
4. 固有名詞が含まれていると翻訳機能そのものが起動しない
解説：機械翻訳は社名・製品名を一般語に意訳したり不自然に音訳することがある！固有名詞の落とし穴を知って備えよ！

Q5. 「ドキュメントを翻訳」で作った別言語版と、元の文書の関係として正しいのはどれか？
1. 元の日本語文書が翻訳版に上書きされて消えてしまう
2. 翻訳すると元の文書も自動で外国語に置き換わる
3. 翻訳版は読み取り専用になり、一切編集できなくなる
4. 元の文書はそのまま残り、翻訳された内容が別の新規ファイルとして作られる ← 正解
解説：翻訳は元文書を残したまま、別の新規ファイルとして生まれる！原本は消えぬ、安心して使い倒せ！
