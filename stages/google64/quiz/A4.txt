【A4】AI検索最適化（ACO）のためのファイル命名規則 - クイズ（サイト実装分）

サイト版：quest.html?id=A4

Q1. フォルダに「最終」「本当に最終」「最終_修正版」というファイルが並び、どれが最新か分からなくなりました。AI検索最適化(ACO)の観点で推奨される命名はどれでしょうか？
1. 「YYYYMMDD_案件名_書類種別_v01」のように日付・案件・種別・版で構成する ← 正解
2. 「最新」「完全版」など状態を表す言葉を付ける
3. 「document1」「document2」と通し番号だけにする
4. 作成者の名字と作成した曜日を付ける
解説：日付・案件・種別・版を並べれば、人にもAIにも中身と新しさが一目で伝わるのじゃ。「本当に最終」や「完全版」はどれが本命か迷わせる悪い呪文、通し番号だけでは中身が語れんのう。

Q2. この命名規則を地道に続けると、将来のAI活用でどんな恩恵があるとされていますか？
1. ファイル容量が自動で半分に圧縮される
2. 命名しておくとAIが自動でフォルダ分けまで行ってくれる
3. 名前に日付・案件・種類・版を含めると、人が検索して必要な資料を選びやすい ← 正解
4. 命名したファイルはAIの学習対象から自動で除外される
解説：分かる名前は探す手がかりになるのじゃ。ただし、名付けだけでAIの正確さが保証されるわけではないぞ。NotebookLMには必要な資料を自分で選んで取り込むのう。

Q3. 「20260711_ヤマダ商事_Estimate_見積_v1最終」——このファイル名でACO的に一番まずい点はどれでしょうか？
1. 日付を先頭に置いていること
2. 日本語と英語(Estimate/見積)を無秩序に混ぜ、版の表記(v1/最終)も揺れていること ← 正解
3. 案件名を含めていること
4. 区切りにアンダースコアを使っていること
解説：言葉が混ざり版の書き方も揺れると、検索の網から漏れやすくなるのじゃ。日付を先頭に置くのもアンダースコアで区切るのも良い作法——日本語なら日本語、版はv01と揃える、これが検索上手の心得よのう。

Q4. 経理のあなたが受け取った請求書を保存します。命名規則の例として最も適切なのはどれでしょうか？
1. 「請求書_山田商事_最新版_コピー」
2. 「seikyu_0711_yamada_fix」
3. 「山田商事さん請求書(確認済)」
4. 「20260711_山田商事_請求書_v01」 ← 正解
解説：日付→案件→種別→版と整った名が正解じゃ。「最新版」「コピー」「fix」「確認済」といった気分の言葉は後から意味が薄れる——一年後に探しても、AIに尋ねてもすぐ見つかる形に整えるのう。

Q5. 「フォルダにきちんと入れれば命名は適当でよい」と考える同僚がいます。それでもファイル名を整える意義として、この考え方に沿うのはどれでしょうか？
1. フォルダをまたぐ横断検索やAI検索では、名前自体が中身を語る手がかりになる ← 正解
2. 名前を整えるとフォルダ分けが一切不要になる
3. 名前さえ良ければ共有権限の設定を省ける
4. 名前を整えるとファイルが正しいフォルダへ自動で移動する
解説：フォルダをまたいで検索する時、頼りになるのは名前そのものじゃ。しまい場所が変わっても名が中身を語ってくれる——だから命名は無駄にならん、フォルダ分けと両輪で効くのう。ね、兄者？「うむ」
