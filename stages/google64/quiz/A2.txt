【A2】Chromeプロファイル活用による複数アカウントの切り替え - クイズ（サイト実装分）

Q1. 1つのChromeで仕事用と個人用のGoogleアカウントを行き来していたら、社内資料の共有リンクを個人アカウントで開いてしまい権限エラーが頻発します。根本から解決する方法はどれでしょうか？
1. Chromeのプロファイルを用途ごとに分け、環境そのものを切り替える ← 正解
2. 共有リンクを開くたびにアカウントを手動で切り替える
3. 個人用アカウントを削除して仕事用だけを残す
4. リンクを開く前に、ログイン中のアカウントを毎回確認する
解説：プロファイルごとに部屋を分ければ、そもそも別のアカウントで開く事故が起きにくいのじゃ。毎回の手動切替や目視確認は、忙しい日にほど抜けが出る——根治には環境を分けるのが早いのう。ね、兄者？「うむ」

Q2. Chromeで新しいプロファイルを追加する操作はどれでしょうか？
1. Chromeをもう1本インストールし直して2本目を用意する
2. 設定の「同期をオフにする」を選ぶ
3. Chrome右上のプロフィールアイコンをクリックして「+追加」を選ぶ ← 正解
4. シークレットウィンドウを開いて別アカウントでログインする
解説：右上のアイコンから「+追加」、これだけで新しい部屋が建つのじゃ。シークレットは一時しのぎ、閉じれば消えてしまう——恒久的に分けたいならプロファイルを立てるのう。

Q3. プロファイルを分けて使うと、部屋ごとに独立して管理されるものはどれでしょうか？
1. ブックマーク・閲覧履歴・拡張機能・保存パスワード ← 正解
2. パソコンにインストール済みのソフト全般
3. OSのユーザーアカウントとファイルのアクセス権
4. インターネット回線の速度と接続先
解説：ブックマークも履歴も拡張機能も、部屋ごとに別々の道具箱になるのじゃ。あくまでChromeの中の話で、パソコン本体やOSの設定までは分かれん——そこを取り違えぬようにのう。

Q4. 士業のあなたは複数の顧問先を担当します。プロファイルの実務的な使い方として最も適切なのはどれでしょうか？
1. 全顧問先の作業を1つのプロファイルにまとめて効率化する
2. 顧問先ごとにブラウザの種類(Chrome/Edge)を変えて分ける
3. 案件が終わるたびプロファイルを削除して作り直す
4. 顧問先ごと・仕事用・個人用などで分け、情報が混ざらないようにする ← 正解
解説：用途ごとに部屋を分ければ、よその顧問先の情報が画面に紛れ込む事故を防げるのじゃ。ブラウザを使い分ける手もあるが管理が煩雑、同じChromeの中でプロファイルを分けるのが素直よのう。ね、兄者？「うむ」

Q5. 共用端末で一時的にログインするとき、Chromeに残る情報を減らすための適切な使い方はどれでしょうか？
1. 自分用のプロファイルを共用端末に作って作業する
2. 信頼できる端末でゲストモード等を使い、作業後はサインアウトして全ウィンドウを閉じる ← 正解
3. 共用端末の既存プロファイルに自分のアカウントを追加する
4. 共用端末で自分のブックマークを同期させておく
解説：ゲストやシークレットでも、端末の持ち主や通信先から完全に隠れるわけではないぞ。ダウンロードしたファイルにも気を配り、機密は信頼できる端末で扱うのじゃ。
