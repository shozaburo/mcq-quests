Q1. 音声入力で書き出した文章を校正するとき、特に注意して見るべき点はどれか？
1. フォントの種類と文字色が全体で揃っているか
2. 「以外／意外」「制作／製作」などの同音異義語や、固有名詞・専門用語の変換ミス ← 正解
3. 段落の背景色が白のまま保たれているか
4. ファイル名が日付順に正しく並んでいるか
解説：音声入力は同音異義語や固有名詞の誤変換が命取り——そこを重点的に校正せよ！「以外／意外」を見逃すな、執念で検めよ！

Q2. 音声入力中に改行や句点を入れたいとき、正しいやり方はどれか？
1. 音声入力では不可能なので、必ず後から全て手作業で入れる
2. 3秒黙ると自動で段落が変わる仕様なので黙って待つ
3. キーボードに触れた瞬間に音声入力が壊れるので絶対触らない
4. 音声コマンドは言語条件を確認し、日本語で意図どおりにならない改行・句読点はキーボード等で整える ← 正解
解説：日本語の入力と、音声による編集コマンドは別である。公式の編集コマンドは英語のアカウント・文書が条件。「改行」「まる」で必ず操作できるとは限らぬのである。

Q3. 音声で一気に書き出した文章は話し言葉で乱れがち。講座が推奨する仕上げの手順はどれか？
1. 乱れも味なのでそのまま社外へ送る
2. 全文を一度削除して最初からキーボードで打ち直す
3. Geminiに「誤字脱字とトーンを校正、ビジネス文書として整えて」と指示する ← 正解
4. フォントと文字色を変えて見栄えだけ整える
解説：話し終えたらGeminiに「誤字脱字とトーンを校正、ビジネス文書に整えて」と命じよ！荒削りの石も磨けば玉となる！

Q4. 「音声入力＋AI校正」という高速入力メソッドの本質的な狙いはどれか？
1. 手を止めずに思考を書き出し、整える工程はAIに任せて時短すること ← 正解
2. 話した内容を録音ファイルとして残すこと自体を目的にすること
3. キーボードを一切使わないことを目的に、全業務を音声化すること
4. 誤変換をゼロにして、校正作業そのものを完全になくすこと
解説：思考は声で吐き出し、整えはAIに委ねる——これぞ分業の妙だ！勢いを殺すな、走りながら立ち上がれ！

Q5. 音声入力が特に効く実務シーンとして、最も適切なのはどれか？
1. 既に完成した文章の誤字を1文字だけ直したいとき
2. 頭の中のアイデアや企画の素案を、詰まらず一気に書き出したいとき ← 正解
3. 数式や関数を1つのセルに正確に打ち込みたいとき
4. 静粛が求められる会議中に議事を密かに記録したいとき
解説：湧き出るアイデアを詰まらせず一気に吐き出す、そこで音声入力は輝く！勢いを味方に起き上がれ！
