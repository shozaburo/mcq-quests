Q1. 取引先A社との案件で、スキャンした契約書PDF・社内で使うGoogleドキュメントの提案書・参考にしたい業界解説YouTube動画・競合のWebサイトを、まとめてNotebookLMで扱いたい。正しい方針は？
1. 「ソース追加」から、PDFアップ・Googleドキュメント連携・YouTube URL・Webサイト貼り付けを1つのノートブックに混在させてよい ← 正解
2. 形式が違うので、PDF用・ドキュメント用・動画用にノートブックを4つ作る必要がある
3. YouTubeとWebサイトはPDFに変換してからでないと追加できない
4. GoogleドキュメントはドライブでPDF書き出ししないと取り込めない
解説：PDFもドキュメントもYouTubeもWebも、一つの陣に混在させてよいのだ。多様な兵を束ねてこそ大軍となる、それも兵法よ。

Q2. 取引先ごと・案件ごとに資料が増え続けている。半年後に「あの件の資料どこだっけ」を防ぐ、最も理にかなった運用はどれ？
1. 全案件の全資料を1つの巨大ノートブックに入れ、毎回キーワード検索で探す
2. 資料はNotebookLMに入れず、Googleドライブのフォルダ分けだけで運用する
3. プロジェクト（案件・取引先）ごとにノートブックを分けて作る ← 正解
4. 3か月ごとに全ノートブックを削除して作り直す
解説：案件ごとに陣を分けておけば、後の捜索は疾きこと風の如しなり。整った陣立てこそ勝機を生む礎ぞ。

Q3. Web上で公開されている官公庁のガイドラインページを、資料として取り込みたい。最短の手順は？
1. ページ全体をスクリーンショットし、画像をPDF化してからアップロードする
2. 本文をコピーしてGoogleドキュメントに貼り、そのドキュメントを連携する
3. ページを一度印刷してスキャンし、紙資料として取り込む
4. 「ソース追加」でそのWebサイトのURLを貼り付ければよい ← 正解
解説：URLを貼るだけで取り込めるものを、わざわざ画像や印刷に回すは愚策なり。回り道を捨て最短の道を征け。

Q4. 社内に散らばる規程・マニュアル・議事録をNotebookLMで「一元管理」する、中小企業にとっての本当の狙いはどれ？
1. アップした資料が自動で社外公開され、宣伝に使えるようになる
2. 散在する資料を1か所に集め、AIにまとめて質問・要約させる体制を作れる ← 正解
3. アップした資料の誤字脱字が自動で校正される
4. 原本がドライブから消えて、ストレージ容量を節約できる
解説：散らばる資料を一所に集め、AIに問える体制を築く。兵力の集中は戦の常道、情報も同じよ。

Q5. ある担当者が「PDFは1ノートブックに1個しか入らないと思っていた」と言う。正しく訂正するとどうなる？
1. その通りで、複数PDFを扱うには有料プランが必須である
2. PDFは複数入るが、他の形式と混ぜると先に入れたPDFが消える
3. 1つのノートブックに複数のPDFも、他形式のソースも一緒に追加できる ← 正解
4. PDFは3個まで、という上限が形式ごとに決まっている
解説：一つの陣に複数のPDFも他形式も共に納められるのだ。数の思い込みで戦力を眠らせるでないぞ。
