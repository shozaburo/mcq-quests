Q1. Gmailのテンプレート機能を使い始めるための最初の手順はどれか？
1. 管理者にメールサーバーの設定変更を依頼する
2. Gmailの設定 → 詳細タブでテンプレートを有効化する ← 正解
3. Chromeの拡張機能ストアで「テンプレート」アプリを購入する
4. Googleドキュメントで定型文を作り毎回コピーする
解説：設定 → 詳細でテンプレートを有効化、これが第一歩だ！初期設定ひとつ怠けるな、願を掛けるのはそれからだ！

Q2. テンプレート機能の正しい活用イメージはどれか？
1. 迷惑メールを自動で報告する機能として使う
2. 受信メールを自動で削除する機能として使う
3. よく送る定型メールを保存し、新規作成時に呼び出して使い回す ← 正解
4. メールの送信予約時刻を管理する機能として使う
解説：よく送るメールをテンプレートに保存し、新規作成時に呼び出せ！同じ文を何度も打つ手間を断ち切るのだ！

Q3. Gmailのフィルタ機能でできることとして、講座で挙げられているのはどれか？
1. 特定のメールに自動でラベルを付けたり、既読にしたり、転送したりする ← 正解
2. 取引先のメールサーバーの障害を遠隔で復旧させる
3. 相手の受信トレイから自分の送信済みメールを消す
4. メールの文面をAIが自動で全文書き換える
解説：フィルタは「自動でラベル付与・既読・転送」を組む仕組みだ！仕分けは機械に任せ、判断に執念を注げ！

Q4. 毎朝届く特定取引先の受注メールを、専用ラベルに自動で振り分けるフィルタを作る。設定として正しいのはどれか？
1. 条件を「未読のもの全部」にすれば、確実に受注メールだけを拾える
2. 条件は空欄のまま作れば、自動で受注メールだけを判別してくれる
3. 送信元アドレスや件名など、受注メールを特定できる条件で絞り込む ← 正解
4. 本文に一度でも数字が含まれるメール全てを条件にする
解説：送信元や件名で受注メールを特定できる条件に絞れ！条件が広すぎれば無関係な便りまで拾う、設定は的確にだ！

Q5. テンプレートとフィルタを組み合わせる狙いとして最も適切なのはどれか？
1. メールの誤送信を法的に無効化するため
2. 受信トレイの保存容量を無制限にするため
3. 上司へのメール報告義務そのものをなくすため
4. 定型的なメール業務の作成・仕分けを自動化・省力化し、時間を生み出すため ← 正解
解説：定型業務は仕組みで回し、浮いた時を本業へ！日々の小さな効率化の積み重ねが八起きの力となる！
