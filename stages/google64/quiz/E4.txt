Q1. QUERY関数の特徴を正しく説明しているのはどれ？
1. SQL風の記述で、大量のデータから条件に合う行を動的に抽出できる ← 正解
2. セルの見た目を整えるための書式設定専用の関数
3. 画像をシートに挿入するための関数
4. 他人のシートを強制的に編集する関数
解説：QUERYはSQL風の号令でデータを選り分ける関数だ、クルックー。膨大な回答の海から、必要な行だけを瞬時に掬い上げるのだよ。

Q2. =QUERY(範囲, "SELECT A,B WHERE C='完了' ORDER BY D DESC") が行うことは？
1. C列の「完了」をすべて「未完了」に書き換える
2. A列とB列を削除してから、D列を昇順に並べ替える
3. C列が「完了」の行だけを対象に、A列とB列を、D列の降順で取り出す ← 正解
4. 範囲全体をコピーして、新しいシートを作る
解説：WHEREで「完了」に絞り、SELECTでA・B列を選び、ORDER BY D DESC で降順に並べる、それだけの命令だ、クルックー。読み解けば恐るるに足らぬのだよ。

Q3. QUERYで作った月次レポートがある。元データに新しい回答が追記されたときの挙動は？
1. 手動で関数を入れ直さないと反映されない
2. 指定した参照範囲内なら、条件に合う新しいデータが結果に反映される ← 正解
3. エラーになってレポートが消える
4. 古いデータが自動で削除されてしまう
解説：QUERYが見るのは指定した範囲なのだ、クルックー。追記行が範囲の外なら含まれぬ。範囲と見出し行を確かめてから、自動集計を働かせたまえ。

Q4. QUERYで「部署ごとの回答件数」を数えたい。式に加えるべき句は？
1. SELECT だけで、部署ごとの件数は自動的に集計される
2. "SELECT B, COUNT(A) GROUP BY B" のように COUNT と GROUP BY を使う ← 正解
3. ORDER BY を付ければ、それが件数になる
4. WHERE で件数を直接指定する
解説：数を束ねたくば COUNT で数え、GROUP BY で部署ごとにまとめるのだ、クルックー。集計の号令はこの二語で成るのだよ。

Q5. SQLをまったく知らない担当者が、QUERY関数を使いたい。講座で勧められている方法は？
1. SQLの資格を取得するまで、QUERYは封印する
2. QUERYは諦め、すべて目視でフィルタする
3. 詳しい同僚が出社するまで作業を止める
4. Geminiに「QUERY関数で〇〇を抽出する式を書いて」と頼み、書いてもらう ← 正解
解説：SQLの学位など不要、Geminiに「〇〇を抽出する式を書け」と命じればよいのだ、クルックー。道具を使いこなす者にこそ玉座は微笑むのだよ。
