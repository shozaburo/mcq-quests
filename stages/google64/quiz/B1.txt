Q1. 「新商品の紹介文を書いて」とだけ頼んだら、当たり障りのない文章が返ってきた。5W1Hの考え方で最初に足すべきなのはどれ？
1. 「もっと良い感じで」と気持ちを強めに伝える
2. 「役割・対象・目的」を加え、誰として誰に何のために書くかを示す ← 正解
3. 同じ指示をもう一度そのまま送り直す
4. 「500文字で」とだけ文字数を指定する
解説：気持ちを込めても中身は変わらんぞ！役割・対象・目的を示してこそ的を射た文になるのだ。丸投げして気合で押す怠け者はいねがー！？

Q2. 初心者パートさん向けのマニュアルを作らせたいのに、専門用語だらけの文章が出てきた。5W1Hのどの要素が欠けているか？
1. 制約（どこまで書くか）
2. 例（参考にする見本）
3. 対象（誰に向けて書くか） ← 正解
4. 形式（どんな形で出すか）
解説：誰に向けるかを言わねばAIは万人向けの難しい言葉を使うのだ。読み手をパートさんと伝えれば言葉はやさしくなる。対象をぼかす者はいねがー！？

Q3. 見積書の督促メールを作らせたら長くて堅すぎた。狙い通りに整えるには、次にどの要素を足すのが最も効くか？
1. 形式と制約：「ビジネスメール形式・150字以内・角が立たない表現で」 ← 正解
2. 熱意：「誠意を込めて書いて」と精神論を添える
3. 回数：「3パターン作って」と数を増やす
4. 役割：「あなたはAIです」と念押しする
解説：どんな形で・どこまで、つまり形式と制約を握らせれば出力はピタリと整うのだ。祈って何度もガチャを回すよい子はいねがー！？

Q4. 依頼に「参考例」を添えると効果を期待できる場面はどれか？
1. AIに短い計算の答えだけを返させたいとき
2. 自社の過去資料と同じトーンや型に揃えて出力させたいとき ← 正解
3. 毎回まったく新しい発想で案を出させたいとき
4. 質問の意図をAIに聞き返させたいとき
解説：「これと同じ調子で」と見本を渡せば、AIは自社の型を真似てくれるのだ。手本も見せずに『うちらしくない』と嘆く者はいねがー！？

Q5. 5W1Hを盛り込んだプロンプトでも、まだ出力がしっくりこない。実務での正しい向き合い方はどれ？
1. AIは万能なので、しっくり来ないのは自分の理解不足だと諦める
2. 一度で完璧を狙い、ダメなら二度と使わない
3. 出た文をそのまま提出して結果を運に任せる
4. 「ここをもっと具体的に」と不足を指摘し、対話で詰めていく ← 正解
解説：プロンプトは一発勝負ではない。足りぬ所を『ここをもっと具体的に』と指摘し往復で磨くのが本筋だ。一度で見放す短気者はいねがー！？ガハハ！
