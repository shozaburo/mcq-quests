Q1. ドライブのフォルダが名前順に並び、よく使う「進行中」が下のほうに埋もれて毎回探す羽目になっています。番号付き命名(01_進行中 など)の一番の効き目はどれでしょうか？
1. 使う順・大事な順に並びを自分で固定でき、目的地へ迷わず着ける ← 正解
2. フォルダ内のファイルまで自動で使用頻度順に並び替わる
3. 番号を付けたフォルダは検索結果で常に上位に表示される
4. 名前順よりも作成日時を優先して表示するようになる
解説：頭に番号を振れば、フォルダは自分の決めた順に整列してくれるのじゃ。埋もれていた「進行中」が列の先頭に立つ、良い道しるべよのう。中のファイルや検索順まで変わるわけではないぞ。

Q2. 終わった案件を消さずに残しつつ、日々の一覧から目立たなくしたい。「08_アーカイブ」のように8番を付ける狙いはどれでしょうか？
1. 8はドライブで特別扱いされる予約番号だから
2. 8番フォルダは一定期間後に自動で圧縮されるから
3. 8番を付けると自動でゴミ箱へ移動するから
4. 古いものをまとめて表示順の最後に送り、今使うフォルダを見やすく保つため ← 正解
解説：済んだものは「8番」の袋にまとめ、列の後ろへ下がってもらうのじゃ。8番に特別な機能があるわけではない——大きな番号ゆえ末尾に並ぶ、その並び順を利用しているだけよのう。ね、兄者？「うむ」

Q3. 整理熱心な同僚が「深く分類するほど整うはず」と7階層も8階層も掘っています。この管理術の考え方に沿う助言はどれでしょうか？
1. 階層は深いほど整うので10階層を目指すべき
2. 3階層を目安にとどめる。深すぎると探す手数が増えて破綻しやすい ← 正解
3. 全ファイルを1フォルダに入れる1階層こそ唯一の正解
4. 階層の深さはGoogleが自動で最適化するので気にしなくてよい
解説：深い森は迷子のもと、目安は3階層までじゃ。掘れば整うわけではないし、かといって1階層に全部放り込むのも探せなくなる——ほどよい深さが探しやすさの肝よのう。

Q4. バラバラに散らかった既存フォルダを、この番号ルールで整え直します。最初に着手すべきことはどれでしょうか？
1. とりあえず全ファイルを削除して一から作り直す
2. 目についたフォルダから片端に番号を振っていく
3. 「進行中」「保管」「アーカイブ」など大分類を決め、番号付きの器を先に用意する ← 正解
4. ファイル名をすべて英語に翻訳してから並べ替える
解説：まず受け皿となる番号付きの大分類を建て、そこへ移していくのが順序じゃ。設計図なしに片端から番号を振ると途中で破綻する、削除から入るのはもっと危うい——大事な種まで捨ててしまうからのう。

Q5. 「01_」「02_」と付けていくうち、間に新しい分類を差し込みたくなりました。並び順を崩さず後から挿入しやすい、番号付けの実務的なコツはどれでしょうか？
1. 10,20,30…と間隔を空けて振り、後から15などを差し込めるようにする ← 正解
2. 最初から01,02,03…と1刻みで詰めて振っておく
3. 番号は付けず作成日だけで管理する
4. 新しい分類は常に末尾に足し、番号は気にせず名前で探す
解説：10,20,30と隙間を空けて振っておけば、後から15を差し込んでも列が崩れんのじゃ。詰めて振ると差し込むたびに総入れ替え、これは骨が折れる——先を見越した余白が身を助けるのう。ね、兄者？「うむ」
