Q1. 会議で書きなぐったホワイトボードを、そのまま議事録に起こしたい。Geminiでの最短手順はどれ？
1. ホワイトボードを一度印刷し、スキャナーで取り込み直す
2. 内容を思い出して自分でイチから打ち直す
3. 写真を撮り、Geminiにドラッグして「議事録形式にして」と頼む ← 正解
4. 写真を自分宛てメールに添付すると自動で変換される
解説：画像をドラッグして『議事録形式に』と一言頼めば足りるのだ。印刷して二度手間、手打ちで三度手間する苦労性はいねがー！？

Q2. たまった名刺100枚を顧客リストにしたい。マルチモーダルを活かす実務的な頼み方はどれ？
1. アップロードできる枚数ずつ画像を渡し「会社名・氏名・連絡先の表にして」と頼んで原本と照合する ← 正解
2. 「名刺を整理したい」とだけ伝え、画像は渡さずに待つ
3. 名刺を1枚ずつ手入力し、Geminiには報告だけする
4. 名刺の内容を口頭で読み上げて文字にしてもらう
解説：一度に渡せるファイル数には上限があるのだ。少数ずつ表にし、連絡先の読み違いを確かめてまとめるのだぞ。個人情報を扱える環境かも確かめよ！

Q3. 手書きのアンケート用紙をGeminiで読み取るとき、正しい理解はどれ？
1. 手書きは常に100%正確に読み取れる
2. 手書きは全く読み取れないので画像活用は無意味
3. 走り書きも意外と読めるが、似た数字や崩れた字を取り違えることがある ← 正解
4. 読み取れるのは英語の手書きだけで、日本語は不可
解説：AIは走り書きも意外と読むが、似た数字や崩し字を取り違えることもある。100%完璧と過信も、全く読めぬと諦めるのも間違いだ。決めつける者はいねがー！？

Q4. Geminiの「マルチモーダル」を正しく説明しているのはどれ？
1. 複数のファイルを同時に開いて並べる機能のこと
2. 文字だけでなく画像なども入力として理解し扱えること ← 正解
3. 多言語へ自動翻訳する専用の機能のこと
4. 文章を自動で複数人に一斉送信する機能のこと
解説：文字も画像もまとめて理解できるのがマルチモーダルだ。テキストしか渡せぬと思い込んで宝を眠らせる者はいねがー！？

Q5. 撮影したレシートの写真をGeminiに渡すとき、読み取り精度を上げる工夫として最も適切なのはどれ？
1. できるだけ暗い場所で斜めから小さく写す
2. 文字の一部が切れても気にせず撮る
3. できるだけ低い解像度で撮る
4. 明るい場所で真上から、文字がはっきり写るように撮る ← 正解
解説：AIとて読めぬほど暗く歪んだ写真はお手上げだ。明るく真上から鮮明に撮るのが下ごしらえよ。ボケ写真を渡して『読めない』と怒る者はいねがー！？ガハハ！
