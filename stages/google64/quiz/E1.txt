Q1. 毎月の顧客満足度アンケートを担当し、回答が届くたびシートへ手作業で写している。最も効果的な改善は？
1. フォームの「回答」タブでスプレッドシート連携（リンク）アイコンを押し、以後は自動追記させる ← 正解
2. 回答通知メールを印刷し、月末にまとめて手入力する
3. 回答が100件たまってからCSVを手動で書き出す
4. 回答をGoogleドキュメントに貼り付けて保管する
解説：「回答」タブの連携アイコンひとつで、以後の回答はシートへ勝手に流れ込むのだ、クルックー。写経のごとき手作業は即刻やめたまえ。

Q2. 会員と非会員で表示する設問を変えたい。Googleフォームで使うべき機能は？
1. 全員に同じ設問を出し、非会員には「答えないで」と注記する
2. 回答に応じて「セクションに移動」する分岐ロジックを設定し、出す設問を出し分ける ← 正解
3. フォームを2つ作り、両方のURLを全員へ送る
4. 回答後にシート側で不要な列を毎回手で削除する
解説：選択肢に「セクションへ移動」を仕込めば、答えに応じて道が分かれる分岐フォームになるのだ、クルックー。設計の段で仕込むのが賢者の作法なのだよ。

Q3. フォームと連携済みのシートを扱ううえで、正しい注意点はどれ？
1. 連携シートに手で列を挿入・削除すると以降の自動追記がずれる恐れがあるため、分析や加工は別シートで行う ← 正解
2. 連携シートは自動でロックされ、誰も編集できなくなる
3. 連携シートを編集すると、フォームの設問文まで書き換わる
4. 回答は1日1回まとめてしか反映されない
解説：回答が流れ込む器を勝手にいじれば列がずれて崩れるのだ、クルックー。原本の器はそのままに、加工は写しのシートで行いたまえ。

Q4. あとで関数やGeminiで集計しやすいアンケートにするための、報告書・設問設計のコツは？
1. できるだけ自由記述を多くし、回答者に自由に書かせる
2. 「はい/いいえ」も日付も1つの記述式にまとめて聞く
3. 選択式やプルダウンを活用し、1問1項目で集計しやすい形に設計する ← 正解
4. 設問に通し番号を付けず、毎回並び順を変える
解説：集計しやすさは設計の段で決まるのだ、クルックー。1問1項目・選択式で整えておけば、後の分析が滑らかなバターのごとく進むのだよ。

Q5. フォームとシートを自動連携しておく、実務上の一番の利点はどれ？
1. 回答者の顔写真が自動で集まる
2. 紙のアンケートより印刷代がかさむ
3. 回答が自動で暗号化され、本人以外は一切見られなくなる
4. 回答が届くたび即シートに反映され、締切直前でも最新状態で集計・グラフ化できる ← 正解
解説：余が愛でるのは即時性だ、クルックー。締切ぎりぎりの一票さえ最新の集計に乗る、それが自動連携の真価なのだよ。
