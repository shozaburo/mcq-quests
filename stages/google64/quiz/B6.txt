Q1. NotebookLMの回答に自動で付く番号付きの「引用（シテーション）」の役割はどれ？
1. 回答をより説得力のある文章に自動で書き換える機能
2. その答えの根拠が、どのソースのどこにあるかを示す ← 正解
3. 回答の文字数を数えて画面に表示する
4. 回答を自動で他言語に翻訳する
解説：引用は『この答えの元ネタはソースのここだ』と示す道しるべだ。根拠の見えぬ答えを丸呑みにする者はいねがー！？

Q2. 回答に「うちの規定では残業は事前申請」とあった。本当にそう書いてあるか確かめる最短の方法はどれ？
1. 同じ質問をもう一度打ち直して答えを見比べる
2. 社内の別の人に電話して口頭で聞く
3. 回答に付いた引用番号をクリックし、元ソースの該当箇所を確認する ← 正解
4. ネットで一般的な残業ルールを検索する
解説：引用番号を押せば元の一文へ一足飛びだ。クリック一つの確認すら惜しんで思い込みで動く怠け者はいねがー！？

Q3. 契約書チェックでNotebookLMの引用機能が「強い」とされる理由はどれ？
1. 契約書のひな形を自動で作成してくれるから
2. AIが法律の専門家として助言する資格を持つから
3. 引用が付く回答は内容が絶対に間違わないと保証されるから
4. 回答に原文の該当箇所という証拠が付き、確かめながら判断できるから ← 正解
解説：『証拠つきで答える』からこそ契約書や重要資料で頼れるのだ。ひな形作成や資格の話と取り違える者はいねがー！？

Q4. ネット全体を答えに使う一般的なAIチャットと比べた、NotebookLMの根本的な特徴はどれ？
1. 選択したソースを根拠に回答し、引用から原文を確認できる ← 正解
2. 常にインターネット全体の情報を最優先で使う
3. 回答が一切間違わないことが保証されている
4. 回答ごとに必ず人間の担当者が目視検品している
解説：資料に基づく回答と引用が持ち味だ！ただし、要約の誤りが消えるわけではない。番号を開いて自分で確かめるのだ！

Q5. 引用が付くNotebookLMでも、なお起こりうる落とし穴はどれ？
1. 引用番号を押しても、元ソースの該当箇所には移動できない
2. 回答の要約が、引用元の原文のニュアンスと微妙にズレることがある ← 正解
3. 引用が付いた回答は、ソース外の一般知識も自由に混ぜて答えている
4. 引用が付いていれば、原文を見なくても100%正しいと保証される
解説：引用が付いても、AIの要約は原文のニュアンスと微妙にズレることがある。だから要所は引用先の原文を覗くのだ。付いてれば100%と信じ込む者はいねがー！？ガハハ！
