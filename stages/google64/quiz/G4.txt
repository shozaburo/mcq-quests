Q1. 録音から起こした長い議事録を、NotebookLMで活かす最初の一手として正しいのは？
1. 議事録は機密なのでAIには入れず、手作業だけで要約する
2. 議事録を100行に分割し、1行ずつ別ソースとして登録する
3. 議事録をソースとして投入し、そのうえで抽出したい内容を問いかける ← 正解
4. 議事録を印刷して読み上げ、音声で全文を打ち直す
解説：まず議事録を陣に納め、しかる後に問いを放つ。陣を敷いてから攻める、順序を違えるでないぞ。

Q2. 議事録から実務に役立つ情報を引き出す問いかけとして、この教材が推奨する組み合わせはどれ？
1. 「主要決定事項を抽出」「未解決の論点をリスト化」「アクションアイテムを整理」と目的別に問う ← 正解
2. 「この会議は成功でしたか？」と感想を尋ねる
3. 「参加者の発言回数を数えて」と集計だけさせる
4. 「議事録を全部英訳して」とまず翻訳させる
解説：決定事項・未解決の論点・アクション、この三方から攻めるのだ。狙い定めた問いこそ良き答えを生む軍略なり。

Q3. アクションアイテム（ネクストアクション）を整理させるとき、指示に加えると実務でそのまま動ける要素は？
1. 全体の文字数を2000字以上に指定する
2. 箇条書きを禁止し、必ず長い文章で書かせる
3. アクションの数を必ず10個ちょうどに揃えさせる
4. 「誰が・いつまでに」担当者と期限をつけて整理させる ← 正解
解説：将と期日の定まらぬ軍令は動かぬ。「誰が・いつまでに」を付けてこそ、令は実を結ぶのだ。

Q4. 問いかけを「段階的に」行うよう勧められるのはなぜか。最も適切な理由は？
1. NotebookLMは1日1回しか質問できないから
2. 決定事項→論点→アクションと一つずつ確認する方が、抜け漏れなく会議内容を資産化できるから ← 正解
3. 一度にたくさん聞くと利用料金が高くなるから
4. 段階的に聞かないとソースが消えてしまうから
解説：一手ずつ段を踏んで問えば、漏れなく会議の実りを刈り取れる。焦らず着実に、徐かなること林の如しなり。

Q5. 2時間の定例会議の議事録から、翌週の動きに落とし込みたい。最も成果につながる進め方はどれ？
1. 議事録全文をそのまま関係者にメール転送して読ませる
2. 「決まったこと」だけAIに1回聞いて、それで終える
3. 議事録を投入し、決定事項→未解決の論点→担当者と期限つきアクション、の順に段階的に抽出させる ← 正解
4. 議事録は保存だけしておき、来週の会議で改めて議論し直す
解説：決定・論点・期日付きの動きへと段階で刈り取れば、会議は資産に変わる。話して終わりの軍議は勝ちを逃すぞ。
