Q1. 取引先から「打ち合わせしたい」と言われた。予約スケジュールのリンクを使うと、日程調整の手間はどう変わる？
1. 候補日を3つ挙げてメールし、相手の返信を待って調整する往復が残る
2. 予約ページのリンクを一度送れば、相手が空き枠を選んで確定まで進む ← 正解
3. 相手のカレンダーの空きをこちらで探し、こちらから予定を入れる
4. 電話で口頭確認したうえで、後からリンクを送って追認してもらう
解説：ZUNDA…（訳：リンクを一度送れば、候補日をやり取りする往復は消える。日程調整の畑を何度も耕し直す不毛を、リンク一本で終わらせるのだ）

Q2. 予約スケジュールを新しく作る。最初の入口として正しいのは？
1. Gmailの設定から「日程調整」をオンにする
2. Google Meetで会議室を先に発行し、そのURLを流用する
3. Googleカレンダーの「＋作成」から「予約スケジュール」を選ぶ ← 正解
4. Googleフォームで空き時間アンケートを作って集計する
解説：ZUNDA…（訳：入口はカレンダーの「＋作成」→「予約スケジュール」ただ一つ。種を蒔く畝を間違えれば、いくら待っても芽は出ないのだ）

Q3. 「毎週水曜の午後だけ相談を受け付けたい」。予約スケジュールでこれを実現する設定は？
1. 予約可能な曜日・時間帯（水曜午後）をあらかじめ枠として指定しておく ← 正解
2. 予約が入るたびに、その日時でよいか手動で承認する
3. 水曜以外に入った予約を、後からメールで断る運用にする
4. いったん全曜日で受け付け、水曜以外の枠を毎回手で閉じる
解説：ZUNDA…（訳：受け付ける曜日と時間帯を先に枠として囲うのだ。開ける畝を最初に決めておけば、望まぬ場所に客は入らぬのだ）

Q4. 相談予約を「1日3件まで・前後の予定と15分は間隔を空ける」で受けたい。予約スケジュールでの正しいやり方は？
1. 予約枠の設定で「1日の予約上限」と「予約の前後に空ける時間（バッファ）」を指定する ← 正解
2. 枠は無制限にしておき、4件目が入ったら手動で以降を閉じ、間隔も都度ずらす
3. 相談は先着1件のみ受け付ける設定にし、残りは翌日以降へ自動で送る
4. 勤務時間そのものを1日45分に縮めて、物理的に3件しか入らないようにする
解説：ZUNDA…（訳：予約枠の設定には「1日の上限」と前後の「バッファ」がある。手で閉じて回るのは畑を見張り続ける愚。最初に垣根の高さを決めておくのだ）

Q5. 有料の日程調整ツールに月額を払う同僚に勧める、最も的確な一言は？
1. 「Zoomの代わりになるからビデオ会議の費用が浮くよ」
2. 「Slackを入れれば、チャットのやり取りで日程が決まるよ」
3. 「Dropboxに空き時間表を置いて共有すれば調整できるよ」
4. 「Googleカレンダーで予約ページを作れる。使える機能はアカウントと契約を確認しよう」 ← 正解
解説：ZUNDA…（訳：個人アカウントでも予約ページを作れるが、複数の予約ページや自動リマインダー等には対象の契約が要る。使いたい機能を先に確認するのだ）
