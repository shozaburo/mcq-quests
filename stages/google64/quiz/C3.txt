Q1. 予定作成時に、通常の予定ではなく「フォーカスタイム」を選ぶと何が変わる？
1. その予定が自動的に全社員へ共有される
2. 対応アカウントでフォーカスタイムを作り、Google Chatの通知ミュートや会議の自動辞退を設定できる ← 正解
3. その時間はメールの送受信が一切できなくなる
4. 会議用のMeetのURLが自動で発行される
解説：ZUNDA…（訳：静かにできるのは設定に応じたGoogle Chatの通知。PCの通知全部が消えるわけではない。利用できるアカウントかも確認しよう）

Q2. 「重要な資料作成がいつも後回しになる」。この機能を使った実務的な対策は？
1. 資料作成の時間を、先にフォーカスタイムとしてカレンダーに確保する ← 正解
2. 毎朝気合を入れ直してから取りかかると決める
3. 資料作成は必ず残業時間に回すと決める
4. 資料作成の日は他の予定より優先し、割り込んで進める
解説：ZUNDA…（訳：先に時間を囲って取っておくのだ。畑の一角を最初に柵で守らねば、他人の予定という雑草に奪われてしまうのだ）

Q3. Google Tasksに溜まった「そのうちやる」タスクに、実際の作業時間を割り当てる操作は？
1. タスクを印刷して机に貼り、目につくようにする
2. タスク名をメールの件名にして自分宛てに送る
3. Googleカレンダーでタスクに日時を設定し、作業する時間を予定として確保する ← 正解
4. タスクは空き時間へ自動配置されるので、特に何もしない
解説：ZUNDA…（訳：タスクに日時を与え、カレンダー上で実際に取り組む時間を確認する。やることと時間を結び付けるのだ）

Q4. フォーカスタイムとTasksを1つのカレンダーで統合管理する狙いとして最も適切なのは？
1. 会議の数を強制的に減らすため
2. 上司に日々の進捗を自動で報告するため
3. 空いた時間へ予定を自動で埋めてもらうため
4. やるべきタスクと確保した作業時間を同じ画面で見渡し、計画の抜けを防ぐため ← 正解
解説：ZUNDA…（訳：タスクと時間を同じ帳面に載せてこそ計画が立つ。豆と畑を別々に数える者は、収穫の日を読み違えるのだ）

Q5. フォーカスタイムで集中を確保しても、同僚が構わず会議を入れてくる。より効果を上げる運用は？
1. フォーカスタイムを非公開にして、誰にも見えないようにする
2. その時間帯を「予定あり」として周囲に見せ、埋まっていると伝わるようにする ← 正解
3. 会議が入るたびにフォーカスタイムを削除して譲る
4. フォーカスタイムは平日を避け、休日にだけ設定する
解説：ZUNDA…（訳：埋まっていると周囲に見せてこそ柵は機能する。囲った畑も、垣根が見えねば人は平気で踏み入るのだ）
