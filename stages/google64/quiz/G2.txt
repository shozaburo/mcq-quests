Q1. 他のAIチャットと比べたNotebookLMの本質的な違いとして、最も的確なのはどれ？
1. 選択したソースに基づく回答と引用で、原文をたどって確認しやすい ← 正解
2. 常にインターネット全体を検索して最新情報で回答する
3. ソースの内容と一般知識を必ず半々で混ぜて回答する
4. ソースが古いと自動的にWebの新情報で上書きして回答する
解説：資料を根拠に問答できることが強みなり。ただし誤りがない保証ではない。引用と原文を照らし、条件や例外まで検めるのだ。

Q2. 総務担当が「うちの慶弔休暇は何日？」と正しい自社ルールを引き出したい。事前準備として不可欠なのは？
1. 準備は不要。NotebookLMは各社の就業規則を最初から知っている
2. 厚労省のモデル就業規則だけ入れれば自社規定も答えられる
3. 自社の就業規則・社内規程をソースとしてアップロードしておく ← 正解
4. 質問を一度英語にしてから入力する
解説：己の陣中の掟を問うなら、まず自社の規程を陣に納めよ。己を知らずして正しき答えは得られぬ。

Q3. 士業が顧客説明の根拠としてNotebookLMの回答を使う。信頼性の面で最も助かる特徴は？
1. 回答がそのまま法的効力を持つ正式文書になる
2. AIが正しさを保証してくれるので原本確認が不要になる
3. 回答が長文であるほど正確だと判定できる
4. 引用元が明示されるので、説明の根拠を即座にたどって確認できる ← 正解
解説：引用元が示されるゆえ、根拠を即座に検められる。動かぬこと山の如き説明は、確かな出典より生まれるなり。

Q4. ソースに一切書かれていない事柄を質問したとき、期待される正しい振る舞いは？
1. ソースに情報がない旨を示し、資料外の勝手な回答を作らない ← 正解
2. 一般知識から推測してそれらしい答えを必ず作り出す
3. 自動でWeb検索に切り替えて回答する
4. エラーになりノートブックが強制的に閉じる
解説：源にないことを埋めてよいわけではない。AIが不足を正しく判断する保証もないゆえ、資料の有無を自ら確認し、必要なら追加してから問い直すのだ。

Q5. 会議で「就業規則には副業について書いてあるはず」と主張が割れた。NotebookLMを使い、その場で決着させる賢い使い方は？
1. 記憶を頼りに、AIの一般論だけで結論を出す
2. 就業規則をソースに入れ「副業に関する規定を該当箇所とともに示して」と問い、引用元を全員で確認する ← 正解
3. とりあえず多数決で決め、後日総務に確認する
4. 副業の一般的なルールをWebで検索して代用する
解説：自社規程を源に問い、引用元を皆で検めて決着させよ。憶測の水掛け論は時を溶かす、一次情報で断ずるが将の器ぞ。
