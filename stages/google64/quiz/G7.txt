【G7】Studioのレポートを用いた要約・FAQ・ブリーフィング資料作成 - クイズ（サイト実装分）

出典：stages/google64/data/quests/G.js の G7
サイト版：quest.html?id=G7

Q1. NotebookLMの「Studioのレポート」機能は、どこから使えるか？
1. PC版のStudioパネルで「レポート」を選び、FAQやブリーフィング等の形式を指定して生成する ← 正解
2. Googleドライブの設定画面から有効化して使う
3. 有料の別アプリをインストールしないと使えない
4. 毎回サポート窓口にメールで生成を依頼する
解説：画面のStudioからレポートの形式を選ぶのだ。要約はチャットで頼むこともできる。欲しい資料の形に合わせて使い分けよ。

Q2. Studioのレポートで自動生成できるものの組み合わせとして正しいのはどれ？
1. 請求書・領収書・納品書
2. 契約書・定款・登記申請書
3. FAQ・ブリーフィング資料・学習ガイドなど ← 正解
4. 動画・BGM・イラスト
解説：レポートは用途に合う形式を選んで作る。すべてが一度に生成されるわけではないぞ。必要な一つから整え、元の資料と照らすのだ。

Q3. 分厚い業務マニュアルを新入社員にすばやく浸透させたい。Studioのレポートの活用として最も手早いのはどれ？
1. マニュアルを全ページ印刷して手渡す
2. 内容を口頭で毎回一から説明する
3. 全文を書き写してから渡す
4. マニュアルをソースに入れ、FAQや要約を自動生成して社内共有資料の元ネタにする ← 正解
解説：マニュアルを源として、FAQや要約を自動で生ませよ。新兵の教練を仕組みで行う、人は城の教えに適う道なり。

Q4. 目的に応じてStudioのレポートの出力を使い分けたい。狙いと出力の対応として最も適切なのはどれ？
1. 全体像を短く掴みたいときはFAQ、想定問答集が欲しいときは要約、会議前の要点共有には目次が向く
2. 会議前の要点共有には学習ガイド、想定問答集にはブリーフィング、全体像の把握には目次が向く
3. 想定問答集が欲しいときはFAQ、全体像を短く掴みたいときは要約、会議前の要点共有にはブリーフィングが向く ← 正解
4. どの目的でも、まず目次を1つ作れば要約もFAQもブリーフィングも不要になる
解説：要約は全体像、FAQは想定問答、ブリーフィングは会議前の要点。狙いに応じ武具を選び分けよ、それも兵法よ。

Q5. 毎週の部内共有会に向け、複数の報告書を短時間でまとめたい。Studioのレポートの活かし方として最も効率的なのはどれ？
1. 報告書を1枚ずつ手作業で書き写し、要点を自分で抜き出してから清書する
2. 複数の報告書をまとめてソースに入れ、要約やFAQを自動生成して共有資料の土台にする ← 正解
3. 報告書は入れず、共有会の場で全文を読み上げて口頭だけで共有する
4. 報告書ごとに別々のノートブックを作り、それぞれの音声概要だけを生成する
解説：複数の報告書も一つの陣に集め、要約とFAQで土台を築け。一枚ずつ手写しに時を溶かすは愚策、疾きこと風の如く仕上げるのだ。
