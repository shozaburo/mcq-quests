Q1. 発注表の「単位」欄を『個・箱・ケース』の3種だけに限定したい。適切な設定は？
1. データ → データの入力規則 で、プルダウン（リスト）を設定する ← 正解
2. 表示 → 固定 で列を固定する
3. 挿入 → 図形描画 で注意書きを描き添える
4. ファイル → 印刷設定 で範囲を絞る
解説：「データ」メニューの「データの入力規則」でリストを与えるのだ、クルックー。選ばせる形にすれば、はみ出す入力はそもそも生まれぬのだよ。

Q2. すでに「(株)」「株式会社」が混在してしまった台帳を、AI解析にかける前に整える手として最適なのは？
1. 気づいた人がその都度、目視で直す運用に任せる
2. 検索と置換や関数で表記を統一し、以後は入力規則で固定して再発を防ぐ ← 正解
3. セルの色を変えて目印にするだけにする
4. 混在したままGeminiに渡し、判断を丸投げする
解説：まず置換で乱れを正し、然るのち入力規則で門を固めるのだ、クルックー。掃除と再発防止は二段構えでこそ効くのだよ。

Q3. データの入力規則で制限できる内容として、正しい組み合わせはどれ？
1. フォントの種類とセルの背景色
2. 印刷の向きと用紙サイズ
3. リストの選択肢・日付・数値の範囲など、入力する中身の条件 ← 正解
4. 共有相手のメールアドレスだけ
解説：入力規則が縛るのは見た目の飾りではなく、中身の秩序だ、クルックー。リスト・日付・数値範囲で、器に入るものを選ぶのだよ。

Q4. 取引先名の表記を統一しておくと、Geminiに集計を任せたとき何が起きる？
1. 見た目が整うだけで、分析結果そのものは変わらない
2. AIの利用料金が自動で安くなる
3. AIが使えなくなり、手計算に戻る必要がある
4. 同じ取引先を同一のものとして正しく名寄せ・集計でき、分析の精度が段違いに上がる ← 正解
解説：「(株)」と「株式会社」が別物と数えられては帳簿が濁るのだ、クルックー。表記を揃えてこそAIの目は正しく物を見る、余の帝国も帳簿の秩序から始まったのだよ。

Q5. 数量欄にマイナスや文字を絶対に入れさせたくない。入力規則の使い方として適切なのは？
1. 数値かつ「0以上」を条件にし、範囲外の入力は拒否する設定にする ← 正解
2. 入力規則ではなく、セルを結合して物理的に防ぐ
3. 列全体を非表示にして誰にも触らせない
4. 入力後に毎回、担当者が目視で確認する
解説：「0以上の数値のみ、範囲外は拒否」と門番を立てるのだ、クルックー。誤りを叱るのではなく、そもそも入れさせぬのが上策なのだよ。
