Q1. 外出先で受け取った紙の書類を、その場でPDFにしてGoogleドライブへ保存したい。正しい操作はどれでしょうか？
1. ドライブアプリの「+」ボタンから「スキャン」を選んでカメラで撮影する ← 正解
2. スマホのカメラで写真を撮り、Googleフォトからドライブへ移動する
3. スマホで撮った写真を、Gmailで自分宛てに送ってから保存する
4. 書類を写真に撮り、画像ファイルのままドライブへアップロードする
解説：ドライブアプリのスキャンなら、切り抜きや向きを確認してPDFとして保存できるのじゃ。ページの欠けや文字の鮮明さを確かめてから納めるのう。

Q2. 10ページある契約書をスキャンします。後で扱いやすくする便利な使い方はどれでしょうか？
1. 1ページずつ別々のPDFにして、順番に番号を付けて保存する
2. 続けて全ページ撮影し、1つのPDFに結合して保存する ← 正解
3. 1ページ目だけスキャンし、残りは後で追加する前提で省く
4. 全ページを縮小して1枚の画像に収める
解説：続けて撮れば1冊のPDFにまとまるのじゃ。バラバラの別ファイルにすると後で順番が分からなくなり、1枚に縮めれば文字がつぶれて読めん——束ねて1冊、これが肝心よ。ね、兄者？「うむ」

Q3. スキャンしたレシートを、後でGeminiに読ませて経費精算を手伝ってもらいたい。そのために大切なことはどれでしょうか？
1. レシートは白黒2値で撮らないとAIが読めない
2. レシートは影を強く付けて立体的に撮る
3. 文字認識(OCR)が効くよう鮮明に撮り、中身の分かるファイル名を付けて保存する ← 正解
4. レシートを複数枚まとめて1枚に重ねて撮る
解説：読み取れる鮮明な画像と中身の分かる名前、この二つが揃えばAIが経費の山を耕してくれるのじゃ。影が濃かったり複数枚を重ねたりすると文字が拾えん——明るく平らに、1枚ずつが賢い撮り方よのう。

Q4. この直接スキャン機能が、中小企業の実務で特に威力を発揮する場面はどれでしょうか？
1. 社内の大型複合機のトナーを節約したいとき
2. 過去に紙で保管した書類を、年度末にまとめて電子化したいとき
3. 手書きメモを清書して、きれいな印刷物に仕上げたいとき
4. 外出先で受け取った書類やレシートを、その場でデータ化して即保存したいとき ← 正解
解説：出先で受け取った紙を、その場でドライブに納められるのが真骨頂じゃ。机に持ち帰って山にする前に片づける、それが紙仕事に勝つ道——まとめて後で、では結局たまってしまうからのう。

Q5. 手書きのアンケート用紙をスキャンしてPDF化しました。集計担当が中身のテキストを取り出しやすくするには、次に何をするのが実務的でしょうか？
1. GeminiなどにPDFのテキスト化・表形式への整理を依頼し、読み取り結果を原本と照合する ← 正解
2. PDFを印刷し直して手作業で書き写す
3. PDFをそのまま共有し、各自に目視で数えてもらう
4. PDFを画像に変換してから拡大表示する
解説：手書きは数字や名前を取り違えることがあるのじゃ。AIに下ごしらえを任せたら、原本と照合する。読めぬ箇所を推測で埋めさせぬのが大切よのう。
