Q1. 競合5社を比較する調査を任された。GeminiのDeep Researchの最大の利点はどれ？
1. 検索結果のリンク一覧を出すだけで、内容の比較は自分で行う
2. 調査計画に沿って複数の情報源を調べ、出典付きのレポートにまとめる ← 正解
3. 1つのサイトだけを深く読み、要点を一行に要約してくれる
4. 調べる前に、比較する競合名と結論をこちらが全部書いて渡す必要がある
解説：まず計画を確かめて調査を始めるのだ。所要時間や調べる情報源の数はテーマで変わる。出てきた結論は根拠と照らすのだぞ！

Q2. Deep Researchを実行すると、いきなり調べ始めず先に「調査計画」を出してくる。この計画を確認する意味として最も適切なのはどれ？
1. 計画の文字数に応じて調査時間が自動で短くなるから
2. 計画を承認するまで他の機能が一切使えなくなるから
3. 調査の方向がずれていないか、着手前に軌道修正できるから ← 正解
4. 計画は表示専用で、内容に手を加えることはできないから
解説：計画は『この方向で調べるぞ』の宣言だ。ずれていれば着手前に直せる大事な関所なのだ。読まずにポチッと承認する怠け者はいねがー！？

Q3. Deep Researchのレポートについて、実務で知っておくべき正しい理解はどれ？
1. 有料機能なので、書かれた数字や結論に誤りは一切ない
2. AIが巡回したページは、すべて公式の一次情報に限られる
3. 出典が付くので、レポートの内容は常に最新に保たれる
4. Web上の情報を自動で要約したものなので、出典は付くが元記事のニュアンスとズレる場合がある ← 正解
解説：Deep Researchは集めた情報の要約だ。出典は付くが、元記事のニュアンスとズレることもあると忘れるな。有料だから完璧と過信する者はいねがー！？

Q4. 次のうち、Deep Researchを使うのが最も適した業務はどれ？
1. 新規参入したい市場の規模・主要プレイヤー・トレンドを広く調べたいとき ← 正解
2. 自社の勤怠データを集計したいとき
3. 取引先に送る一通のお礼メールを整えたいとき
4. 今日の会議室を予約したいとき
解説：多数のサイトにまたがる市場調査こそDeep Researchの本領だ。表計算やメール一通に使うのは牛刀だぞ。使いどころを外す者はいねがー！？

Q5. Deep Researchで思ったより浅いレポートが出た。実務で質を上げる工夫として最も適切なのはどれ？
1. 何も指定せず「調べて」とだけ繰り返す
2. 調査の目的・比較したい観点・対象範囲を具体的に指定してから再実行する ← 正解
3. レポートが浅いのは仕様なので改善は諦める
4. 質問文をできるだけ短くして曖昧にする
解説：目的と観点を絞って渡せば掘る深さが段違いだ。『なんとなく調べて』で浅いと嘆く注文下手はいねがー！？ガハハ！
