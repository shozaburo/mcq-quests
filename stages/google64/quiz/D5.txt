【D5】チーム共同執筆：スマートチップでの担当割り振りと、提案モードを使った効率的なレビュー - クイズ（サイト実装分）

サイト版：quest.html?id=D5

Q1. Googleドキュメントでスマートチップを挿入して担当者を割り振るには、どうすればよいか？
1. 人物チップは「@名前」で挿入し、Tasksへの割り当ては「@task」やチェックリストから担当者を指定して行う ← 正解
2. 担当者の名前を太字にして黄色マーカーを引く
3. ドキュメントの共有設定で「オーナー権限」を全員に渡す
4. コメント欄に担当者の社員番号を書き込む
解説：名前のチップだけではタスク割り当ても共有も完了せぬ。仕事用・学校用アカウントのタスク機能で担当者を指定し、文書の共有も確認するのである。

Q2. 他人の文書をレビューするとき、元の文を勝手に消さずに修正案を残したい。使うべき機能はどれか？
1. 編集モードのまま直接書き換えて、変更点は口頭で伝える
2. 閲覧モードに切り替えて頭の中だけで修正を覚えておく
3. 文書を丸ごとコピーして別ファイルで直し、後で差し替える
4. 編集モードを「提案モード」に切り替え、変更履歴を残しながら修正する ← 正解
解説：編集モードを「提案モード」に切り替えれば履歴を残してレビューできる！相手の文を尊びつつ直す、共同執筆の礼儀だ！

Q3. 提案モードで残した修正を、最終的に文書へ反映するかどうかを決めるのは誰か？
1. 閲覧権限しかない人でも、誰でも承認できる
2. 文書の編集権限を持つ人が提案を承認・却下する。担当者の運用ルールも決めておく ← 正解
3. Geminiが自動で良し悪しを判定して反映する
4. 提案から24時間経つと全て自動で反映される
解説：編集権限があれば承認・却下できるのである。提案した本人が編集者なら本人も承認できる。最終判断を誰が担うかは、チームで決めるのである。

Q4. Googleドキュメントの提案モードに似た、Wordの機能はどれか？
1. 差し込み印刷機能
2. マクロ記録機能
3. 校閲（変更履歴）機能 ← 正解
4. アウトライン表示機能
解説：Wordの変更履歴に似た、修正案を残して確認するための機能である。「上位互換」と決めつけず、各ツールの機能を確かめて使うのである。

Q5. 提案モードでレビュー中の「修正内容」の扱いについて、正しく理解しているのはどれか？
1. 提案モードでの変更は即座に本文に確定し、元には戻せない
2. 提案は承認されるまで元の文が保持され、却下すれば元のまま残る ← 正解
3. 提案モードでは他人が付けたコメントを一切見ることができない
4. 提案モードにすると、それまでの編集履歴が全部消えてしまう
解説：提案は承認まで元の文を保ち、却下すれば元のまま！確定と勘違いして慌てるな、仕組みを知る者は転ばぬ！
