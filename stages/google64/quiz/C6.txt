【C6】コンパニオンモードと画面共有（タブ・ウィンドウ別）の使い分け技術 - クイズ（サイト実装分）

Q1. 同じ会議室に集まった数人が、各自の手元PCからもMeetに入りたい。ハウリングを防ぐ正しい参加方法は？
1. 全員がイヤホンをつければ、通常参加のままでよい
2. PCのスピーカー音量を最小にして、通常参加する
3. 各自「コンパニオンモード」で参加する ← 正解
4. PC参加者はカメラだけをオフにして参加する
解説：ZUNDA…（訳：会議室＋手元PCはコンパニオンモード。マイクとスピーカーが同じ部屋で重なれば音は暴れる。一つの畑に鍬は二本要らぬのだ）

Q2. コンパニオンモードの用途として、正しい理解は？
1. 自宅から高画質で参加するための特別モード
2. 会議室にいながら、手元PCで資料共有やチャット参加をするためのモード ← 正解
3. スマホ専用の、通信量を抑える省データモード
4. 音声だけで参加する、電話会議用のモード
解説：ZUNDA…（訳：会議室の人が手元PCで共有やチャットに加わるためのもの。体は一つの畑に置き、手はもう一つの畝へ伸ばせるのだ）

Q3. 画面共有で「見せたくない情報の映り込み」を最も防げるのはどの方式？
1. 見せたい資料の「タブのみ」を共有する ← 正解
2. 「画面全体」を共有する
3. デスクトップの「ウィンドウ」単位で共有する
4. どれを選んでも、相手に映る範囲は変わらない
解説：ZUNDA…（訳：「タブのみ」が最も安全。見せたい一枚の葉だけ差し出せば、畑の裏側までは覗かれぬのだ）

Q4. つい「画面全体」を共有したまま進めたとき、実際に起こりがちな事故は？
1. 会議の録画が自動で停止する
2. 音声が二重に聞こえてハウリングする
3. 共有画質が勝手に落ちて、文字が読めなくなる
4. 他のタブやSlackなどの通知ポップアップが、相手に見えてしまう ← 正解
解説：ZUNDA…（訳：画面全体では他のタブも通知も映り込む。蔵の扉を全開にすれば、見せたくない豆袋まで晒されるのだ）

Q5. プレゼン資料と、その場で開く参考ページを行き来しながら見せたい。安全さと使い勝手のバランスが良いのは？
1. 念のため「画面全体」を共有しておく
2. 見せたいページを開いた「ウィンドウ」単位で共有し、その中だけを行き来する ← 正解
3. 共有はせず、口頭ですべて説明する
4. 1ページごとに共有を止め、別タブで開き直す
解説：ZUNDA…（訳：資料をまとめた「ウィンドウ」ごと差し出せば、その中は自在に、外は隠せる。柵の内で自由に歩けるようにするのだ）
