Q1. 翻訳字幕を利用できるアカウントで、英語の会議に日本語の字幕を表示したい。Meetでの正しい手順は？
1. 別の翻訳アプリを起動し、スマホをスピーカーに向ける
2. 主催者に、日本語で話してもらうよう頼む
3. チャット欄に「日本語でお願いします」と書き込む
4. 設定 → 字幕（キャプション） → 翻訳字幕を有効にする ← 正解
解説：ZUNDA…（訳：設定→字幕→翻訳字幕で、英語の会議も日本語で追える。言葉の壁は、いまや畑の垣根より低いのだ）

Q2. AI背景生成を利用できるアカウントでMeetに参加します。背景機能の正しい理解は？
1. 用意された画像のほか、AIで背景を生成して使うこともできる ← 正解
2. 背景の変更は有料プランでも不可能で、物理的な衝立が要る
3. 背景に使えるのは、自分で事前に撮影した写真だけである
4. 背景を変えると、必ず画質が落ちて実用に耐えない
解説：ZUNDA…（訳：背景はAI生成も選べる。散らかった畑は見せず、望む景色をまとえばよい。見た目もまた餡の包み方なのだ）

Q3. Meetのノイズ除去が実際に抑えてくれる音の例として、正しいのは？
1. 自分の話し言葉の、言い間違いそのもの
2. キーボードの打鍵音、ドアの開閉など、話し声以外の周囲の音 ← 正解
3. 相手側の回線遅延による、音飛びやプツプツ音
4. 自分がBGMとして流している音楽だけ
解説：ZUNDA…（訳：打鍵音などを抑える機能だ。人の話し声やテレビの声まで消えるとは限らない。静かな場所やマイクの位置も大切なのだ）

Q4. 翻訳字幕・AI背景・ノイズ除去に共通する、導入のうれしさは？
1. 会議に参加できる人数の上限が増える
2. 会議データの保存容量が節約できる
3. 利用可能な機能をMeet内で設定して、会議を聞き取りやすく、見やすくできる ← 正解
4. 議事録が自動で多言語へ翻訳される
解説：ZUNDA…（訳：翻訳字幕やAI背景などは、対象プラン・言語・管理者設定で利用条件が異なる。表示されないときは条件を確認しよう）

Q5. 英語会議で翻訳字幕を頼りに商談を進める。字幕はリアルタイム処理で、数字や社名を取り違えることがある。実務上の心得は？
1. 契約金額・日付・固有名詞は字幕任せにせず、口頭やチャットで復唱して確認する ← 正解
2. 字幕はリアルタイムでも正確なので、表示された金額のまま合意して先へ進める
3. 精度を上げるため、字幕表示中は自分のマイクを常にミュートにしておく
4. 字幕が追いつくよう、相手に終始できるだけゆっくり話し続けてもらう
解説：ZUNDA…（訳：字幕は道を照らす提灯であって、道そのものではない。リアルタイムの訳は数字や名を取り違える。金額と固有名だけは、相手の口でもう一度確かめるのだ）
