【A8】メール添付に頼らないドライブリンクによる大容量データ共有 - クイズ（サイト実装分）

Q1. 50MBの動画を取引先にメール添付しようとしたら送れませんでした。ドライブリンクで共有する、メール添付にない決定的な強みはどれでしょうか？
1. メール添付の容量上限を超えるファイルもリンクで案内でき、共有後にアクセス権を変更できる ← 正解
2. 送信と同時に、相手のダウンロードが自動で始まる
3. 相手がファイルを開くと、開封通知が必ず自分に届く
4. リンクなら相手はGoogleアカウントがなくても必ず編集できる
解説：Driveの保存容量やファイル上限はあるが、添付の上限を超える荷物を案内できるのじゃ。後でアクセス権は取り消せる。ただし、相手が既に保存したコピーまでは回収できぬぞ。

Q2. ドライブで相手のアクセス権を確認しながら共有リンクを取得する操作はどれでしょうか？
1. ファイルをブラウザのアドレスバーにドラッグする
2. ファイルをダウンロードしてから、相手に添付し直す
3. ファイルを右クリックして「共有」からリンクを取得する ← 正解
4. ファイルを開いた状態のURLを、そのままコピーして送る
解説：共有画面を開けば、相手の権限を確認してリンクをコピーできるのじゃ。アドレスバーのURLでも、共有画面のリンクでも、開けるかはアクセス権で決まる。リンクを写すだけでは権限は増えぬのう。

Q3. 機密の見積書をリンク共有します。関係者以外の目に触れさせない、最も安全な設定はどれでしょうか？
1. 「リンクを知っている全員(閲覧者)」にして、相手にだけURLを伝える
2. 「リンクを知っている全員」にしつつ、ファイル名を分かりにくくする
3. 「制限付き」にした上で、リンクをパスワード付きZIPで送る
4. 「制限付き(指定したユーザーのみ)」にし、相手のアドレスを指定する ← 正解
解説：「制限付き」で相手を名指しするのが安全な渡し方じゃ。「全員」設定はURLが一度漏れた瞬間に誰の手にも扉が開く、名前を隠しても鍵にはならん——指定した相手だけを通すのが確かよのう。

Q4. Gmailで容量の大きいファイルを添付しようとすると、Googleはどう振る舞うでしょうか？
1. 添付を自動で複数のメールに分割して送信する
2. 容量超過の添付を、自動でGoogleドライブのリンクに変換して送ってくれる ← 正解
3. 添付ファイルを自動で圧縮し、容量内に収める
4. 送信を保留し、相手が受信可能になるまで待機する
解説：大きすぎる荷物は、Gmailが気を利かせてドライブのリンクに載せ替えてくれるのじゃ。分割も圧縮もせず、そっと蔵に置いて道しるべを渡す仕組み——慌てず流れに任せればよい、寛大なものよのう。

Q5. 半年前に社外へリンク共有した資料が、まだ相手に見られる状態のまま残っていることに気づきました。情報管理として取るべき対応はどれでしょうか？
1. 共有設定を開き、不要になった相手の権限を削除する(またはリンクを制限に戻す) ← 正解
2. 新しいリンクを送り直せば、古いリンクは自動的に無効になる
3. ファイル名を変更すれば、相手はリンクを開けなくなる
4. ファイルを別のフォルダへ移動すれば、共有は自動で解除される
解説：不要な相手は共有設定から外すのじゃ。名前の変更や移動を、権限の解除の代わりにしてはならぬ。グループや親フォルダからのアクセスも確認するのう。ね、兄者？「うむ」
