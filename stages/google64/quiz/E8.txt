【E8】GAS（Google Apps Script）基礎：フォーム送信後の通知やメール自動配信 - クイズ（サイト実装分）

出典：stages/google64/data/quests/E.js の E8
サイト版：quest.html?id=E8

Q1. スプレッドシートからGAS（Apps Script）の編集画面を開く、正しい手順は？
1. データ → データの入力規則
2. 挿入 → ピボットテーブル
3. 拡張機能 → Apps Script ← 正解
4. ファイル → バージョン履歴
解説：「拡張機能」メニューの「Apps Script」だ、クルックー。ここが自動化の工房への裏口なのだよ。

Q2. GASで書くコードについて、正しい説明はどれ？
1. JavaScript風のコードで、Googleの各サービスを操作・自動化できる ← 正解
2. Excel専用のマクロ言語なので、Googleでは動かない
3. 日本語で命令を書けば、必ずそのまま動く
4. コードは書けるが、保存はできない仕組みである
解説：GASはJavaScript風の言語、フォームもメールもChatも操れるのだ、クルックー。Googleの城内を自在に駆ける伝令なのだよ。

Q3. GASのトリガーには種類がある。「フォームが送信された瞬間に担当者へ通知メールを送る」自動化に選ぶべきトリガーの種別はどれ？
1. 毎日決まった時刻に自動で動く「時間主導型」トリガー
2. スプレッドシートのセルが手で編集されたときに動く「編集時」トリガー
3. フォームの回答が送信されたことをきっかけに動く「フォーム送信時」トリガー ← 正解
4. スプレッドシートを開いた瞬間に動く「起動時（開いたとき）」トリガー
解説：早馬にも役目の違いがあるのだ、クルックー。刻限で駆けるは時間主導型、編集で目覚めるは編集時、この用向きに合うのは回答の到着で動く「フォーム送信時」よ。仕掛けと引き金を取り違えるでないぞ。

Q4. プログラミング未経験の担当者がGASを始めたい。講座で勧められている、現実的な第一歩は？
1. JavaScriptの分厚い専門書を読破してから着手する
2. 未経験者にGASは無理なので、外注一択と考える
3. 「GASでフォーム送信時に〇〇へ通知するコードを書いて」とGeminiに頼み、書いてもらう ← 正解
4. 他社のコードを無断で持ってきて、そのまま使う
解説：書き方を知らずとも「〇〇するコードを書け」とGeminiに命じればよいのだ、クルックー。小さな自動化から、良きバターのごとくじっくり育てたまえ。

Q5. 書いたGASを初めて実行すると「承認が必要です」と表示された。正しい対応は？
1. 危険な兆候なので、二度と実行しない
2. 自分のアカウントで権限を承認し、メール送信などの操作許可をスクリプトに与える ← 正解
3. パソコンを再起動してから、もう一度試す
4. コードをすべて日本語に書き換えてから実行する
解説：初陣のスクリプトには権限の許しが要るのだ、クルックー。自らのアカウントで「承認」と告げ、メールを送る力を家臣に授けたまえ。
