Q1. Geminiに実務で使えるプレゼン構成案を出させたい。最も良い頼み方はどれ？
1. テーマ・対象・持ち時間15分を伝え、「構成案を3パターン出して」と条件をそろえて頼む ← 正解
2. 「かっこいいプレゼンの構成を、できるだけ詳しく丁寧に考えて」と念入りに頼む
3. 「15分のプレゼンの構成を考えて」と持ち時間だけ指定して頼む
4. 「対象は新入社員、いい感じにまとめて」と相手だけ伝えて頼む
解説：あら、丁寧に「詳しく」と願っても、中身の条件が無きゃAIは迷子よ。テーマ・相手・持ち時間をそろえて3案出させる……何を伝えるかが勝負なの。言葉数じゃないのよ。

Q2. AIの構成案が途中で話の筋が飛んでしまう。詳細で挙げられている、論理破綻を防ぐコツはどれ？
1. 専門用語をできるだけ多く盛り込ませる
2. 1回の指示で確定させ、修正は加えない
3. SCQA・PREP・起承転結など「型」を指定して作らせる ← 正解
4. とにかくスライドの枚数を増やす
解説：ふふ、SCQAやPREP、起承転結……「型」を指定するの。骨組みがあれば話は崩れない。仕立てと同じで、型紙があるから形になるのよ。

Q3. 構成を「3パターン提案して」と頼むことの一番のメリットはどれ？
1. パターン数が多いほどAIの回答精度そのものが上がる
2. 複数を見比べて、自分の目的に一番合うストーリーを選べる ← 正解
3. 3案をすべてつなげて長編プレゼンにできる
4. AIの利用料金が割引になる
解説：選択肢は多いほうがいいに決まってるじゃない。並べて見比べて、目的に一番似合う一着を選ぶ……それが大人の買い物ってものよ。

Q4. AIが最初に出した構成が、少し狙いとずれていた。詳細に沿った進め方はどれ？
1. 最初の提案をそのまま使うのが鉄則
2. やり取りは1往復だけにとどめる
3. 気に入らなければ毎回別のAIに乗り換える
4. 「もっと課題を強調して」など注文をつけ、対話で寄せていく ← 正解
解説：一発で完璧なんて期待しないことね。ずれたら注文をつけて、対話で寄せるの。直しを重ねてこそ、身体に合うドレスになるのよ。

Q5. 持ち時間は15分なのに、AIの構成案が明らかに盛り込みすぎだった。詳細の考え方に沿った対処はどれ？
1. 「15分に収まる分量で、要点を絞って再構成して」と持ち時間を基準に調整させる ← 正解
2. 情報は削らず、本番で早口にして詰め込む
3. 分量が多いほど中身が濃いので、そのまま使う
4. 持ち時間の指定はAIには通じないので考慮しない
解説：あら、盛りすぎは自慢にならないのよ。「15分に収めて」と時間を基準に絞らせるの。早口で押し込むなんて、聞くほうが息切れするわ。引き算も構成の腕よ。
