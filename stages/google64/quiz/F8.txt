【F8】配布資料の最適化（PDF出力）と安全な共有・公開権限の適切な管理 - クイズ（サイト実装分）

出典：stages/google64/data/quests/F.js の F8
サイト版：quest.html?id=F8

Q1. 取引先に、レイアウトを崩さず・編集させず、どの環境でも同じ見た目で資料を渡したい。最も適した方法はどれ？
1. ファイル→ダウンロード→PDF でPDF化して渡す ← 正解
2. 編集できるGoogleスライドのリンクを、そのまま送る
3. 各スライドをスクリーンショットして、画像で送る
4. PowerPoint形式で書き出して送る
解説：見た目を固めて編集も防ぐなら、PDFが正装よ。編集リンクじゃ触られ放題、スクショは粗くなる、PowerPointは相手の環境でずれることもあるの。どの画面でも同じ姿で届くのがPDFの気品ってわけ。

Q2. 資料を共有するとき、慎重に選ぶべき設定はどれ？
1. スライドの背景色
2. 使用フォントの埋め込み設定
3. 「閲覧者（コメント不可）」や「リンクを知っている全員」などの権限範囲 ← 正解
4. ファイル名の長さ
解説：「閲覧者」にとどめるか、「リンクを知っている全員」まで開くか……権限範囲こそ慎重に選ぶところよ。ドレスコードと同じ、入れる人は選ばなきゃ。

Q3. 社外秘の資料を、期間限定で取引先に見せたい。詳細で挙げられている方法はどれ？
1. 全員に編集権限を付けて、自由に直してもらう
2. 「リンクを知っている全員」で公開し、URLだけ伏せておく
3. パスワードをスライドの1枚目に書いておく
4. 対象の仕事用・学校用アカウントなら有効期限を設定し、使えない場合は期限を管理して手動で権限を外す ← 正解
解説：有効期限を付けられるかはアカウントの条件次第よ。使えなくても、終了日を決めて権限を外す運用にできるわ。開けた扉の後始末までが共有なの。

Q4. 「リンクを知っている全員」に設定した場合のリスクとして、正しいのはどれ？
1. ファイルが一定期間で自動削除される
2. 閲覧者に編集権限が自動で付いてしまう
3. リンクが転送されると、意図しない相手まで閲覧できてしまう ← 正解
4. PDF出力ができなくなる
解説：リンクは転送された瞬間、あなたの手を離れるの。意図しない相手にまで届く……噂と同じで、広まってからじゃ止められないのよ。

Q5. 特定の担当者3名だけに見せたい機密資料がある。最も安全な共有の仕方はどれ？
1. 「リンクを知っている全員」にして、3名にだけURLを送る
2. 3名のメールアドレスを指定し、閲覧者として個別に共有する ← 正解
3. 誰でも編集可にして、本人たちに任せる
4. 全社の共有フォルダに置いておく
解説：見せたい相手が決まってるなら、アドレスを名指しで招くのが一番よ。リンク任せは危ういの……招待客は名前で呼ぶのが上品ってものでしょう。
