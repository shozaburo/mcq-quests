Q1. 取引先から「あなたのアドレスから不審なメールが届いた」と連絡がありました。乗っ取りの疑いがあるとき、まず打つべき最も効果的な一手はどれでしょうか？
1. パスワードを変更し、不審な端末・設定を確認して、2段階認証も整える ← 正解
2. 送信済みメールをすべて削除し、しばらく送信を控える
3. 全端末からいったんサインアウトし直して様子を見る
4. 迷惑メールフィルタを強化して不審なメールを弾く設定にする
解説：乗っ取りが疑われるなら、パスワード変更だけで終わらせぬことじゃ。不審な端末や転送設定も確認する。入れぬときは公式のアカウント復元へ進むのじゃ。

Q2. 2段階認証を設定するための管理画面の、正しい入口はどこでしょうか？
1. Gmailの「設定」→「アカウントとインポート」から開く
2. myaccount.google.com の「セキュリティ」→「2段階認証プロセス」から開く ← 正解
3. Chromeの「設定」→「同期とGoogleサービス」から開く
4. Googleドライブの「設定」→「セキュリティ」から開く
解説：アカウント全体の守りは myaccount.google.com のセキュリティ、ここが正しい玄関じゃ。Gmailやドライブの設定は、それぞれの部屋の戸締まりでしかないからのう。

Q3. 出張中にスマホを紛失し、認証コードを受け取る端末がなくなってしまいました。事前に備えていれば締め出されずに済んだものはどれでしょうか？
1. パスワードをできるだけ長く複雑にしておくこと
2. ログイン履歴を毎日確認する習慣をつけておくこと
3. 発行したバックアップコードを安全な場所に保管しておくこと ← 正解
4. 認証手段を認証アプリ1つに絞っておくこと
解説：スマホを失くしても、控えておいたバックアップコードがあれば扉を開けられるのじゃ。手段を1つに絞りきると、それを失った日に泣きを見る——備えは大地の恵みのように蓄えておくものよのう。

Q4. 総務のあなたは仕事用と個人用のGoogleアカウントを両方使います。書類の保存先を取り違える事故を減らす、実務的に良い方法はどれでしょうか？
1. 個人用アカウントを削除して1つにまとめる
2. ブラウザのプロファイルを分け、アカウントごとに使う環境を切り替える ← 正解
3. 両方に同じパスワードを設定して管理を簡単にする
4. 仕事のファイルを個人アカウントにも複製して二重に持つ
解説：環境ごと分けておけば、仕事の書類を私物の棚にうっかり仕舞う事故が減るのじゃ。同じパスワードや丸ごと複製は、かえって漏れの危うい橋になるからのう。ね、兄者？「うむ」

Q5. 認証アプリとSMS(電話番号)を2段階認証の手段として比べたとき、より安全性が高いとされる考え方はどれでしょうか？
1. 手段は1つに絞り、予備は持たないほうが漏洩経路が減る
2. SMSは電話番号を知られていなければ破られないので最も安全
3. パスワードが複雑なら認証手段は何を使っても同じ
4. 認証アプリを主に使いつつ、バックアップコードも別途控えておく ← 正解
解説：SMSは電話番号の乗っ取り(SIM乗っ取り)で抜かれることがある、だから認証アプリを軸に据えるのじゃ。いざという時のバックアップコードも忍ばせておけば堅い守りよのう。
