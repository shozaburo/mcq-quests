【B5】多様なソース（PDF/URL/Googleドライブ）のインポートと管理 - クイズ（サイト実装分）

Q1. NotebookLMを初めて使う。正しいスタート手順はどれ？
1. 新しいノートブックを作らず、Geminiに質問するだけで全社内資料が取り込まれる
2. notebooklm.google.com を開き、新規ノートブックを作ってソースを追加する ← 正解
3. アプリストアで専用アプリを購入してインストールする
4. Googleへ利用申請書をメールで送って許可を待つ
解説：notebooklm.google.com から新しいノートブックを作り、必要なソースを追加するのだ。目的に合う資料を選ぶところから始めるのだぞ！

Q2. 新製品企画のために、社内PDF・参考サイトのURL・議事録のGoogleドキュメントを扱いたい。NotebookLMの正しい理解はどれ？
1. PDFしか取り込めないので他は諦める
2. URLは取り込めないので手で本文を貼り付ける
3. PDF・URL・YouTube・Googleドキュメントなどを1つのノートブックに混在させて取り込める ← 正解
4. 1つのノートブックにはソースを1個しか入れられない
解説：PDFもURLもYouTubeもドキュメントも、混ぜて1つに取り込めるのが強みだ。PDFしか入らぬと思い込む食わず嫌いはいねがー！？

Q3. 1つのノートブックに追加できるソースの数について、実務で正しい理解はどれ？
1. 上限は一切なく、無制限に追加できる
2. 追加できるソースは常に1個だけに固定されている
3. 全ユーザー共通で永久に3個に固定されている
4. 利用プランごとに上限があるので、現在の上限を確認し、必要なら案件ごとにノートブックを分ける ← 正解
解説：資料の器には上限があるぞ！上限の数字は公式の利用条件で確認し、必要な資料を選ぶのだ。分けたノートブックを一度に横断して答えるわけではないぞ！

Q4. 複数プロジェクトの資料をNotebookLMで扱う。後から探しやすくする管理のコツはどれ？
1. プロジェクトごとにノートブックを分けて作る ← 正解
2. 全プロジェクトの資料を1つのノートブックに全部混ぜる
3. 資料は取り込まず毎回その場で質問文に貼る
4. ノートブックは作らずメモ帳で管理する
解説：テーマごとにノートブックを分けてこそ、後で迷わず引ける。何もかも一緒くたに放り込んで探し物に半日費やす者はいねがー！？

Q5. 取り込んだPDFの内容が古くなり、新しい版に差し替えたい。管理として最も適切なのはどれ？
1. 古いソースはそのまま残し、新旧が混ざっても気にしない
2. 古いソースを外して新しいPDFを追加し、常に最新だけを参照させる ← 正解
3. ノートブックごと消して一から作り直すしかない
4. PDFは一度入れたら差し替えられないので諦める
解説：古い版を残せばAIは古い情報でも答えてしまうぞ。差し替えて最新だけを食わせるのが管理の要だ。古い資料を放置して誤答を招く者はいねがー！？ガハハ！
