Q1. Google MeetでGeminiに議事録を作らせたい。いつ、何をするのが正しい？
1. 会議が終わってから、録画ファイルを手動でGeminiにアップロードする
2. 対象プランと管理者設定を確認し、Meetの「Geminiによるメモ作成」を開始する ← 正解
3. 会議中、発言をすべて自分でチャット欄に打ち込んでおく
4. 議事録係を1人決め、その人にGeminiの画面を共有させる
解説：ZUNDA…（訳：メモ作成・録画・文字起こしは別の機能。必要なものを開始し、参加者にも知らせよう。利用には対象プランや管理者設定の確認が要る）

Q2. 議事録機能をONにして会議を終えると、成果物はどこに、どんな形で残る？
1. 録画データがそのまま参加者全員にメール送信される
2. 文字起こしがチャット欄に流れるだけで、保存はされない
3. 要約・決定事項・タスクがまとまったGoogleドキュメントが自動生成される ← 正解
4. 議事録がPDF化され、印刷キューへ送られる
解説：ZUNDA…（訳：終了後、要約・決定事項・タスクがドキュメントに実る。収穫も脱穀も済ませて蔵に納めてくれるのだ）

Q3. クライアントとの重要な商談でこの機能を使う、最大の実務メリットは？
1. メモ取りから解放され、相手の話と交渉そのものに集中できる ← 正解
2. 会議の所要時間が自動的に半分に短縮される
3. 相手の発言が、自動でていねいな敬語に整えられる
4. 議事録係の人件費を、クライアントへ請求できるようになる
解説：ZUNDA…（訳：記録を任せ、人は会話に集中する。豆を数える手を止めてこそ、相手の目をまっすぐ見られるのだ）

Q4. MeetのAIメモを議事録として配る前に、確認が必要なのはどれ？
1. 話し合われていない担当者や期限もAIが正しく決定済みか
2. 要約・決定事項・担当者・期限が実際の合意と一致しているか ← 正解
3. 録画の解像度を上げればメモの誤りが必ず消えるか
4. AIメモなら参加者の確認を省いてよいか
解説：ZUNDA…（訳：AIメモにも抜けや誤りはある。発言や合意と照らし、担当と期限が曖昧なら人に確認してから配るのだ）

Q5. AI議事録をチームに送る前に、ひと手間かけるとしたら最も適切なのは？
1. AIが作ったものは完璧なので、確認せずそのまま全員へ送る
2. 気になる箇所は消し、自分に都合のよい内容だけ残して送る
3. 決定事項と担当・期限が正しいかを人が確認してから共有する ← 正解
4. 議事録は一切共有せず、自分の控えとしてだけ持っておく
解説：ZUNDA…（訳：決定と担当と期限だけは人の目で検（あらた）めてから配るのだ。AIの餡は旨いが、客に出す前に一口味見するのが料理人なのだ）
