Q1. 作り終えたスライドの発表原稿をAIに任せたい。詳細で紹介されている頼み方はどれ？
1. スライドをGeminiにシェアするかPDFで読ませ、「各スライドのスピーカーノートを書いて」と頼む ← 正解
2. スライドのタイトルだけをコピーしてGeminiに貼り、そこから原稿を作らせる
3. スライドを画像で1枚ずつ保存し、順に感想を書いてもらう
4. 発表を一度本番でやって録音し、その文字起こしを原稿にする
解説：スライドまるごとGeminiに読ませて「ノートを書いて」と頼むの。タイトルだけじゃ中身は分からないでしょう。全部見せてこそ、あなたに合った台本が返るってわけ。

Q2. スピーカーノート生成時にできる条件指定の例として、正しいのはどれ？
1. フォントサイズの指定だけができる
2. 条件は指定できず、一律の原稿しか出ない
3. スライドの背景色に合わせて口調が変わる
4. 「初心者向け／専門家向け」「15分用／30分用」など聞き手や時間を指定できる ← 正解
解説：「初心者向けに」「15分用で」なんて注文が通るのよ。ふふ、相手と持ち時間で衣装を替える……当然のたしなみじゃない。

Q3. この機能の実務上のメリットとして、最も適切なのはどれ？
1. 発表そのものをAIが代行してくれる
2. スライドの作成自体が不要になる
3. 原稿準備の時間を大きく縮め、話の構成整理にも役立つ ← 正解
4. 質疑応答の回答内容まで保証される
解説：原稿作りの時間がぐっと縮んで、話の流れまで整理できるの。準備が軽くなれば、本番で輝く余裕が生まれるってわけよ。

Q4. 同じスライドを、今度は現場の専門家に向けて発表することになった。賢い使い方はどれ？
1. スライドを一から作り直す
2. 「専門家向けに書き直して」と条件を変えて原稿を再生成する ← 正解
3. 原稿はそのままで、話す速度だけ上げる
4. 聞き手に事前に資料を読んでおいてもらう
解説：あら、賢いのは条件を変えて作り直させること。「専門家向けに」の一言で、同じスライドが別の顔を見せるの。使い回しが効くのが強みよ。

Q5. AIが書いた発表原稿を、本番でどう扱うのが適切か。最も良い姿勢はどれ？
1. 一字一句そのまま棒読みするのが正解
2. 原稿は読まず、当日その場の思いつきで話す
3. 長すぎる箇所も一切削らず、すべて読み上げる
4. たたき台として、事実確認と自分の言葉への調整をしてから使う ← 正解
解説：AIの原稿はあくまで下地よ。事実を確かめて、あなたの言葉に直してこそ生きるの。借り物の台詞も、着こなしてこそ様になるってものよ。
