Q1. NotebookLMで自社の営業プレイブックを作るとき、ソースに入れる材料として最も有効なのはどれ？
1. 競合他社のパンフレットだけ
2. 過去の商談の録音文字起こしや、受注につながった成功事例の資料 ← 正解
3. 営業担当の顔写真と名刺データ
4. 業界ニュースのヘッドライン一覧のみ
解説：過去の商談の文字起こしと成功事例こそ、勝ち筋を宿す軍記なり。己の戦歴から学ぶが最強の兵法ぞ。

Q2. 商談議事録を投入した後、断られ場面に強くなる「反論処理の型」を作るのに最も効く問いかけは？
1. 「うちの商品は素晴らしいですよね？」と同意を求める
2. 「競合の悪口を10個考えて」と頼む
3. 「よくある反論TOP10と、それぞれへの切り返しトークを抽出して」と頼む ← 正解
4. 「反論されない方法を1つだけ教えて」と聞く
解説：「よくある反論TOP10と切り返し」を抽出させよ。敵の出方を先に読み備える、風林火山の構えなり。

Q3. 相手や場面に応じたトークを準備したい。この教材が挙げる抽出テーマとして適切な組み合わせは？
1. 自社の社歌・創業者の座右の銘
2. 天気・スポーツ・グルメの雑談ネタ集
3. 商談を早く切り上げる口実集
4. 決裁者向けトーク・価格交渉対策 ← 正解
解説：決裁者向けの弁と価格交渉への備え、この二つを抽出させよ。相手の位に応じ言を変える、火の如き攻めの支度ぞ。

Q4. 商談記録から反論処理やトーク案を「型」としてまとめる、経営上の最大のメリットは？
1. 属人的だった営業ノウハウが共有可能な『営業の型』になり、チーム全体が底上げされる ← 正解
2. 営業担当が商談中に一切話さなくて済むようになる
3. 顧客がAIと直接商談してくれるようになる
4. 今後いっさい議事録を取らなくてよくなる
解説：個人の技を「型」に変えれば全軍の力となる。人は城、人は石垣。兵一人ひとりを強くする仕組みこそ勝利の源泉なり。

Q5. エースの退職で受注率が落ちた。NotebookLMで立て直す実務手順として最も筋が良いのはどれ？
1. 新しいエースを採用するまで営業活動を止める
2. エースが残した商談の文字起こし・成功事例を投入し、反論TOP10と切り返し・決裁者向けトークを型として抽出し全員で共有する ← 正解
3. とりあえず各自の勘で商談を続け、様子を見る
4. 競合のパンフレットを集めて真似することに専念する
解説：去りし将の戦歴を型に写し、全軍へ配れ。人は城の教えの通り、仕組みで兵を強くすれば城は崩れぬ。
