Q1. NotebookLMで作る「第2の脳」とは、実務的にどういうものか？
1. ネット全体から一般的な知識を答えてくれる汎用の検索エンジン
2. 頭で覚えるべき情報を減らすための暗記アプリ
3. 自分の発信や資料を集約し、自分の視点で答えを返してくれる情報基盤 ← 正解
4. 文章を自動でSNSに投稿し続ける発信ツール
解説：自分の情報を一か所に集め、己の代わりに考える土台を築くのが第2の脳だ。ただの検索や暗記アプリと取り違える者はいねがー！？

Q2. 「第2の脳」に入れる情報として、狙い通りに機能させる組み合わせはどれ？
1. 他人が書いた一般的なニュース記事だけを大量に集める
2. 自分のブログ・SNS投稿・録音、読書メモ、業務資料など自分の情報 ← 正解
3. インターネット上の匿名の口コミを手当たり次第に集める
4. 内容は問わず、容量の大きいファイルを優先して入れる
解説：自分の発信・読書メモ・業務資料を集めてこそ『自分だけの脳』になるのだ。他人のニュースや匿名口コミばかり詰めても自分の声は返らんぞ。中身を選ばぬ者はいねがー！？

Q3. 「第2の脳」ができた後、その真価を引き出す問いかけとして最も適切なのはどれ？
1. 「一般的にはどう考えるのが正解？」と世間の模範解答を求める
2. 「この分野の最新ニュースを教えて」とネットの最新情報を尋ねる
3. 「私の代わりに結論だけ決めて」と丸投げして即断させる
4. 「私らしく考えると、この件はどう捉える？」と自分の視点を引き出す ← 正解
解説：『私らしく考えると?』と問えば、過去の自分の思考に沿った答えが返るのだ。世間の模範解答や最新ニュースを求めるなら普通のAIで十分。宝を活かさぬ者はいねがー！？

Q4. 「第2の脳」を、時間が経っても役立つ生きた仕組みに保つコツはどれ？
1. 自分の発信や業務資料を、同じノートブックに集約し続ける ← 正解
2. 一度作ったら二度と手を触れない
3. テーマと無関係な資料も手当たり次第に放り込む
4. 毎週ノートブックを消して一から作り直す
解説：同じノートブックへ集め続けることで脳は育つのだ。作りっぱなしで放置し、埃をかぶらせる怠け者はいねがー！？継続こそ力よ。

Q5. 「第2の脳」を仕事のチームでも活かしたい。属人化を防ぐ発展的な使い方として最も適切なのはどれ？
1. 自分だけが見られるよう鍵をかけ、誰にも渡さない
2. 個人メモなので中身は整理せず放置する
3. ベテランの知見を集約したノートブックをチームに共有し、誰でも質問できるようにする ← 正解
4. 作った脳は退職時にすべて削除する
解説：一人の頭の中を皆で引ける形にすれば、退職や属人化の穴も埋まるのだ。宝を独り占めして抱え込む者はいねがー！？ガハハ！
