Q1. 部署の親フォルダを協力会社に共有したところ、その中に置いた「役員限定」フォルダまで相手に見えてしまいました。なぜこうなったのでしょうか？
1. ファイル作成者が退職すると権限が消えるから
2. 共有権限は一定期間で自動的に失効するから
3. 親フォルダの共有権限が、中のフォルダやファイルにも引き継がれる(継承される)から ← 正解
4. 閲覧者が自動で編集者に昇格したから
解説：親フォルダの権限は、中の子や孫にもそのまま流れていくのじゃ。上の器を渡すと中身まで見えてしまう——この「継承」を知らぬと、蔵の奥まで開けっ放しにしてしまうのう。

Q2. 上のフォルダは協力会社に共有したまま、その中の1フォルダだけは社内限定に戻したい。使うべき設定はどれでしょうか？
1. 対象フォルダの共有設定で「アクセスを制限」を有効にし、共有相手と一般的なアクセスを確認する ← 正解
2. そのフォルダで協力会社を閲覧者から編集者に変更する
3. そのフォルダに社内メンバーを新たに編集者として追加する
4. そのフォルダのリンクを「リンクを知っている全員」に切り替える
解説：限定したい資料は、アクセスを制限したサブフォルダへ置くのじゃ。直接の共有やグループ、一般的なアクセスも確かめる。共有ドライブの管理者などは引き続きアクセスできるぞ。

Q3. 資料の共有設定で、閲覧者・コメント可のユーザーによるダウンロード・印刷・コピーを無効にする狙いはどれでしょうか？
1. 閲覧者がファイル自体を開けないようにするため
2. 閲覧者の編集履歴をコメントとして残すため
3. 閲覧者のアクセスを社内ネットワーク内に限定するため
4. 閲覧者・コメント可のユーザーが使うダウンロード・印刷・コピーの操作を制限するため ← 正解
解説：閲覧者に権限変更の力は元々ないのじゃ。ダウンロード等の制限と編集者の再共有制限は別の設定。画面の撮影まで防げる保証はないから、見せる相手も選ぶのう。

Q4. 顧問先ごとの機密資料を扱う士業事務所です。漏洩を防ぐ運用として最も適切なのはどれでしょうか？
1. 事務所全体フォルダを全員に共有し、中の権限は個別に考えない
2. 機密資料はアクセスを制限したフォルダに分け、共有相手と一般的なアクセスを必要な範囲に絞る ← 正解
3. 機密資料はメール添付でやり取りし、共有設定は使わない
4. 手間を省くため全ファイルを「リンクを知っている全員」にする
解説：必要な担当者を決め、誰に見えるかを確かめるのじゃ。親の権限だけでなく、直接共有やグループから入れる人も見落とさぬようにのう。

Q5. 「とりあえず全員に編集者権限を配れば、後で誰かが困らなくて親切」と考える担当者がいます。情報漏洩の観点でこの考えの何が問題でしょうか？
1. 必要のない人まで機密に触れ、削除・誤共有・持ち出しの窓口が増える ← 正解
2. 編集者全員に通知が飛び、メンバーの作業が中断される
3. 権限が多いとファイルのバージョン履歴が保存されなくなる
4. 編集者どうしの同時編集で保存が競合し、必ずデータが消える
解説：必要な人に必要な分だけ、が権限の作法じゃ。全員に編集の鍵を配れば、触れる手が増えるほど漏れや誤操作・持ち出しの口も増える——親切のつもりが仇になるのう。ね、兄者？「うむ」
