Q1. Googleドキュメントから電子署名の依頼を送る手順として正しいのはどれか？
1. 共有ボタンで編集権限を渡し、相手に名前を打ってもらう
2. 挿入 → 図形描画でサインの画像を手描きしてもらう
3. ツール → 電子署名から署名者を指定して送信する ← 正解
4. ファイル → 印刷からPDFにして紙で郵送する
解説：「ツール → 電子署名」から署名者を指定して送るのだ！正しい手順こそ契約の重みを守る、心して臨め！

Q2. この電子署名機能の位置づけとして、講座の説明に合致するのはどれか？
1. GoogleドキュメントやDrive上のPDFから署名を依頼し、進捗を確認できる機能 ← 正解
2. 手描きサインを画像として飾るだけの装飾機能である
3. Googleフォームの回答を集計する機能の一種である
4. 日本国内では一切法的効力を持たない実験機能である
解説：署名欄と署名者を指定し、依頼や進捗を管理する機能である。他サービスと同じ機能がすべてあるとは限らぬ。必要な手続きに合うかを確認するのである。

Q3. 電子署名機能を使う前に確認すべき利用条件はどれか？
1. 署名者全員が同じ会社のドメインであること
2. パソコンにプリンターが接続されていること
3. 契約書が英語で書かれていること
4. 署名を依頼する側が対象のWorkspaceプランを使い、組織では管理者が機能を許可していること ← 正解
解説：Workspace IndividualやBusiness Standardなど、対象の契約を確認するのである。有料なら全プランで使えるわけではないぞ。

Q4. 複数人が署名する契約で電子署名の依頼を送るとき、締結を滞らせないための正しい進め方はどれか？
1. 署名者の順序や役割は指定できないので、誰から署名しても同じである
2. 送信前に署名者と各人の署名欄を確かめ、必要な承認手順にも合うか確認する ← 正解
3. とりあえず全員に編集権限を渡し、好きな場所に署名してもらう
4. 送信後は署名欄も署名者も一切変更・確認できないので、事前の設定は不要である
解説：誰がどこに署名するか、送信前に確かめるのである。特定の順番が必要なら、利用できる機能と組織の手順を確認するのである。

Q5. 電子署名によるペーパーレス締結が中小企業にもたらす実務メリットとして最も適切なのはどれか？
1. 契約内容の交渉そのものをAIが代行してくれる
2. 印刷・郵送・返送待ちの手間と時間が消え、契約書PDFの管理負担も減る ← 正解
3. 収入印紙をどんな契約でも完全に無視できるようになる
4. 契約相手の信用調査が自動で行われる
解説：印刷・郵送・返送待ちの日々よさらば、PDF管理の重荷も軽くなる！紙に縛られず、スピードで起き上がれ！
