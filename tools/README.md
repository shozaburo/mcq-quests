# tools

## bgm-place.py — Sunoで作った曲をステージのBGMに仕上げる

Sunoで作った8曲（または候補16曲）を、A.mp3〜H.mp3 に仕上げて並べる。

```
pip install librosa scipy numpy      # 初回だけ
python3 tools/bgm-place.py <入力フォルダ> <出力フォルダ> --seed 7
cp <出力フォルダ>/[A-H].mp3 stages/chatgpt64/bgm/
```

やること

1. 曲名のことばと、測ったテンポ（BPM）の両方で、どの部屋の曲かを見分ける
   （曲名を強め・BPMを弱めに見て、8曲と8部屋を1対1で割り当てる）
2. 候補が2曲ある部屋は、どちらか1曲をランダムに選ぶ（`--seed` で固定できる）
3. 曲の終わりの無音を切る
4. 音量を -16 LUFS にそろえる（2回測って合わせる方式）
5. くり返し再生のつなぎ目の音量差が 8dB を超えていたら、頭の2秒を終わりに重ねて
   なめらかにする（`acrossfade`。もとの曲より2秒短くなる）
6. 結果を `_report.json` に残す

部屋ごとの目標テンポは、Sunoに渡した指示文の値（A=92／B=85／C=100／D=72／
E=80／F=108／G=96／H=66）。ステージを増やすときは `AREAS` を書き換える。

サイト側は `assets/bgm.js` が `stages/<stage>/bgm/{A-H}.mp3` を
`loop = true` で再生する。ファイルが無い場合は静かに何もしない。
