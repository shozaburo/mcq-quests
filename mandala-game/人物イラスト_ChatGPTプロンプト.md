# 人物イラスト生成プロンプト（ChatGPT / GPT Image・DALL·E 用）

4人分。**正方形・バストアップ**。4枚が同じ絵柄でそろうよう、共通の指定を全プロンプトに入れてある。

## 使い方

1. ChatGPT に下のプロンプトを**1人ずつ**貼って生成する
2. 生成された画像を `1024×1024` の正方形で保存し、下記のファイル名でこのフォルダの `img/` に置く
   - `img/hayato.png` / `img/mio.png` / `img/taiga.png` / `img/sayo.png`
3. ファイルを置くだけでゲーム側に出ます（`data.js` の各人物に `img` を追記する形。未設置でも動きます）

**4枚まとめて作りたい場合**：最初の1枚を作ったあと、2枚目以降で
「**さきほどと同じ画風・同じ照明・同じ背景処理・同じ塗りで、別人を描いてください**」と添えると揃いやすい。

---

## 共通のスタイル指定（各プロンプトに含めてある）

- 和の落ち着いた色調（生成りの紙、藍・墨・金茶）
- 水彩＋淡い線画。写真ではない
- 背景は無地に近い和紙のテクスチャ、人物の背後だけ淡くにじませる
- 正方形・バストアップ（胸から上）、正面〜やや斜め、目線はこちら
- 表情は穏やかで、少し誇りのある顔。作り笑いではない
- 文字・ロゴ・透かしは入れない
- 実在の特定人物に似せない

```
義足で職場に復帰した人。杖を片手に持ち、背筋を伸ばして立っている。
表情は穏やかで、まっすぐ前を見ている。苦労を経た人の静かな自信。悲壮感は出さないこと。

画風：水彩と淡い線画。写真的な描写ではなく、手描きの温かみ。
色調：生成りの紙のような背景色に、藍・墨・金茶を基調とした落ち着いた配色。
背景：無地に近い和紙のテクスチャ。人物の背後だけ淡くにじませる。小物や風景は描かない。
構図：バストアップ（胸から上）、正面からやや斜め、目線はこちら。顔が画面中央にくるように。
照明：やわらかい斜め上からの光。強い影は作らない。

文字・ロゴ・透かしは一切入れないでください。実在の特定人物には似せないでください。
```

## 画像を置いたあとの作業

`data.js` の各人物に1行足すだけです（すでに対応済み。画像が無い場合は自動で頭文字の丸印になります）。

```js
{ id:"hayato", name:"隼人（57）人材ビジネスの統括部長", img:"img/hayato.png", ... }
```

| 人物 | id | ファイル名 |
|---|---|---|
| 隼人 | `hayato` | `img/hayato.png` |
| 美緒 | `mio` | `img/mio.png` |
| 大河 | `taiga` | `img/taiga.png` |
| 紗代 | `sayo` | `img/sayo.png` |

推奨サイズ 512×512〜1024×1024 の正方形。1枚 300KB 以下に圧縮しておくと、
研修会場の回線でも待たされません。
