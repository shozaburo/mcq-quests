# マンダラチャート®人生とビジネスを豊かにするゲーム（v3・カード制／複数人版）

4〜6人で回すことを前提に作り直した版。v2（1人用・毎週ルーレット）の後継。

## v2から変えた理由

v2は毎週ルーレットを回して二択を迫る形だった。1人ならいいが、**複数人だと毎回の判断が重く、
待ち時間が長く、流れが悪い**。そこで「軽い手番」と「重い手番」を分けた。

## 遊び方

`index.html` を開く（`data.js` と同じフォルダに置くこと）。

1. **人数を選ぶ**（1〜8人）
2. **各自が人物を選び、A型チャートを作る** — 中心の言葉を3案から、8分野の年間目標を各2案から
   （8分野はすべて **0%** から始まる。行動はまだ何も起こしていない）
3. **はじまりの賽** — 各自が**四つの賽**を振り、**心・体・現預金・月収**を決める。
   心・体は目×10+40（50〜100）、現預金は目×10万円（10〜60万円）、
   **月収は目×5+10万円（15〜40万円）**。月収は世帯の月収として置く
   （ひとりで稼いでいても、家族で支えていても、家計に入ってくる額）。
   出発点は人によって違う。持ち点は選べず、ここからどう組み立てるかだけが選べる
4. **手番が来たら手帳をめくる** — 細長い手帳がひらき、**週間行動計画の見開き**が出る。
   曼荼羅手帳の週間ページは**それ自体が3×3のマンダラ**で、中央が「今週の目標・役割」、
   まわりを月〜日の7日と「今週の評価・感想・対策」が囲む。中央の欄に、その週の判定が押される
   （4週に一度は給料日で、右のMEMO欄に**記帳**が入る）

   - **アクション（3回に2回）**
     盤面のマンダラが選べるようになる。**A型チャートのマスを直接タップ**して、
     この一週間で動かす分野を選ぶ → 賽を振る → **出た目×10%** だけ進む。
     どのマスが埋まるかは**ランダム**（きれいに揃って進むことは現実には起きない）。
     ♦重点分野なら目が1つ上がる。**判断は軽く、10秒ほどで次の人へ**

   - **リスク発生（3回に1回）**
     「突然のトラブル（四苦八苦）か、それとも幸運の縁か」。
     マンダラルーレットが回り、止まった分野で出来事が起きる。
     - **7割は三択のエピソード**（既存96話）。どれにも代償と実りがある
     - **3割は運命の回**。賽を振り、その目のぶんだけ劇的に動く

5. **13週＝1四半期で一区切り** — 全員の順位・8分野の進捗（前期比）・8大原則のメンターコメント。
   各自が来四半期の**重点分野♦**を選ぶ。次へ進むと**8分野の進捗は0%に戻る**
   （三か月は三か月で区切って積む＝OKRの刻み）。心・体・お金の持ち点は持ち越し
6. **4四半期を終えると** 一年の結果と段位（得点は四半期ごとの積み上げ）

## 運命の回（四苦八苦／幸運の縁）

リスク発生の3割で起きる、賽を振る回。**順当に上がるのではなく、劇的に動く**。

| 種類 | 例 | 効果 |
|---|---|---|
| 四苦八苦 | 高熱で一週間寝込んだ／親が救急車で運ばれた | 賽の目 × 5 だけ心・体・お金が**減る** |
| 四苦八苦 | 取引先が突然たたんだ／設備が壊れた | 賽の目 × 5 だけお金が**減る** |
| 四苦八苦 | 積み上げたものが崩れた／信頼を損ねた | その分野の進捗が **0%に戻る**（やり直し） |
| 幸運の縁 | 思わぬ紹介／追い風／ひらめき | 賽の目 × 10% だけその分野が**一気に進む** |
| 幸運の縁 | 臨時の入金／評価された | 賽の目 × 5 だけお金・心が**増える** |

現在20枚（四苦八苦10・幸運10）。プラスとマイナスは同数で、期待値は中央に置いてある。

途中で閉じても**続きから再開**できる（端末内に保存）。

## 三つのメーター（心・体・お金）

目盛り付きの横バー。変動すると跳ねて増減が浮かぶ。

| | 単位 | 意味 |
|---|---|---|
| **心** | 0〜150（100が満） | やる気・充実・心の余白 |
| **体** | 0〜150（100が満） | 体力・健康の余力 |
| **お金** | 円（万円単位） | **手持ちの現預金**。0を割ると借入 |

- 心・体は**100が満ちた状態**。バーに基準線があり、**100超は「無理」表示**（無理をしている領域）
- お金は日本の給与所得者の**月収中央値（およそ30万円）が真ん中**に来るようにしてある。
  初期は10〜60万円。得点計算では 0〜150 の指数に直して他の二つと比べる（33万＝50、67万＝100）
- **借入の金利は四半期ごとに10%**。マイナスのまま四半期をまたぐと利息が乗り、
  レビュー画面で「利息◯万円 → 残高−◯万円」と生々しく出る

## お金はこまめに動く

一年に数回の大事件だけでお金が動くのは嘘くさい。実際には毎週すこしずつ出ていく。

**① 月収（4週に一度の給料日）**
はじまりの賽で決めた月収が、第4・8・12週に記帳される。
`給与 − 生活費（月収の82%） = 手元に残る分`。月収15万円の人と40万円の人では、
同じ一年でも残高の伸びがまるで違う。**世帯月収**なので、自分が稼いでいるかどうかは問わない。

**② 分野を動かすと、その分野なりにお金が動く**（アクションのたびに1つ起きる）

| 分野 | 例 | 平均 |
|---|---|---|
| B 仕事 | 副業の入金／残業手当／立替が戻った | **＋1.3万** |
| C 経済 | 固定費を落とした／積立を始めた | ＋0.5万 |
| F 人格 | 本をまとめて買った／早起きして家で過ごした | −0.8万 |
| A 健康 | ジムの会費／歯の治療／人間ドック | −1.3万 |
| G 学習 | **講座の受講料（−4万）**／参考書／受験料 | −1.3万 |
| H 遊び | 一泊の旅行／趣味の道具／映画と食事 | −1.5万 |
| E 社会 | **友人の結婚式のご祝儀（−3万）**／年会費／送別会 | −1.8万 |
| D 家庭 | 親への仕送り／家族の学用品と行事／修繕 | −2.0万 |

**増やす側は仕事と経済しかない**。学びも、人づきあいも、遊びも、家族も、
動かせばお金が出ていく。だから「仕事だけやる」も「学びだけやる」も、家計から歪む。
8分野の調和は、精神論ではなく家計の話でもある——というのがここの狙い。

全32項目、`data.js` の `areaMoney` で研修先ごとに差し替えられる。

## ハイライト画像とエンディングムービー（Gemini / Veo 3）

**四半期ごと**のリフレクションと**年間結果**に、生成AI用のプロンプトが出る。
生成そのものは各自の端末でやってもらう（このゲームは通信しない）。

| いつ | 何が出るか | 渡す先 |
|---|---|---|
| 四半期ごと | **その三か月の一枚**の画像プロンプト | Gemini（画像生成） |
| 年間結果 | 同上＋**8秒×5カットの台本** | Veo 3 |

プロンプトはその人の実際のプレイから起こされる。**中心の言葉／いちばん進んだ分野と到達%／
置き去りにした分野／心・体・お金の状態／手帳に残った気づきの一行**が織り込まれるので、
同じ盤を回しても全員ちがう文章になる。画風は人物イラストと同じ和の水彩でそろえてある。

ムービーの台本は四半期ごとの実データから4カットを起こし、最後にこの1カットで終わる。

> 一年を終えたこの人が、手帳をひらいて次の一年の中心に何を書くか迷っている。
> ペン先は紙に触れているが、まだ動かない。そこで映像は終わる。

「コピー」を押してGeminiに貼るだけ。休憩時間や研修後の宿題として使える。

## 結果の見せ方

四半期／年間の結果は、**マンダラチャート（3×3）**と**レーダーチャート（8角形）**の二枚で出る。
マンダラは到達度が高いほど緑が濃くなり、0%は赤字。レーダーは盤と同じ巡り（12時のCから時計回り）
に軸を並べてあるので、盤面と同じ形で歪みが見える。

## 得点

```
得点 = 8分野の平均到達% × 10 × 調和の係数 × 心体財の係数
分野の到達%   = その分野の8マスの平均（各マス100%上限）
調和の係数    = (一番低い分野+10) ÷ (平均+10)   （どれかを見捨てると伸びない）
心体財の係数  = 0.5 + 一番低いメーター/100    （心・体・お金も、低い方で決まる）
```

**8分野も、心体財も、「一番低いもの」で決まる**。マンダラチャートの調和の思想を二重に効かせている。

調和の係数に +10 の下駄を履かせているのは、1四半期（13手番）では
確率的にどうしても手の回らない分野が残り、そこで全員が0点に潰れてしまうため。
順位づけの性質（調和を取った人が上、一点集中が最下位）は変わらない。

なお**手をつけていない分野（0%）には、リスクカードのルーレットが3倍止まりやすい**。
見ていない分野ほど、出来事のほうから訪れる。

年間の段位：秀1200+ / 優900+ / 良600+ / 可300+ / 続それ以下。

シミュレーション（4人物×800回・月収と分野ごとの出費まで入れた版）：

| 打ち方 | Q1（13週）の中央値 | 通年の中央値 | 通年の現預金 | 借入で終わる率 |
|---|---|---|---|---|
| 低い分野・低いメーターを守る | 105点 | **792点** | 80万円 | 0% |
| 適当に選ぶ | 77点 | 304点 | 58万円 | 7% |
| 伸びている分野ばかり伸ばす | **57点** | **218点** | 56万円 | 9% |

伸びている分野を伸ばす「わかりやすく強そうな打ち方」が最下位になる。ここが研修の核。

**月収の差より、打ち方の差のほうが大きい**（通年・調和重視・各250〜290回）：

| 月収 | 通年の得点中央値 | 通年の現預金 |
|---|---|---|
| 15万円 | 671点 | 65万円 |
| 30万円 | 825点 | 81万円 |
| 40万円 | 944点 | 99万円 |

月収の高い人と低い人で1.4倍。打ち方の違いは3.6倍（792 対 218）。
**配られた条件より、配られたあとの打ち方のほうが効く**——これは意図してこの比にしてある。

## 演出

- **手帳をひらく**：細長い表紙が左に開き（金文字が鏡文字にならないよう裏面は隠してある）、
  週間行動計画の見開きが現れる。日付・罫線・MEMO欄・ページ番号・綴じ目まで入っている
- **賽**：ドット目の賽が跳ねて転がり、止まるときに一度弾む
- **メーター**：バーが伸縮し、増減が数字で浮かんで消える
- 検証時は URL に `?fast=1` で演出を短縮できる（研修では使わないこと）

## キャッシュについて

`data.js` を更新したら、`index.html` の `<script src="data.js?v=N">` の **N を必ず+1** すること。
古い `data.js` が残っているとカードが引けなくなる。
起動時に不整合を検知して赤い帯で警告し、その場合でも手番が詰まらないようにしてある。

## 人物データ（研修先ごとの版を作る）

`data.js` の `profiles` に1人分足すだけ。

```
{
  id, name, desc,
  centerOptions: [中心の言葉 3案],
  areas: { A〜H: { goalOptions:[年間目標 2案], cells:[B型の実践行動 8つ] } },
  episodes: [ 24本（8分野×3本）
    { area:"A", principle:"kansha", title, text(200字級),
      a:{ label, cells:[[分野,マス番号0-7,±1]], meters:{kokoro,karada,okane}, result },
      b:{ ... }, c:{ ... },      // 3択。cは「第三の道」
      insight }
  ]
}
```

- `principle`：`sougo` `tougou` `arubeki` `kaihatsu` `kansha` `shutai` `kasetsu` `keizoku`
- `meters` は各 -3〜+3。画面では **×5** して反映される
- **鉄則**：どの選択肢にも代償がある。cを「正解ボタン」にしない
- `progressFlavors` は進捗報告カードの場面描写（18種）

現在の収録：**8人 × 24話 × 3択 ＝ 192話・576の選択肢**（＋運命カード20枚）。

## 盤面の並び（マンダラチャート標準配置）

```
  F  C  G
  B 中心 D
  E  A  H
```
A型・B型9×9のブロック・ブロック内8マス・ルーレット・結果のマンダラ・
**四半期リフレクションの重点分野**、すべてこの規則。レーダーチャートの軸も、
12時のCから時計回りにこの盤を一周する順（C→G→D→H→A→E→B→F）に並べてある。

**週間行動計画の見開きも同じ形**をしている。曼荼羅手帳の週間ページは3×3のマンダラで、
中央が「今週の目標・役割」、まわりを月〜日の7日と「今週の評価・感想・対策」が囲む。

```
  月  火  水 │M
  木 目標役割 金│E
  土  日  評価│M
```
細長い手帳をひらくと、見開きがマンダラチャートとほぼ同じ正方形になる——
という現物の特徴を、画面でもそのまま再現している（3列＋MEMO＝3.66 に対して3行）。
